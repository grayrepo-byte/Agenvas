# 画布交互与视觉优化

界面实现位于 `frontend/`，产品决定同步至规格与 ADR 0005。保留现有蓝色主题、shadcn 组件、节点创建、连线与生成授权规则；没有 API、合约、数据库或依赖变更。

## 呈现与交互

- 画布采用深灰点阵、细边框与轻阴影，统一卡片、选中外圈、浮动工具栏及保存状态。视觉变量集中在 `src/shared/ui/design-tokens.css`。
- 左上项目返回、名称与保存状态、右上资源与导出分别组成悬浮区域。左侧中部直接展示创建、选择、手形与设置；选择/手形使用 shadcn ToggleGroup，并提示 V、Space，沿用现有按住 Space 临时平移、短按切换手形及输入区快捷键隔离规则。“+”菜单在按钮旁展开，新节点落在当前可见画布中心；双击保留触发位置。
- 左下角改为紧凑视图工具条，避让右下角导演窗口：显示实际缩放比例、恢复 100%、放大/缩小、适应画布，以及默认收起的小地图。到达缩放边界时禁用对应按钮；空画布禁用适应和小地图。适应视图最高为 100%，避免首个节点被自动放大。
- 空画布使用现有 shadcn Empty，直接提供文字、图片、视频和音频创建按钮，复用既有节点创建流程，在当前可见画布中心放置；中、英、日、俄文案继续集中管理。
- 节点编辑面板继续采用屏幕尺寸和节点锚点，在视口边缘自动避让；保留底部导航区域。与面板重叠的节点操作栏移到面板上方。只调整浮层位置，不修改画布坐标或视口，不重建编辑器。
- 短窗口通过收缩提示词区域保留操作栏，长提示词继续内部滚动。浮层层级保证关闭按钮可点击，原有菜单与对话框仍使用公共 Portal。
- 动效用于面板出现、工具按钮悬停、保存状态及卡片层次变化。卡片拖动不对坐标或尺寸做过渡。新增 CSS 动效仅在系统允许时启用；视图工具在减少动态效果模式下立即切换。
- 导演入口位于右下角并采用次级视觉层级。桌面从 1024px 提供画布编辑；更窄视口保留现有只读或简化提示。自适应编辑栏尺寸计算、草稿保存、状态与挂载生命周期保持原规则。

本节描述当前轻量布局；下文各次验证记录仅对应各自当时的实现，本次检查结果由开发清单记录。

## 可复现预览

在 `frontend` 执行 `pnpm dev --host 127.0.0.1`，打开：

- `/e2e/canvas-studio.html`：文字、图片、视频及独立导演窗口的合成工作区。
- `/e2e/canvas-studio.html?empty`：空画布与首次创建。

该页面使用真实工作区组件与内存 Mock，请求不会到达后端。支持创建产物节点、调整布局和编辑媒体草稿；未实现的写操作明确返回错误。刷新会重置合成数据，界面预览不能作为真实 Provider 接通的证据。此入口不进入生产构建。

## 自适应编辑栏（2026-10-21）

按用户最新反馈，编辑栏采用自适应布局：

- 宽度结合画布实际可用空间、节点在屏幕上的显示宽度与可读行长约束，不固定为某个像素宽度。窗口缩放或节点展示尺寸变化时重新计算。
- 图片、视频、音频及文字提示词按实际排版高度增长，删除文字后收缩；换行宽度变化时重新测量。测量保留原编辑器、光标、焦点与滚动位置，不重建文字或结构化引用。
- 编辑栏高度上限取自画布可用高度，并给视图导航及节点操作栏保留空间；提示词和超长反馈在各自区域内滚动，工具栏保留在滚动区外。
- 模型及参数工具栏按编辑栏自身宽度换行，使用容器查询处理窄面板。文字编辑不预留媒体参考区的空白。

当前自适应行为覆盖较早的固定宽编辑栏及固定行数约定。实现、主题变量、测试与本说明均位于前端，没有 API、数据库或依赖变更。

验证：新增内容增长/收缩、宽度变化重新测量、光标与草稿保留、画布/节点边界更新的回归测试。`usePromptContentHeight`、`CanvasEditorOverlay`、`PromptMentionEditor`、`TextGenerationEditor` 四个文件的 12 项通过；`MediaDraftEditor`、`ProjectWorkspacePage`、`ProjectWorkspaceImageLayout` 三个文件的 206 项通过，共 218 项。`pnpm typecheck`、`pnpm lint`、`pnpm build`、`git diff --check` 通过；构建仍保留既有的大分块提示。

本轮浏览器不可用，未做视觉复测。布局测量测试使用受控 DOM 尺寸，不能替代真实浏览器的布局与视觉验收。全量测试、后端测试、真实 Provider 调用：未运行。
