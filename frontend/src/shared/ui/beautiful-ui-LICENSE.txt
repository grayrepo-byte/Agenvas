Shared non-canvas UI adapts the dark sidebar row hierarchy/collapse motion,
context-card surfaces, records status chips and pixel loader from Beautiful UI.
https://www.beautifului.dev/
https://github.com/slev12397/beautiful-ui/blob/main/components/primitives/SidebarNav.tsx
https://github.com/slev12397/beautiful-ui/blob/main/components/primitives/ContextCards.tsx
https://github.com/slev12397/beautiful-ui/blob/main/components/primitives/RecordsTable.tsx
https://github.com/slev12397/beautiful-ui/blob/main/components/primitives/LoadingState.tsx
https://github.com/slev12397/beautiful-ui/blob/main/app/globals.css

Adaptations: application routes and real session lifecycle; Phosphor icons;
scoped black tokens, native accessible controls, responsive navigation and
reduced-motion styles. No demo data, simulated tasks, or private reasoning.
The loader is shared with canvas consumers without changing their behavior.
