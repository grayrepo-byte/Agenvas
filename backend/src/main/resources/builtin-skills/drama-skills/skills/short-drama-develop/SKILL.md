# 故事开发卡片

先读取 [卡片工作流](references/agenvas-cards.md)，需要保存时读取 [卡片模板](assets/card-templates.md)。输入可以是用户想法、原著分析卡、梗概或多集剧本卡；不要求先建立全套材料。

1. 从当前输入确认题材、观众体验、主角目标、对抗关系、已有事实、时代、制作形态、语言及必须/禁止项。未知项留为待定，使用《创作简报》卡记录实际决定与候选，不能把模型建议写成用户已经接受。
2. 方向尚未决定时给出真正不同的故事方案，说明改变的戏剧发动机、风险与制作负担。已有明确方向时直接实现，不重复让用户确认。
3. 原著改编读分析索引和分集候选的固定版本，写《改编方案》卡：保留/合并/删改、原文功能、新载体、因果桥梁与来源引用。仅输入多集整稿时按 [多集摄入](references/multi-episode-intake.md) 先建《剧集索引》卡，再逐集规划。
4. 写《故事引擎》卡：人物策略、对手反制、状态变化、代价、反复出现但持续升级的机制。不要把设定百科当发动机。
5. 写《分集规划》卡，每集给 EP ID、进入状态、本集目标、关键转折、回报、退出压力、下一集继承事实及来源。集数多时拆成连续范围卡，在进度卡中引用实际版本。
6. 回查因果、跨集知识/持物/伤势/关系、重复回报和未决项。修改时引用原卡并追加版本；交接给写作的是本集精确卡片版本，不是文件位置。

## 按需方法

题材或钩子：[题材与钩子](references/genre-and-hook-playbook.md)；只有对应题材才读 genre-cards 内具体条目。
改编：[改编手艺](references/adaptation-craft.md)；创作参考：[参考摄入](references/creative-reference-intake.md)；导演阐述：[导演简报](references/director-brief-craft.md)。
故事因果：[故事手艺](references/story-craft.md)、[循环机制](references/mechanism-loop.md)、[前提装置](references/premise-devices.md)。
分集：[分集设计](references/episode-design.md)、[揭示反转回报](references/reveal-reversal-payoff.md)、[人物与系列记忆](references/serial-character-and-memory.md)。

## 完成

当前请求范围内的简报、引擎或分集规划已写入卡片，创作者决定与建议分开，来源和未决项可追溯，即完成；后续写作不自动开启。规则见 [阶段契约](references/stage-contract.md)。
