# 分集剧本卡片

先读取 [卡片工作流](references/agenvas-cards.md)，保存格式见 [卡片模板](assets/card-templates.md)。有分集规划时读本集固定版本；只有想法时建立最小单集意图；已有剧本只修订用户点名范围。

## 写作流程

1. 锁定本集观看承诺、人物目标、阻力、当集兑现和退出状态。开发大纲与长篇分析是可选输入，不强制补齐。
2. 在当前上下文排列「因为—行动—结果—新压力」，让物件、对白、沉默、空间或声音承担戏剧工作。只有输入确实依赖选择、争议证据、有限次数或精确死线时才用专项结构，不凭检查表加机关。
3. 逐场写可见变化、人物策略与场尾状态。动作、对白、画外音、声音事实、画面文字和连续性交接写在同一份《EP001 剧本》卡；长集可按场次范围拆卡，各卡带本集/场次 ID 与已写前文的真实版本引用。
4. 一级标题写 EP 和集名，场次标题写 EP-SC、内/外、地点、时间；对白写角色与必要表演提示。使用 [VO]、[OS]、[SFX]、[画面文字]、[连续性]、[转场] 区分文本职责。
5. 完稿检查因果、可表演性、观看承诺、题材语气和交接事实。自己新写的对白删除重复解释；用户原文保留个性，不借润色重写无关段落。
6. create_text 保存新剧本，revise_artifact 修订原卡并提交完整正文。用实际返回的新版本交接资产或分镜；失败/冲突保留候选。跨批次续写先读上次场尾与进度卡，不能仅凭聊天摘要续接。

## 时长与声音

只有用户需要时报告台词可发声字数、明确给定的语速、动作/停顿/转场假设与估算区间，写在剧本末尾或《剧本时长核对》卡。标点不计入可发声字数，数字/缩写按实际读法。没有速率只报告可数事实和未确定项，不虚构精确秒数；已有目标时长仍须通读压缩重复内容。VO 比例从实际台词计算，引用用户明确接受的节奏要求；估算不代表成片时长。

## 完成

点名范围保存成功，场景因果连贯、对白可表演、承诺有兑现或有意延迟、退出状态可追溯，即完成。资产、分镜、媒体与审查仅在用户需要时接续。规则见 [阶段契约](references/stage-contract.md)。
