# 单集分批续写与交接

同一轮写长集时，可以在当前上下文维护最小交接摘要；跨轮续写或用户要求保留断点时，将它写入《剧本创作进度》文字卡，使用 create_text/revise_artifact 保存真实版本。进度不能替代剧本正文。

## 只记下一段真正需要的内容

- 当前 EP、最后完成场次、本批实际保存的剧本 artifactId/versionId。
- 场尾仍影响下一场的地点、在场人物、知识、关系、伤势、持物和风险。
- 已建立但尚未兑现的铺垫/回报。
- 下一场确定的职责与退出状态，必要的议程、阻力与转折。
- 尚未完成范围、缺输入、保存失败与真正未决的创作分叉。

只记变化和依赖，不复制整集、人物小传或全部旧节拍。每项事实都能回到实际剧本版本与场次核对；摘要与正文冲突时先报告来源变化，不把候选想法当既定剧情。

## 恢复

下一轮由用户绑定当前剧本、进度及直接依赖的规划卡。先 read_artifacts 读实际版本与最后完成场次，检查 contentTruncated；只读到预览不能当完整前文。

对照场尾状态和未兑现义务，剔除因新版本过期的摘要。再读下一场直接依赖的规划/连续性来源，写明确的场景职责。正文保存成功后才更新进度中的实际 versionId；失败保留候选和断点。整集完成时把进度状态修订为完成，保留历史记录，不删除既有卡片。

进度只帮助续接，不代表创作者确认、审查通过或媒体批准。
