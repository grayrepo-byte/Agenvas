# 分镜与关键帧卡片模板

来源剧本/视觉设定 artifactId/versionId；本卡 EP/场次范围。

## SHOT-条目

剧本场次/行范围；戏剧职责；空间和轴线；景别/机位；人物站位；动作；对白/声音/画面文字；持续时间意图；起始状态；结束状态；持续状态变化依据。

### 关键帧提示词

起始帧与结束帧各冻结一个可见时刻，说明身份、状态、构图、光向、保持/允许变化。实际参考 IMAGE versionId 与顺序/用途/控制边界；无图片时写计划条目。

### 跨镜核对

左右手、持物/归属、视线、轴线、光态、起止状态衔接；缺场次/缺参考/未决项。关键帧提示词拆卡后记录该卡的真实 versionId。
