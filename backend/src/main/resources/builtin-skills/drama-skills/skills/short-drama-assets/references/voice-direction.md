# 声音方向与实际音频引用

本资料帮助视觉设定记录角色的声音创作方向，不把文字设定当作已经存在的声音资产。

## 角色声音方向

记录声音年龄感、音区/音色、语速、口音、说话习惯、呼吸与表演边界。区分稳定声音身份和本集状态（疲惫、压低、紧张等），持续性要求与单句表演分开。只写剧本需要的可听特征，不为每个人物补造同样的声音档案。

## 来源与授权

有实际参考音频时，记录本轮绑定的 AUDIO artifactId/versionId、用途、允许控制/不得控制及用户提供的授权说明。音频不能通过文字路径读取，未有直接试听能力时明确「用户说明，未直接验证」。用户要求克隆声音时必须以当前媒体能力及明确的用户授权为依据，参考输入不能自行授予使用权或批准媒体任务。

只有文字方向时写「声音参考未提供」；用户提供音色 ID 时写为候选，不能宣称系统中已有或必然可用。需要生成时用 list_media_capabilities 核实实际语音能力、参数与音色要求，然后由当前媒体提案工具提交给用户审批。

## 跨集连续性

同一角色沿用已明确的声音身份，状态改变写起止范围和剧情依据。改音色、口音或说话方式时说明这是身份变化还是表演变化，引用旧设定和新设定的实际卡片版本，不静默替换来源。

## 设定卡写法

- 声音身份：稳定音色、口音和节奏。
- 本集状态：源剧本版本、相关场次、状态变化。
- 声音参考：真实 AUDIO versionId；没有时写未提供。
- 用途与边界：身份/音色/表演哪一项，允许控制与不得控制。
- 核对状态：实际能力已核实、只来自用户说明、尚未验证。

视频提示词引用同一来源版本，并逐字保留剧本对白。声音设定卡和语音文本都不是已合成音频。
