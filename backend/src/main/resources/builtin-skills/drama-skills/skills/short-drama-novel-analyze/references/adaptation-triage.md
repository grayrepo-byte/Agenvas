## 产出什么

一份 `改编价值快评卡`，回答**这本书值不值得花全量拆解的成本**。

它是一份可以被后面推翻的假设：S5 拿全量结果回来对照它，被推翻的判断写进
`改编价值卡` 开头。

## 抽样怎么取

从章节索引卡的明确范围选样本：M 章中选 m=min(12,M) 个，m=1 时取唯一一章，m>1 时取 1+round(k*(M-1)/(m-1))，k 从 0 到 m-1。首尾必取，去重后在快评卡写下实际 sequence。使用同一索引版本时沿用同一批序号。

每个样本必须读到实际原文固定版本的完整对应范围。当前没有某样本输入时标记未读，不用摘要替代；说明实际已读样本和缺项。发现只有卷首页/目录条目的样本时顺延到最近正文并记录调整。用户要求更大样本时明确写出 m 与实际章号。

快评只判断**功能与载体**：不写完整情节点表，不写人物表，不产出 `逐章分析卡组` 下的文件。
逐章提取的格式要求见 [章节提取](chapter-extraction.md)，这一步不套用。

## 写六件事

`改编价值快评卡` 固定六段，缺一段不算快评。

### 1. 故事框架

从 [聚合与实体](aggregation-and-entities.md) 的框架表里选一个：升级流 / 复仇线 /
单元剧 / 多线交织 / 蜕变成长。框架决定后面按什么切单元，也决定这本书按集切的难度——
单元剧与短剧的集结构最贴合，多线交织在竖屏里最贵。

抽样判不出来时写「抽样不足以判断框架」并说明原因。

### 2. 三类判定比例

对抽到的每一章，判断它承担的功能属于哪一类（定义见 [改编价值](adaptation-value.md)）：

| 判定 | 含义 |
|---|---|
| `screen_ready` | 功能由可见行动、可听对白或空间关系承担 |
| `needs_carrier` | 功能成立，但当前载体是文字专属 |
| `prose_only` | 功能依赖读者与叙述者的关系，屏幕上无法兑现 |

写出三类各占抽样里的多少章。这是快评里唯一给数字的一段，其余用文字判断。
`prose_only` 过半时直接说明：全量拆解大概率只会把同一个结论算得更精确。

### 3. 开篇替换点

见下一节。

### 4. 制作负担量级

抽样里出现的：最多几人同框、需要多少个不重复空间、有没有群戏 / 动作 / 特效 /
可读文字 / 跨时间造型变化。给量级，不给预算表。

按已接受的制作形态估；形态未定时按两种形态各给一句，不替创作者选。

### 5. 三处最大改编风险

具体到抽到的哪一章、哪个功能。写「改编难度较大」对任何一本书都成立，
因此对这一本没有信息。

### 6. 分集候选量级

按抽样里的戏剧结果密度给一个量级（例如「约 20–30 集」），并写清这是从 N/M 章推出来的。
集数由创作者与 `$short-drama-develop` 定，这里给的是量级。

## 开篇替换点

回答一个问题：**如果这本书改成短剧，第 1 集从哪里开始**？

找**观众在此处收益最强、且能同时交代主角身份、眼前危机与目标的一处**：打脸、奇观、
反转、身份揭露、奖励兑现或危机爆发，能被拍出来而不是被想出来。兑现它的可以是旁观者——
群体改口、对手当众吃瘪，收益照样落在观众身上。它通常不在第一章，也常常不是时间上最早的那个
爽点：后文的高潮可以提前做冷开。写清四条：

- 落在第几章（用索引的 `sequence`），收益类型是什么；
- 抽样里若另有更晚、更强的高光，一并写出，它是冷开候选；
- 它之前的内容里，哪些是观众必须知道的，可以怎样在开场后补进去；
- 哪些是原著读者需要、短剧观众不需要的。

抽样里没有这样的一处时，写「抽样内未见可用的开篇替换点」，并列进第 5 段的风险。
全量拆解后，S3 的爽点表会给出完整排名，S5 回填时拿它对照这里的判断。

## 结论限于抽样范围

`改编价值快评卡` 第一行写覆盖率，用实际已读样本数与当前索引章数计算，注明该索引是否覆盖全书：

```markdown
> 本快评基于抽样：读了 340 章中的 12 章（3.5%），章号见下表。结论是假设，不是结论。
```

三条：

- **只用读过的章做证据**。 需要提到抽样外的内容时写「抽样未覆盖」。
- **比例的分母是抽样章数**，在文里写出来。
- **候选集条目是 S5 的产物**，快评给量级即可。

## 停靠与交接

快评写完后向创作者报告：覆盖率、六段结论、全量拆解需要的章节范围与分批方式、
以及一句直给的建议（值得拆 / 不值得拆 / 拆但先砍掉某几卷）。

用户只请求快评时到此完成；继续拆解未获授权时说明下一步所需范围。进度卡写实际样本、产出版本和「下一步：逐章提取」。用户已经要求全量拆解时继续，不重复确认。

创作者一开始就说「一次跑完」时不停靠，`改编价值快评卡` 仍然要写——S5 要拿全量结果回填对照它。
