# 原著分析与章节卡片

把实际读到的原文变成可追溯的功能分析。先按需读取 [卡片工作流](references/agenvas-cards.md) 和 [卡片模板](assets/card-templates.md)。所有产出是画布文字卡，原文保持只读。

## 入口

只有书名时需要原文文字卡；只有文件路径时需要用户把内容放进卡片并绑定。原文足够时立即处理当前范围。已有分析时先读章节索引卡、进度卡和本轮分析卡，检查它们指向的原文版本，再从缺项继续。

## S0：章节索引卡

读取完整可用的原文卡。为每章分配跨卷唯一 sequence，保留原章节标题、卷/原文章号、源 artifactId、versionId 及该正文的起止行。原章号重复不等于 sequence 重复。索引记录来源集合与范围状态「全书已提供/仅提供部分」。不把目录条目当正文，不按摘要重建原文章界。

逐项核对顺序、重号、跳号、空章、边界重叠与未覆盖范围。无法判断的边界写进问题栏，先处理明确范围；需要用户裁定时展示候选。不能把未提供章节计入总数。没有标题时与用户约定按段落/场次划分，使用同一份索引供后续引用。

使用 create_text 保存《原著章节索引》和《原著分析进度》，将实际工具结果版本记录到后续卡片。更新索引以新内容版本保存，不覆盖旧索引的来源。

## S1：改编价值快评卡

按 [快评方法](references/adaptation-triage.md) 从索引确定抽样章号，实际读取所选原文，写《改编价值快评》。开头说明已读 N/M、样本序号和来源版本；M 是当前索引范围，不自动等于全书。快评包含框架、可拍/需换载体/文字专属比例、开篇候选、制作负担、三处风险、分集量级。

只请求快评时到此完成。用户已要求全量拆解时继续 S2；快评不替代全文分析，也不自动改变用户原先授权的范围。

## S2：逐章分析与覆盖检查卡

每章保存《原著分析 ch-N · 原章标题》，明确索引版本、sequence 和原文固定版本/行范围。按 [逐章提取](references/chapter-extraction.md) 写概要、带来源的情节点、载体记录、出场称谓、未决项。

每批完成后，读取本批实际保存的分析卡，逐项对照索引，保存或修订《原著分析覆盖检查》，将来源和分析卡的真实 artifactId/versionId 写进表格：

- 已完成：sequence 属于索引，来源版本/范围一致，正文内容及必需栏已经核对。
- 缺章：索引里要求处理、尚无分析卡的 sequence。
- 重复：同一 sequence 出现多个分析版本但未指明采用哪个；保留两个引用，等待明确选用。
- 来源变化：分析引用了另一原文或索引版本，不能用于当前版本的完整性判断。
- 未核对：只有进度记录或预览，没有读到实际分析全文；不能计入已验证完成。

这是 Agent 基于实际读取内容的核对报告，不声称系统执行了自动校验器。完成率用已核对的不同 sequence / 当前明确的索引章数计算，列出分子、分母和检查范围。部分原文、未读卡、失败章都必须显式展示；缺项尚存时只能产出标明范围的部分聚合。

本批结束更新进度卡：阶段、范围、已保存分析版本、缺失/失败/未核对、下一批序号。保存失败的章不记完成。无需一次创建全书卡片。

## S3–S5：聚合与交接

读取已核对分析卡，按 [聚合与实体](references/aggregation-and-entities.md) 产出《剧情单元》《节奏与情绪》《人物归并候选》《世界设定》。硬事实回到原文或情节点，无法证实写未明确；人物归并是候选，不能冒充视觉资产。

按 [改编价值](references/adaptation-value.md) 写《改编价值与分集候选》，按收益分布、局部结果和交接状态切集，不平均分章；对照最初快评，说明哪些判断被新材料推翻。每份聚合开头记录实际覆盖和缺项，保存真实来源卡引用。

交付当前阶段的卡片及实际范围。故事开发仅在本轮选择且用户需要时接续；审查同理。人物、情节或改编方向仍由创作者决定。规则与责任见 [阶段契约](references/stage-contract.md)。
