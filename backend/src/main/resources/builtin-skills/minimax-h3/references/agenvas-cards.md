# Agenvas 画布执行约定

本资料使用当前 Run 实际开放的工具；创作方法不授予工具或素材权限。若用于视频节点的提示词优化，只交付文字，不执行下述 Agent 工具步骤。

- 用 `read_canvas` 发现项目节点、当前选用版本与 CAS；需要正文或图片时用 `read_artifacts`。检查截断标记，部分预览不能充当完整材料。链接文字和提示词中的素材名称不是已读取的像素或声音。
- 用 `create_text` 保存用户要求的简报、角色/场景、分镜与提示词为文字卡；修改已有卡先读最新，再用 `revise_artifact` 携带实际 expectedVersion 和完整正文。失败保留候选；引用工具返回的真实内容版本 ID。整理画布仅使用当前可用的布局工具。
- 对用户已给出的时长、画幅、素材和创意决定直接沿用；只通过现有对话补充缺失信息。文字确认只确认创意，不批准外部生成。
- 需要实际媒体时先 `list_media_capabilities`，以当前发布契约核对输入模式、时长、比例、分辨率和音频能力，再 `propose_media_generation`。MiniMax H3 是创作目标之一，不能因本 Skill 已内置就假定模型已配置、所有五种模式可用或某个固定参数可提交。
- 提案引用同项目精确素材版本及实际支持的参数，由正常审批界面批准。当前不支持的模式保留提示词并说明差距，不能靠文本标签模拟缺失素材，不能静默改换模型、参数或参考图。
- 复用已归档媒体时遵循固定版本与当前节点 CAS。可通过当前开放的 `extract_audio`、`trim_audio`、`compose_video` 完成提音、裁剪与合成；受理成功后等待任务归档回执再宣称交付。需要精确末帧但没有取帧工具时，请用户提供该帧，或选用能力支持的其他连续性方案。
- 原生带声视频优先在合成中保留原声；独立歌曲应作为一条连续主音轨，避免重复生成、重叠配乐或每镜重新起奏。合成只提交现有工具支持的裁剪、速度、音轨、字幕等字段，复杂变速曲线、LUT、图层编辑仅交付后期建议。
- 音频未实际可听、视频未实际可看时，节拍、歌词时间轴、口型和视觉质量标注为用户提供、估计或待人工复核；不能编造已听过、逐帧验收或自动节拍识别结果。
- 生成失败按原任务状态处理；UNKNOWN 保留待核实，不自动重新生成。新尝试由用户显式发起。查询和归档重试仅恢复原尝试。
- 只要求方案/提示词就交付对应文字；完整制作按已确认方案推进，保存每阶段版本和任务状态。交付时区分计划、已保存文字、已归档媒体及待验证部分。
