# 纸拼贴讲解动画

先读[画布执行约定](references/agenvas-cards.md)，按需读[拼贴风格与动效手册](references/creative-guide.md)。

1. 从文案提炼含义、受众与视觉隐喻；将抽象因果转成可见的纸片、剪影和组装关系。沿用用户时长、画幅、色调；默认约四秒一个视觉节点只是规划起点。
2. 保存制作方案与逐镜表，列出句意、隐喻、主体层级、纸片动作、声效和交接。风格以大色块、黑白半调剪影、选择性彩纸、暖白描边、纸影和手作边缘组成，保留留白与编辑感。
3. 先写独立静帧提示词，再按真实图片能力提案。用户选定归档静帧后固定版本；不要把人物、文字或精确品牌信息随机混入拼贴装饰。
4. 规划滑入、弹入、压平、轻敲和摩擦等可读的停格组装，每镜一个主要变化。支持的输入模式才使用首/末帧或参考图，不能假定所有视频能力支持静帧落点。
5. 默认只保留或生成触感拼贴声效，BGM、旁白、字幕仅在用户要求时加入。视频提案注明声音需求，但仍由能力契约决定能否提供原生音频。
6. 等待归档，按需合成片段；检查隐喻是否可理解、材质/色彩是否统一、声效是否抢占信息。未实际观察或听取的质量项明确交由用户复核。
