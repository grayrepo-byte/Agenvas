# 品牌宣传短片

先读[画布执行约定](references/agenvas-cards.md)，创作前按需读[品牌叙事与节拍手册](references/creative-guide.md)。

1. 整理 LOGO、产品图/截图、字体/色彩、功能事实、受众、投放场景、画幅、时长和内容语言。用户素材可用于前期方案，不反复索要已经提供的材料；已有明确水印或来源冲突时指出具体问题。
2. 建立品牌事实表和来源清单，记录精确项目版本、来源类别、用户说明及已核验/未核验状态。当前工具不能浏览网页时请用户提供必要页面内容，不把 URL 当成已读来源。产品主张与已证实事实分开。
3. 在 AI/SaaS 的意图→能力→输出→证明、实体产品的展示→交互→细节→结果、服务的背景→过程→成果中选择适合的叙事。LOGO、真实界面与包装优先复用原件，概念场景明确标注。
4. 编写时间轴，每拍包含时间范围、真实资产、主动作、产品证明、文案停留、色彩和转场。15 秒可用 5–8 拍；围绕产品动作和几何关系设计强弱节奏，避免无依据指标和纯装饰界面。
5. 将事实表、来源、分镜、CTA 和音频方案保存为文字卡。创意确认后发现实际能力、提出媒体审批；口头认可不替代系统批准。
6. 原生带声视频可覆盖纯音乐和界面音效；只有需要可控旁白或独立可替换音乐时才单独准备音轨，避免重复声轨。按已归档精确片段合成。
7. 交付实际文字/媒体及来源摘要，检查产品称谓、画幅、时长、文案与品牌安全空间；未观察到的视频效果标明待用户复核。
