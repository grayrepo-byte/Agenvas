# 双人游戏开场

先读[画布执行约定](references/agenvas-cards.md)。本 Skill 制作游戏开场视觉，不创建可玩游戏。

1. 沿用或确认两位玩家名、游戏名、画风与角色图；参考图只锁身份锚点，按用户选择重绘视觉风格。没有照片时依据文字设定，不虚构已观察到的脸部特征。
2. 按[首图模板](references/h3-confirmation-image-template.md)设计风格与色彩联动的 16:9 双人菜单：中央角色、左上玩家信息、右侧统一宽高单行按钮、Continue 视觉焦点、最多五种主色、简洁背景与安全空间。
3. 将首图提示词保存为文字卡，发现适合的图片能力并提案审批。等待真实图片归档与用户选定后再进入视频；改名、换风格或换角色时更新方案并等待新图，不能沿用已经被否决的候选。
4. 按[视频时间轴模板](references/h3-video-prompt-template.md)回填已确认角色、名字、菜单文案与图片精确版本。默认 0–2 秒主菜单、2–4 秒玩家一、4–7 秒玩家二、7–8.5 秒共同确认、8.5–10 秒加载、10–15 秒进入世界；实际时长随用户需求及能力契约调整。
5. 文字、UI 和角色身份保持跨镜一致；提出视频媒体审批，不把首图的创意认可当作生成批准。检查菜单单行可读、人物左右不串位、光色与动作接续；只交付已归档媒体，未观察到的效果标为待复核。
