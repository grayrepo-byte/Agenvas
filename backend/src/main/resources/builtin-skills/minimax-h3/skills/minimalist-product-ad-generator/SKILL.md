# 极简产品广告

先读[画布执行约定](references/agenvas-cards.md)，制作产品专属的简报、锚点与节拍表。具体创作规则见[产品广告手册](references/creative-guide.md)。

1. 检查用户提供的产品图，确认主推款、真实颜色与材质、可展示结构、目标时长/画幅、白色科技或黑底轮廓光方向和文案语言。已有信息直接沿用；概念卖点与可核实功能分开。
2. 选择产品发布、功能触感或色彩家族叙事。每拍一个主动作，以开合、旋转、边缘高光或真实结构驱动转场；白色背景保持留白，避免镜面台面、产品墙与无意义科技装饰。
3. 上游默认使用简洁英文产品片文案；用户指定的语言和原文优先。单行、同一时间一条，默认 3–5 个词；两段文字轻微位移/淡入，强调色取自真实产品，留出可读停留。
4. 规划三张独立锚定图：主视觉、材质/功能细节、结尾文案。保持产品本色与统一光影，分别生成，避免三宫格被误当最终视频构图。需要生成时逐批提出审批。
5. 保存精确节拍文字表：时间、画面/动作、文字、文字进入方式、声音/转场；记录主推款与素材精确版本。生成视频前读回核对完整表。
6. 按实际能力将素材、文案和节拍组织成视频提案。默认优先合适的原生音频；用户需要独立可替换音乐时才另行规划音轨，不硬编码某个音乐型号。
7. 等待归档后交付媒体；产品颜色、文案准确性、节奏和真实结构保留列为验收项。未观察到的效果交由用户复核，失败不自动重生成。
