# 3D 动画短片

先读[画布执行约定](references/agenvas-cards.md)。沿故事→角色/场景→镜头表→分镜→媒体的顺序推进；用户已明确的参数不重复询问。

1. 固定主题、受众、总时长、画幅、对白语言和情绪走向，写一份简报与故事大纲。开头建立钩子，中间有行动和转折，结尾有情绪回报；避免只有美术没有因果。
2. 按[视觉与角色场景手册](references/visual-guide.md)锁定身份、服饰、比例、道具、关键地标和光线。默认电影感 3D 卡通、清楚剪影、温润材质与有预备动作的弹性表演；用户选择的其他风格优先。场景卡无人物，角色卡与场景卡分别管理。
3. 读取[六列镜头表](references/shot-table-spec.md)，保存文字表：镜号/时长、连续性交接、空间与身份锚点、钩子、逐秒指令、音频/对白。逐秒覆盖动作、机位、位置、声音和下一状态。单镜不超实际能力上限，创作上优先不超过 15 秒、至多三个重要角色。
4. 自检所有时段无缺口、前后状态相容、离场角色有去向、地标与光线继承、对白与嘴部动作一致。任何未验证项保留说明，修订后再推进。
5. 按[文字分镜手册](references/storyboard-guidelines.md)制作一份逐镜文档，包含时间、姿态表情、机位、音频/锚点和前后交接。用户要求可视化时才另提铅笔分镜图；分镜格线、镜号和绑定标记仅供审阅，不能混进最终生成画面。
6. 发现实际视频能力，按镜头状态和素材契约准备提案。已选用的人物/场景参考使用精确版本；图像审批后再固定用于视频，不能把规划中的图片当作已存在输入。
7. 归档各镜后以 `compose_video` 按顺序合成，优先 KEEP 所需原声；只有用户要求时添加独立音乐/配音。交付影片和仍需人工检查的角色、空间、节奏、口型与接缝清单。
