# 手绘与实拍融合

先读[画布执行约定](references/agenvas-cards.md)，写作时读[手绘时间轴手册](references/creative-guide.md)。先交付用户主语言的提示词；只要提示词时不生成中间媒体。

1. 默认规划 15 秒、16:9 的单空间或相邻空间连续镜头，用户明确指定的时长与画幅优先。选择新的生活场景、初始手绘形态、核心色、变形链、接触方式、追逐路线和温柔结尾。
2. 0–3 秒明确接触真实手或物体；3–6、6–10、10–13 秒分别增加可追踪的变形/移动/惊喜；13–15 秒将同一实体的线条扩散成空间级变化，留下可爱回报。时长改变时同比调整节奏。
3. 每个新形态保留之前的线、尾部、色彩或母题，摄影者伸手、追赶或接住；手机镜头有意慢半拍跟随，避免稳定居中的展示镜头。
4. 画风为蜡笔/粉笔/彩铅的粗糙边缘、轻微抖线与逐帧重画感，保持温柔日常调性；去掉光滑 CG、均匀霓虹、恐怖解剖和突然跳吓。
5. 输出顺序：时长/画幅/空间开头句→实拍质感→五段时间轴→手绘质感→相机跟随→排除项→环境音。对白或固定品牌名按用户原文保留。
6. 用户要求保存则创建文字卡。需要实际生成时核对已发布能力是否支持目标规格，再提出媒体审批；不能因为用户认可 prompt 就跳过系统审批。
7. 交付实际结果，标注接触、变形连续性、镜头延迟和材质的待复核项；没有视觉回执时不声称已验证。
