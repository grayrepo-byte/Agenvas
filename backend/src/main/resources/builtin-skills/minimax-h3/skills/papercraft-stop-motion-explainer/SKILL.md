# 纸艺定格科普

先读[画布执行约定](references/agenvas-cards.md)，完整方案按需读[纸艺制作手册](references/creative-guide.md)。

1. 确认主题、核心知识、受众、目标时长与交付范围。区分已核实的知识与创作隐喻；用户只要单图、提示词或某段分镜时直接完成对应切片。
2. 提出少量方向，确定纸质、颜色、光线和隐喻。强调前景遮挡、中景信息、背景视差及纸层投影，避免平面贴图或光滑塑料卡通。
3. 分别规划纸偶角色、无人物场景、分层布景和道具：折痕、纸边、关节、支撑、活动方式和统一比例要可见。知识对象的变化应能由纸艺机制表达。
4. 先写 1–3 张视觉预览及单图/系列图提示词，再按用户要求提出图片审批；选定实际版本后形成图生视频方案，单镜时长以实际能力为准。
5. 将学习目标、逐镜时间、图像提示词、纸片动作、机位、转场、声音和知识结论保存为完整文字卡。优先用展开、翻页、滑轨、旋转、替换纸片等连续机制表达变化。
6. 声音可包含纸摩擦、轻敲、折叠或用户需要的旁白；旁白文本先确认。生成与合成沿用能力发现、审批和任务归档，只使用实际可用的音频与字幕参数。
7. 检查纸质/层次、角色身份、信息准确性、镜头节奏和声音关系；输出实际归档结果与待人工复核项。模型提示词中的要求不等于媒体已经达到效果。
