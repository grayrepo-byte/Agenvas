# 深色摄影棚工作台实施计划

**目标**：实现已经批准的深色摄影棚视觉，默认提示词提供三行编辑空间；沿用既有独立生图任务链。

**设计依据**：用户选定的深色桌面视觉稿与三行输入修订。根线程已经直接检查原稿，并明确授权在共享图跨机器不可读时，按其提供的 1487×1058 原稿测量规范继续实现，最终由根线程持原稿做图对图验收。原 Mock 截图不作为目标，不再要求设计审批或更改网络权限。

**技术边界**：只改 Studio 前端、对应路由布局、四语言资源与验收夹具；复用现有 shadcn、TanStack Query、Zustand 和私有资产接口。不改后端、Provider、数据库、API 合约、原画布、登录或其他页面的导航偏好。不触发付费模型，不推送、不建 PR、不合并或发布。

## 审阅重点

- 轮询追加或重排结果时，以不可变内容版本识别主动选择，避免跳回第一张。
- 当前批次历史缩略图与主图对应；跨批历史与同批变体有清楚区别。
- 浏览历史不覆盖草稿，显式复用才回填，复用不提交任务。
- 排队、失败、部分成功、归档恢复与 UNKNOWN 保留真实状态；没有图片时不显示虚构结果。
- 三行及长提示词、竖图、宽屏、窄屏、键盘焦点与短窗口均不遮挡主要操作。
- 中文输入法用 Enter 确认候选后仍可正常换行，内容保留，只有点击生成提交一次；手机键盘弹起后生成按钮可见或可滚动到达。composition/键盘及缩小视口模拟与真实设备验证分开报告。
