# 生图工作区调整计划

设计依据：[image-studio-design.md](image-studio-design.md)。用户已选定 Firefly 工作区方向，无需再次选择。

## 全局约束

保留现有六个提交与无画布功能。只调整工作台前端、窄范围 PageShell 路由布局、对应测试与文档；不改后端、契约、Provider、原画布或权限。既有不可变受理命令、UNKNOWN 行为、模型能力校验、固定版本参考图、私有预览下载和草稿语义继续有效。不调用付费模型。本轮不推送、不改凭据、不创建 PR、不合并或发布。Git author/committer 使用 grayrepo-byte。

## Task 1: 重排工作区并保护交互

先在工作台组件测试中补充失败用例：历史收起/恢复、缩略图与无图状态、切换历史保留草稿、显式回填、按需高级设置。再调整 ImageStudioPage 与局部 CSS，必要时给 PageShell 增加仅限此路由的布局标记。中央图区占主要空间，底部复合 composer 不遮挡，右侧历史桌面可收起、手机为无障碍抽屉。提示词与附件整合，模型及能力参数紧凑呈现，生成按钮醒目。移除重复摘要、大页头、旧双栏表单内滚和装饰空格。单图与多图完整保留比例。维护四语言与现有可靠状态逻辑。

运行工作台和 PageShell 组件测试、typecheck、lint、格式及构建。独立审阅差异，修正实际问题。

## Task 2: 浏览器与视觉验证

更新现有隔离 fixture 浏览器检查，覆盖宽屏、窄屏和短横屏及四语言；断言主图区、composer、历史不覆盖、抽屉焦点/关闭、单图和多图比例、上传、显式受理重试、历史选择和回填、私有下载。对照官方来源与旧图进行视觉检查。尽可能用隔离 Mock 后端和独立 PostgreSQL 走提交到下载及刷新恢复短链路，验证零画布节点写入。截图明确标注模拟生成，保存于仓库外私有目录。

## Task 3: 审阅和文件交付

独立审阅最终前端改动并保留新鲜验证记录。按 grayrepo-byte 身份分批提交，不重写旧提交。确认后端、契约、Provider、画布与权限差异为零。以 f508330ea1b87d6a20c33264139c89994aa55a3a 为唯一前置条件创建仅含 feat/image-studio ref 的 thin bundle，执行 verify、list-heads、隔离导入，记录 base/HEAD/tree/SHA-256。通过 Library 官方单文件流程私有上传桌面截图与 bundle，读回名称和大小确认交付。
