# ADR 0033：MVP 完成后进入持续迭代

状态：接受（2026-10-04，用户确认 MVP 已完成，不再需要 MVP 阶段约束）。

## 决策

后续开发按当前用户需求推进。原 MVP 的首版范围、P0/P1/P2 分级、阶段排期和以控制首版规模为目的的技术禁止清单不再限制新任务。

现有架构、业务行为与安全规则继续作为实施依据；具体变更按实际需求评估，并同步相关规格、合约和决策。解除阶段限制本身不改变代码中的权限、审批、版本、任务恢复或部署行为。

## 后果

- `AGENTS.md` 保留长期工程约束与按需阅读入口，不以历史 MVP 范围否决扩展。
- `MVP-SPEC.md` 保留原文件名，提供历史设计基线与后续功能修订；旧范围清单和阶段标签按历史上下文理解。
- 开发清单保留实际实施与验证记录，不再规定后续阶段顺序；不会因阶段完成批量勾选未完成或未验证项目。
- 架构与依赖调整按实际需求评估；API 和模型变更按实际使用、兼容及数据迁移需求处理，不默认应用仍未发布。
- MVP 完成是用户确认的产品阶段状态，不替代具体真实 Provider、性能、部署或发布验证的证据。
