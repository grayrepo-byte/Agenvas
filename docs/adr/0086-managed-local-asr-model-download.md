# ADR 0086：可选托管语音模型与持久下载

状态：接受。

用户明确要求可配置本地识别，在界面启用并主动下载到 Docker 卷。本决定更新 ADR 0085 中“应用不下载”的产品边界；默认仍关闭，启用与下载是两个独立动作。此次实现授权不包含在开发机实际安装外部软件、下载模型、构建新镜像或重启服务，这些验收须另获授权。

## 决定

复用现有单体、Session/CSRF 与 ADMIN 权限，通用设置页管理安装级授权和固定模型下载。V62 的单例状态保存 enabled、CAS 版本、下载操作身份、字节进度、租约和安全错误码；数据库是真相。只有显式下载命令创建 QUEUED，启用、GET、本地检查、页面重开或失败轮询均不创建下载。取消、关闭功能、完成发布通过短数据库事务串行化；迟到执行器不能覆盖取消或新尝试。识别仍使用既有固定媒体版本 Task 和字幕校正闭环。

选择在服务器镜像中编译固定 whisper.cpp v1.9.5、提交 `d1be6fde11ac6e0407606b4e42fe72d34add8037`，采用目标 Linux 架构的可移植 CPU 构建，关闭本机专用指令、GPU、OpenMP、服务器和隐式模型下载。初稿曾暂选1.8.3，但没有实际引擎验收支持降级；最终核对官方1.9.5发布和CLI仍包含现有参数后，沿用已讨论的1.9.5并固定提交。这不构成引擎/模型实测或未来自动升级承诺。引擎及其许可证在只读镜像中，模型和下载暂存放独立 `asr-models:/opt/agenvas/asr` 卷。容器不会使用 Mac 二进制或启动外部模型服务。

默认托管目录只有一个经审查的 Tiny 多语言 Q5_1 模型：官方维护者仓库 `ggerganov/whisper.cpp` 的固定修订 `f281eb45af861ab5e5297d23694b7d46e090c02c`，`ggml-tiny-q5_1.bin`，32,152,673 字节，SHA-256 `818710568da3ca15689e31a743197b520007872ff9576237bda97bd1b469c3d7`。使用 Tiny 是为当前1536 MB/2 CPU给出较保守的起点；中文、口音和音乐/静音识别可能较差。当前没有 Base 中文实测，模型较小不能证明识别质量或容器内存足够。托管其他模型需要新增固定来源、校验和及资源边界并单独验收，不接受界面任意 URL。部署者仍可通过手动模式配置其他本地模型。

下载复用现有 `agenvas.public-download` 的 DIRECT/HTTP/HTTPS/SOCKS5 及可选 DoH 配置，允许部署者接入 Clash；不继承 Provider 凭据、Cookie 或调试正文捕获。起始下载地址固定在编译目录中，重定向沿用ADR 0079的HTTP(S)格式和无凭据规则，不重新引入域名、端口或DNS/IP准入名单，支持代理Fake-IP；最后仍须精确字节数和SHA-256匹配。连接最长10秒，读等待3秒，整体30分钟，无隐式 HTTP 重试；取消在连接/读期限及每块/重定向边界响应。

下载只用一个有界执行线程和数据库认领；卷文件锁防止多个实例同时写。目录0700、文件0600，暂存与目标同卷；精确大小与SHA-256通过后，才在持有操作fence的短事务内原子替换目标。保留原有完整模型，失败/取消清理本次暂存。启动后的工作器使过期下载租约进入 INTERRUPTED，不自动续传或重试，用户可显式检查已经完整发布的文件或重新下载；已明确受理但尚未认领的QUEUED仍可执行。磁盘须保留128MiB余量，加上已有模型和单个32MB暂存；不能根据文件名或部分字节宣布就绪。

MANAGED 模式严格检查ELF位数、字节序和目标机器类型，macOS或架构错误的二进制不能宣布可用。原生exec启动器限制512MiB虚拟地址空间和1200秒CPU时间，进程身份不经shell分叉；这只是失败边界，仍需真实模型测量。识别受理和执行前检查Linux cgroup已用内存、512MiB进程预算与128MiB余量；无法读取或不足时拒绝启动，执行时接近64MiB余量则停止。保持Compose1536MB/2CPU，无自动调高限制。其他应用任务仍会竞争资源，不能承诺不会触发整容器OOM。

AUTO 模式按模型路径判断是否使用托管模型；部署者明确设置 MANUAL 时完全不下载或覆盖其模型。手动模式沿用既有绝对路径原生引擎、超时、取消和单并发，不强制Linux/cgroup或Tiny校验；模型来源、格式、许可证、兼容和资源由部署者负责。升级后安装级开关默认关闭，需要管理员明确启用一次。UI清楚区分手动与托管，不把自配模型显示成Tiny或已核验MIT。
