# ADR 0047：项目导演聊天窗口与画布操作范围

用户要求取消节点形式的 Agent，改为右下角聊天弹窗，并能操作当前画布全部节点。AgentInstance 作为项目内名称、创作系统提示词、Skill、会话与运行的稳定身份保留；聊天窗口独立于画布缩放，支持切换助手、收起、展开、历史与设置。收起不取消任务，也不丢弃草稿。首次用户打开入口时先恢复已有助手，无实例才幂等创建默认导演；创建配置不调用模型。画布创建、资源恢复和音频对话入口均不再放置 Agent 节点。

新 Run 固定发送时当前画布的文字、图片、视频和音频节点范围，使用系统协议版本 12、工具策略版本 4 与 `canvasScope.version=1`。授权节点 ID 与原精确内容引用固定，目录按页返回这些节点的当前标题、布局、锁定、选用版本及操作 CAS；已删除节点消失，之后用户新建节点不自动入域。本 Run 新产物与已提交工具创建的节点可继续访问。当前选用版本若不属于原引用、显式 Skill 输入或本 Run，`selectedVersionReadable=false` 并保留 `frozenSelectedVersionId`，显示元数据不授予新正文或像素读取权。目录默认只返回元数据与草稿版本/数量；完整媒体草稿显式按需小批读取，正文和图片也按需读取，初始请求不内联整张画布内容。当前选择最多 1000 项，表达任务重点；Skill 必需输入由用户从当前画布明确映射到精确版本，本次选择不写入助手长期素材绑定。工具可以在授权范围及本次运行新产物内按权限读取、修订文字、整理布局、管理节点和修改媒体草稿；布局使用节点权限及最新 CAS/当前选用版本，文字修订仍要求冻结的原精确内容版本和 Artifact CAS；跨项目引用、锁定、任务占用及内容/布局/草稿 CAS 由服务端检查。媒体生成仍先形成固定批次，用户批准后才能受理付费任务；对已有媒体节点生成追加不可变版本，拒绝不能移除既有节点。

助手的“查看产物”通过 `GET /api/v1/projects/{projectId}/agents/{agentId}/outputs` 查询当前画布节点。服务端以节点当前精确选用版本（文字使用当前内容版本）关联的 Run 归属判断，包含该助手对已有节点生成的结果。移除节点或人工切换为其他来源版本后不再归属；尚未生成的审批草稿仅从审批对话查看，不计入产物数量。产物归属不使用输出组，前端在内容、画布、任务、Run 事件与快照恢复后刷新查询。

V26 完整退休旧模型：删除 `AGENT_IMAGE_INPUT` 关系及 Agent CanvasItem，令剩余 CanvasItem 必须关联 Artifact，关系类型只保留 `MEDIA_INPUT` 与 `MEDIA_DERIVATION`；删除 `agent_binding` 表与 `agent_instance.output_group_id`。Agent 创建/更新和画布 API 同时移除旧绑定、输出组及 Agent 节点字段，并规范化历史创建助手的幂等响应 DTO。仅未修改的安装内置导演预设升级到当前画布措辞，用户自定义预设和实例指令不改写。AgentInstance、Skill 绑定、会话、Run、Task、审批和内容版本继续保留。迁移在项目行锁下连续递增 `event_seq`，为每个助手写一条 `agent.instance.changed`，并为每个受影响项目写一条 `canvas.items.changed`，让升级后的 SSE 补发刷新旧拓扑和助手配置。升级前备份数据库，迁移、后端、OpenAPI 及生成前端类型须同批部署；迁移后旧版后端不兼容，回退须恢复迁移前备份。

代价是新旧 Run 具有不同授权范围。历史 Run 的冻结 `bindings`、`outputGroupId`、工具策略和检查点 JSON 不改写，恢复继续按原协议验证旧输入与原输出范围；无 `canvasScope` 的历史 Run 仍以冻结旧 group 标签处理放置恢复，不查询助手配置或旧坐标。新 Run 的节点 group 为空，不能从当前画布或新协议向旧运行授予额外权限。退役的是助手长期配置与画布拓扑，历史执行审计和恢复仍保留。选择数据迁移而非隐藏旧节点，避免两套可变输入/输出归属继续影响新执行；代价是旧绑定配置不再供后续新 Run 复用，若需恢复旧绑定配置，应从迁移前的数据库备份读取。
