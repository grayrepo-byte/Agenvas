# ADR 0059：画布分组与有界编辑撤销

状态：接受，按用户要求完善大画布的命名/折叠分组、复制与撤销/重做。实际验证范围见开发清单。

已有 groupId 只是布局标签，复制只有单个媒体节点，画布没有编辑历史。增加项目持久画布分组和统一画布编辑应用服务，保留成员的绝对坐标。分组支持名称、折叠、成员调整、整体移动、复制与解组；分组不成为 Artifact，不形成执行 DAG，也不隐式取得生成授权。V39 无损补齐既有标签的默认组资料，旧节点、草稿、选用结果和坐标保持。

展开时组框由成员的当前展示尺寸与布局草稿投影；折叠只隐藏展示，保留编辑器挂载及未保存文字。内部关系线隐藏，外部关系映射到组端点，仍保留原持久连接身份。组拖动保存全部成员的布局；成员含锁定节点时整批拒绝几何/成员修改，名称和折叠状态仍可修改。分组不嵌套，单次新编辑或复制最多 100 个节点；已有超大组可保留和逐步整理，不因回填上限锁死无关编辑。

多选/组复制在单个短事务中建立独立目标。文字创建独立 Artifact；媒体只继承当前固定选用、完整草稿和已应用角色快照，参考转为新的手动来源，不复制历史、任务或连线。复制前前端等待相关编辑器已确认保存，失败保留原编辑并停止复制。当前项目的会话剪贴板固定复制时的来源版本，来源变化后要求重新复制；重复或响应丢失的受理请求按持久命令身份重放。

撤销/重做覆盖本次编辑会话中已确认的布局、标题、锁定、分组及复制。前端保存最多 50 项回执顺序，服务器保留最近 100 份编辑快照，并永久保留项目内紧凑命令指纹以识别迟到重试；回执过期返回明确冲突，不将旧命令重新执行。展示编辑按当前语义前提与项目锁内 CAS 补偿，允许同节点连续多步撤销，保留最新媒体选用、正文、草稿与运行状态。新的已确认编辑清空当前会话的重做栈。刷新后不承诺恢复原会话历史。

复制的撤销需要更严格的前提：目标的内容、草稿、选用、角色、拓扑及后续任务/审批/分镜使用均未改变。任一后续工作使撤销冲突，不能通过删除副本丢失用户的新工作。重做使用首次冻结的目标内容，不读取实时来源；恢复后的节点、草稿、文字聚合与角色版本推进，拒绝旧请求覆盖。专用拓扑 epoch 记录连接建立/断开，包括恢复为空的情况；它独立于展示和结果选择 epoch，避免布局或连接保护误伤生成选用。

现有物理移除会级联清理节点草稿、输入、角色和下游引用，普通连线修改也会更改草稿。因此本次不把它们当作可逆展示命令；界面明确撤销范围。正文历史仍通过不可变版本处理，任务、外部费用及生成授权不参与画布回放。需要完整删除/连线撤销时另行定义带跨对象前提的恢复语义，不能反向摆放节点冒充恢复。

OpenAPI、前后端和数据库须同批升级。分组/编辑变化与项目事件原子提交；SSE 与快照恢复刷新服务器投影。编辑服务使用跨模块应用接口读取复制保护和恢复固定工作状态，Canvas 不直接访问其他模块的 Repository。
