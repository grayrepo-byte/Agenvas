# ADR 0002：优先交付固定媒体适配器

状态：接受（2026-09-25）；RunningHub 暂缓部分由 [ADR 0025](0025-runninghub-versioned-input-contracts.md) 覆盖（2026-10-01），动态脚本禁令保留。

## 背景

现有媒体运行通过全局 Mock/ComfyUI 模式与环境变量配置，计划步骤不能选择不同渠道。曾讨论由 Agent 根据 RunningHub 类平台文档生成 Groovy 脚本、管理员审阅后发布；该路径引入脚本运行、平台协议和恢复语义的额外复杂度。用户决定先放弃该路径，完成常用模型的固定接入。

## 决策

- 保留连接、能力、版本和逐步骤审批的统一媒体层；管理员在界面配置密钥与默认能力，普通用户只选择已发布能力。
- Mock、ComfyUI、OpenAI GPT Image 2 和火山方舟 Seedance 使用项目维护的固定 Java 适配器，共用任务状态机、外部请求检查点、UNKNOWN 与归档规则。首批新增 GPT 图片和 Seedance 首帧图生视频，不进行真实付费测试；本地假服务验收不能标成真实 Provider 成功。
- OpenAI GPT Image 2 连接允许管理员设置自定义 HTTPS API Base URL，留空使用官方 `/v1`。地址随连接版本固定；请求路径和模型协议仍由固定适配器决定，执行时阻止私网 DNS 目标及重定向。（2026-09-25 用户追加决策）
- 不实现 Groovy、动态脚本、Agent 生成调用代码或 RunningHub 类工作流平台接入。将来需要时重新提案和设计；Google Nano Banana 2 等其他渠道按固定协议适配器逐个接入。
- Seedance 能力仅对固定模型映射支持的镜头时长开放；不支持的步骤提示修改时长，不自动取整或生成较长视频后裁剪。

后续 Google Nano Banana 2 的固定适配器决策见 [ADR 0004](0004-google-nano-banana-2-fixed-adapter.md)。

## 后果

新增供应商仍需要编写和测试适配器，但计划、审批与画布使用稳定能力契约，无须增加供应商分支。管理员不能通过填 API 模板接入任意平台；这降低了当前交付范围，也避免把尚未验证的动态代码执行和任意平台兼容性标记为已完成。基础层及首批渠道分别见[媒体能力规格](../superpowers/specs/2026-09-25-media-capability-foundation-design.md)和[固定渠道规格](../superpowers/specs/2026-09-25-fixed-media-provider-adapters-design.md)。

2026-10-01 补充：用户明确要求的 AutoDL ComfyUI 工作流接入采用同一固定 Java 协议与受审查参数声明，局部修订本 ADR 暂不接入工作流平台的范围；不开放任意工作流图、脚本或远程发现。见 [ADR 0024](0024-autodl-comfyui-workflows.md)。

2026-10-02 补充：用户决定区分默认部署与开发 Compose。`deploy/compose.yaml` 的文字和媒体默认使用 `configured`，不启用 Mock；`deploy/compose.dev.yaml` 通过 `extends` 复用三服务并显式启用 Mock。默认项目名分别为 `agenvas` 和 `agenvas-dev`，数据卷按项目名隔离；默认端口相同，并行运行须显式配置不同端口。两版仍要求数据库密码与初始化密钥，保存云凭证还须配置服务端主密钥；部署后由管理员配置真实 LLM、连接与已发布能力。没有真实媒体能力时目录为空，预置 Mock 不能用于新生成。切换模式只影响新生成的能力选择，不删除既有配置、结果或固定任务；已受理任务继续按原能力版本核对和恢复。Mock 保留为可独立运行的开发/测试路径，配置分离不代表真实 Provider 或生产发布已验收。

2026-10-04 补充（按用户进一步确认修订）：根目录 `docker-compose.yml` 固定写明 `docker.io/grayrepo/agenvas-server:latest`、`docker.io/grayrepo/agenvas-web:latest`，直接拉取最新应用镜像；PostgreSQL 在所有入口使用官方固定版本 `postgres:17.11-alpine`，不再自建或发布。`docker-compose.local.yml` 和原 `deploy/compose.yaml` 只构建 server/web，Mock 使用独立 `agenvas-dev` 项目。每份 Compose 自己完整列出所有运行参数，不使用 extends/include 或共享 runtime 文件；部署者可直接决定镜像、端口、卷、环境与资源配置。镜像部署和源码部署保留原 agenvas 持久卷，切换前仍须备份并核对版本兼容。

GitHub CI 在测试及三服务双架构安全扫描通过后，只发布扫描过的应用镜像；2026-10-04 按用户决定收紧发布触发：只有 `v*.*.*` 版本标签推送会把镜像上传 Docker Hub，main 推送与手动运行只构建和扫描。稳定版本标签（无预发布后缀）额外更新 latest，预发布版本仅生成对应版本、不更新 latest，完整提交标签继续用于审计。官方 PostgreSQL 只拉取和扫描，撤销退役派生镜像的 gosu 扫描排除。此决定覆盖此前部署配置隐藏在共享文件、要求镜像标签变量及禁止应用 latest 的方案；公开应用镜像降低部署编译门槛，源码和 Mock 仍可独立自托管。Docker Hub 发布凭据由仓库管理员配置，不成为应用运行所需账户；工作流配置完成不代表远端镜像已发布或生产验收完成。

2026-10-05 CI 修订：用户决定取消源码依赖和容器镜像漏洞检查流程及 HIGH/CRITICAL 发布门禁，覆盖上段要求安全扫描通过后发布的规则。保留源码密钥扫描、server/web 原生双架构构建、官方 PostgreSQL 拉取、三服务各架构 SBOM/许可证清单与测试/Compose/生成代码检查；版本标签发布仍复用同一构建镜像，PR 和 main 不推送。取消漏洞检查不表示此前 Jackson 与 gosu 报告已修复，不新增漏洞忽略规则，也不改变依赖或官方 PostgreSQL 镜像。

2026-10-04 启动简化补充（初始化密钥部分由下一决定覆盖）：用户要求普通部署者无需填写 `.env`，运行参数直接写在 Compose。首次空卷启动自动生成三个独立随机密钥，原子保存至 `credentials-data`；数据库密码与 bootstrap secret 为 32 字节十六进制，凭证主密钥为 32 字节 Base64。PostgreSQL 使用官方镜像的文件密码入口，生成脚本完整内联在各 Compose；server 镜像入口以原非 root 用户读取只读密钥文件后 exec Java。运行和查看初始化密钥各一条命令；不采用各安装共用的固定公开密码/初始化密钥。持久值在重启和更新后保留；缺失旧数据库密钥、部分密钥文件、冲突覆盖或非法导入明确拒绝，不能自动换加密主密钥。密钥卷与数据库/资产备份分开加密保管，恢复先还原匹配的密钥；独立 JVM 保留显式环境配置，此决定覆盖容器部署必填 `.env` 的旧流程。

2026-10-04 一次性初始化进一步简化：用户决定取消初始化密钥，`/setup` 仅填写管理员登录名和密码，以减少分发步骤。完成状态属于安装而非活动账号：管理员插入与数据库安装行的完成时间在同一事务提交，行锁、唯一约束及 CAS 仲裁并发；重启、停用或删除账号都不重新开放，失败事务可重试。V9 回填既有账号的完成状态，前后端及 OpenAPI 同步移除 bootstrap header、配置和输入框；部署只自动生成数据库密码与加密主密钥，保留原值。此决定覆盖先前使用 bootstrap secret 保护首位管理员的约定：先在默认仅绑定本机的入口完成初始化，再开放公网反代；程序只能保证初始化次数，不能验证未初始化安装的首位访问者身份。CSRF、登录鉴权和密码规则继续生效。

2026-10-05 默认端口发布修订：用户要求其他设备可通过服务器 IP 使用默认部署，同时默认关闭 API 与数据库的宿主机端口。根目录 `docker-compose.yml` 仅发布 Web 8088 到 `0.0.0.0`；Web 代理通过容器网络连接 `server:8080`，server 通过容器网络连接 `postgres:5432`，两者不再映射宿主机端口。此决定覆盖上段默认镜像入口仅绑定本机的约定；源码与 Mock Compose 保留三个端口的本机绑定，供开发排查。初始化仍仅接受账号密码并只能成功一次，先在受控网络完成初始化，再开放公网反代；HTTPS、鉴权与凭证规则继续生效。端口映射调整不改变项目名或持久卷，已有部署重新执行 Compose `up` 后应用新映射。

2026-10-04 补充：用户要求自托管 ComfyUI 从固定模型字段改为管理员导入 API JSON、选择节点并映射发布；允许发布实例上已安装节点组成的图，保留固定 HTTP 协议与任务恢复边界。见 [ADR 0030](0030-comfyui-imported-workflow-capabilities.md)；普通用户与 Agent 仍不能提交执行图或脚本。
