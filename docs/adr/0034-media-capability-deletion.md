# ADR 0034：删除媒体能力保留历史版本

状态：接受。管理员需要从能力发布设置中删除不再使用的能力，包括已启用或停用的能力。删除使其退出管理列表与创作者目录，并拒绝再次编辑、启用、选择或用于新运行；内置 LOCAL 能力不可删除。

能力与连接版本被已受理任务固定引用，物理删除会破坏任务恢复与结果来源，因此保留能力行和不可变版本，用删除时间标记其退出目录。已有媒体草稿保留选择及参数，必须换成可用能力才可新建运行；引用清理仍能读取原输入声明。历史结果与已受理任务继续使用冻结版本，删除不会取消任务或触发重新生成。

删除按 expectedVersion/CAS 执行，与默认能力选择、功能绑定和能力编辑共用能力行锁。同一事务清空仍引用该能力的默认选择与功能绑定，并递增各配置版本；其他能力的绑定不变。页面确认窗口固定打开时的版本，失败保留窗口，冲突后须显式载入最新配置再确认。删除没有恢复入口；重新发布创建新身份，原发布幂等键重放不能复活旧能力。

新增 V11 在 V10 基础上追加 nullable deleted_at，不清除现有数据。OpenAPI 增加管理员 DELETE 接口，要求登录、管理员、CSRF 和 expectedVersion；返回删除后的脱敏配置。前后端及迁移一起升级。
