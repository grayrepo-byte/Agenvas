# ADR 0071：Agent 工具与专业协议按需加载

状态：接受（2026-11-04）

## 背景

普通问候也默认携带全部业务工具 Schema、分镜/合成/媒体读取协议和已发布媒体能力摘要。Skill 主文件与附件已经渐进读取，但这不能降低首轮固定工具成本。项目导演正文是用户可编辑的创作配置，不能因优化而摘要、翻译或删除。

## 决定

新 Run 的冻结允许列表包含 `load_toolset`，以此区分按需模式；既有不含此工具的 Run 保持原全量模式。沿用 policy schema 7 / system prompt 14 / tool policy 6 的允许列表扩展方式，无数据库迁移、HTTP/OpenAPI/MCP 变化或依赖升级，不改写历史检查点。

首轮只提供简短的底层权限与执行规则、`load_toolset` 定义、项目说明、导演原文、现有 Skill 名称/描述/固定版本、选择摘要和原有有界公开历史。媒体能力摘要不再提前查询或内联，改用已有 `list_media_capabilities`。导演和用户自定义内容原样保留，Skill 主文件及附件仍按既有规则激活与读取。

不按关键词或另一次模型分类决定工具可用性。模型可一次请求 CANVAS、TEXT、LAYOUT、STORYBOARD、MEDIA、INSPECTION、COMPOSITION、SKILLS 中的多个组，任务变化时继续加载。服务端只返回组内与 Run 冻结允许列表相交的工具；完全不可用的组、未知组、重复组和额外字段拒绝。成功加载后，下一模型请求才加入 Schema 和对应专业协议。已加载工具在该 Run 内保留，不在中途自动卸载。

## 持久化与执行边界

加载是普通持久工具账本操作，无外部请求或业务资源副作用。成功回执来自已提交工具结果；用户消息、模型摘要、私有推理或被拒绝批次不能激活工具。续回合从上一请求恢复既有冻结定义，仅为成功加载的新工具加入定义；旧核心/专业规则保留原文，只追加此次新工具需要的规则。已加载的 Schema 和说明不会因部署变化而被静默替换。

新模式的执行器在新副作用前同时检查 Run 允许列表和该持久请求实际暴露的工具名。加载与首次调用隐藏工具放在同一批时，整批回滚。参数修复保留被拒请求的工具和规则；技术重试、租约重认领恢复原请求；摘要无工具，持久 continuation 保留已加载定义和独立固定规则。加载与已暴露的媒体提案同批提交时，可持久等待审批/归档，恢复后再加入新工具。

加载不授予账号/项目/内容访问、节点写入或媒体审批。现有权限、精确版本、CAS、锁定、取消、UNKNOWN 与认证审批服务继续执行。公开记录为“准备所需能力”，沿用既有四语展示，不暴露工具参数或结果正文。

## 取舍与测量

显式加载增加业务任务首次使用能力前的一个模型/工具回合；多组可一次加载。避免了意图误判造成能力缺失，但不能保证模型会正确选择组；真实模型的任务质量和总费用需要单独实测。复杂任务加载全部工具后，固定成本接近原值，不能把首轮节省比例当作整项任务或账单节省比例。

`InitialContextCostTest` 使用合成项目、3 个 Skill 目录项、8 个合成媒体能力和未修改的 V45 英文导演默认正文。以下为应用内 JTokkit 估算组件，非所选 Provider 的实际 Token 用量：

| 组件 | 全量首轮 | 按需首轮 |
| --- | ---: | ---: |
| 系统规则 | 2,199 | 366 |
| 导演原文 | 1,616 | 1,616 |
| Skill 目录 | 126 | 126 |
| 媒体目录及选择指导 | 565 | 0 |
| 其他消息正文 | 74 | 74 |
| 工具 Schema | 2,787 | 73 |
| 工具名称与说明 | 1,717 | 155 |
| 工具数量 | 21 | 1 |
| 含消息/工具开销和 25% 余量的应用估算 | 11,935 | 3,173 |

此合成首轮减少约 73.4%。仅加载 TEXT 后的固定输入估算为 3,724；全部组加载后为 11,568（均未计后续工具历史与媒体附件）。旧 V38 中文导演正文单独约 4,565，继续保留；自定义正文和历史长度亦不受此优化控制。因此不承诺 4K 模型可用，也不推断截断或 Provider 收费。

## 验证范围

服务级测试覆盖目录与自定义指令保留、全部组可达、按阶段扩展、Schema/规则冻结、重复加载、不可信/拒绝回执、畸形参数、允许列表交集、压缩续接。真实 PostgreSQL 与合成模型验证普通对话无业务动作、正式分镜/文本写入、同批隐藏调用回滚、权限拒绝、超时重试、租约恢复，以及加载与媒体提案同批后等待归档再续接；现有逐张图片、分镜、审批和本地媒体工具回归单列记录。

未进行真实 Provider/小模型质量或付费评估、全量测试及真实进程重启；租约恢复模拟不能代表部署全链路。未推送、合并或部署。验收结果见开发清单。
