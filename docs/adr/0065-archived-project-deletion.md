# ADR 0065：归档项目删除与执行审计保留

状态：接受（2026-10-24）。用户要求在项目管理中删除已归档项目。删除采用不可从界面恢复的逻辑删除：项目及其内容退出用户列表和读取范围，底层不可变版本、素材和执行记录保留，避免直接级联删除丢失已受理外部任务的晚到结果或损坏个人资产。文件物理清理继续遵循引用、活动任务与备份检查，不在删除请求中执行。

项目卡片只为归档项目显示删除入口，确认后发送 `DELETE /projects/{projectId}?expectedVersion=...`。失败保留确认窗口并允许重试；等待期间禁止重复提交。确认期间版本变化要求关闭后重新确认，不替用户删除新版本。服务按认证所有者取得项目行锁，仅允许归档且没有活动 Agent Run 的项目删除；活动运行需先完成或取消。所有者、归档状态和版本的条件更新检查影响行数；首次成功递增版本，同一 expectedVersion 的成功重放返回 204，其他旧版本冲突。

V43 扩展持久状态为 `DELETED`，保留原归档时间，更新时间记录删除时间；不增加公开 ProjectStatus 值，已删除项目不返回 Project DTO。项目列表、全部资源、快照和 SSE 读取排除删除状态；项目 HTTP 入口统一检查可见性，覆盖直接通过所有者查询资源的旧接口。不存在、他人所有与已删除项目的用户读取均返回 404，根删除入口允许已成功命令重放。

已受理媒体任务通过专用应用接口读取保留项目和原 Run 状态，继续归档图片、视频、音频及不可变结果，禁止新提交和自动选用，不重建或激活项目。用户文件读取与新编辑仍使用可见或活动项目校验，内部结果归档接口不能成为用户授权入口。原项目中的结果从“全部资源”移除，已经独立收藏的个人资产保持可用。
