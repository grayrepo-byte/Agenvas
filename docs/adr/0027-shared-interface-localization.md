# ADR 0027：共享页面与请求级界面语言

接受（2026-10-01）。按用户要求，英语、中文、俄语、日语共用现有路由和组件，禁止按语言复制页面。语言是浏览器显示偏好，首次按浏览器语言匹配，之后记住用户选择；不进入项目数据或导出，也不要求外部翻译服务才能运行。切换语言不重挂载页面，不清空创作草稿。

同日按用户对折叠导航的反馈，语言入口改为地球按钮打开四语言选择窗口，所有入口共用该交互，不使用下拉框。桌面展开侧栏显示当前语言名，折叠时只显示图标；手机顶部导航仍显示语言名。选中语言立即切换并关闭窗口；浏览器保存偏好失败时保留窗口，显示失败并允许重试。使用公共模态组件保障键盘操作、背景隔离和焦点恢复，验证见 [交互调整记录](../evidence/language-picker-2026-10-01.md)。

前端以中文源消息作为 gettext 风格消息 ID，集中维护四份本地词典，变量在完整句子中插值，静态显示元数据延迟翻译。后端公开异常携带 `ApiMessage` 资源键与参数，在 HTTP 边界按 `Accept-Language` 协商并使用 Spring MessageSource 渲染完整句子；认证、CSRF、校验、资源转存失败和导入警告使用同一规则。避免按最终中文字符串反查翻译，否则动态字段名与范围会导致匹配失败、丢失具体说明。异步转存将描述保存到现有错误详情列，供之后任意语言的读取者渲染；Worker 不依赖请求 Locale。缺失、不支持或无效的语言回退中文，支持的地区变体归入基础语言。响应使用 `Content-Language` 和 `Vary: Accept-Language`，稳定错误码、权限、状态及字段路径不变。

用户内容、提示词、Provider 参数值、音色 ID 与名称、生成结果及历史审计正文保持原值。公开异常资源键与参数通过编译类型和词典检查约束，不能以通用回退替代已知动态业务说明；只有未知实现异常或无法识别的旧转存详情使用安全通用说明。不把用户或 Provider 返回的自由文本当成翻译模板，也不自动重试任务。契约形状不变，无数据库迁移。开发与资源维护说明见 [i18n 配置](../i18n.md)。
