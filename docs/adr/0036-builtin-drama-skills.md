# ADR 0036：内置 Drama Skills 与 100 个候选

接受（2026-10-06）。用户要求默认绑定与每次运行可选择 100 个 Skill，并将 [zenstory-ai/drama-skills](https://github.com/zenstory-ai/drama-skills) 中有用的创作方法纳入内置目录；后续明确要求移除执行不了的流程，并将脚本/文件操作改为 Agenvas 卡片工作流。继续采用 ADR 0035 的三层加载，提高的是候选上限，不把全部正文或附件发送给模型。

## 创作范围与本地适配

基于上游 0.8.1、commit `c2426e03c0e7722bebcc6a488b6658dc38c65ac3`，保留 [MIT 许可证](https://github.com/zenstory-ai/drama-skills/blob/c2426e03c0e7722bebcc6a488b6658dc38c65ac3/LICENSE) 和来源说明。运行不访问 GitHub、不自动更新。保留原著分析、故事开发、分集剧本、视觉资产设定、图片提示词、分镜与关键帧、视频提示词、创作审查八个 Skill。排除文件系统路由/Dashboard、外部供应商生产与剪辑成片。

发行 `agenvas-canvas-v1` 本地适配版，直接加载重写后的主文件，不再给上游操作指令加一段免责前缀。脚本命令、机器配置和文件系统发布模板不进入模型可见正文或附件；保留创作手艺资料并适配其中的操作约定。每包包含本阶段卡片模板和按需共享的 `references/agenvas-cards.md`。共 112 份附件条目：96 份创作参考、八份卡片模板、八份共享流程引用；实际打包 113 个 Markdown 文件。资源 path 只是受控 Skill 附件地址，不是项目文件。

## 卡片执行流程

读取本 Run 绑定的精确 ArtifactVersion，`read_artifacts` 每次最多 12 个；选择意图、标题或正文里的 UUID 不授予权限。检查 `contentTruncated`，预览不能证明全文索引或全量分析；当前没有原文文件导入或文字分页工具，长输入需用户按章节/场次拆成可读文字卡再绑定。每个来源引用含实际 artifactId、versionId 及该正文的行范围/条目 ID。

用户要求保存时，`create_text` 创建文字产物并自动放到 Agent 输出组；`revise_artifact` 使用实际工具结果中的 expectedVersion/CAS 值及完整正文追加版本。失败或冲突保留候选，不能伪报保存成功或新建同名卡掩盖更新失败。内容与布局独立；来源引用使用 `affectedVersions` 的真实 UUID，不能把 `artifactVersions` 的数字 CAS 当内容版本。跨轮读取用户绑定的进度和来源版本，按 Run 限额分批保存断点。

原著流程为原文输入卡→章节索引卡→逐章分析卡→覆盖检查/进度卡→聚合与分集候选卡。索引固定来源版本、跨卷 sequence 与行范围；覆盖报告核对实际读到的分析版本，分别列出完成、缺章、重复候选、来源变化、未核对和失败。完成率只用已核对的不同 sequence 与当前明确的索引范围计算，部分材料不能冒充全书。报告是 Agent 内容核对，没有新增服务端章节解析器或自动覆盖校验器。旧累计记录未重新读取时必须注明未复核。

多集剧本摄入同样使用剧集索引/规划/进度卡。剧本时长在卡中列出可发声字数、速率和动作假设，声音参考及提示词参考只引用实际媒体版本；不声称已有脚本、成片或音频。媒体生成通过现有能力发现、提案、用户审批和 Task，文本确认不提升权限。只请求创作时完成文字卡，不自动开始生成。

## 不可变历史与发行身份

账号首次浏览时在一个事务中注册只读发布版本，账号与内置 key 唯一约束仲裁并发，版本身份由固定 bundleHash 决定。沿用账号归属、绑定外键、数据库版本、Run 快照及导出。目录可查看和试用；内置不可编辑、复制或回收，没有草稿和媒体字节，无需项目参考安装。

新 key 为 `drama-skills/agenvas-canvas-v1/<name>`，旧上游版注册不改写正文、不追加替换其默认版本、不重定向旧固定绑定。当前 manifest 的 key 控制目录、总数、分页和新选择；旧发行及移除项隐藏，新显式选择/绑定/安装拒绝。原版本、绑定和已受理 Run 仍可读取、恢复、导出。旧发行的 Agent 默认选择需要重新选择当前卡片版；个人同名 Skill 保持个人规则。未来已发行版本的修改须显式决定新版本或新发行，不能静默覆盖。

## 限额与合约

V14 将默认 position 上限改为 99，增加可空 builtin_key 与账号内唯一约束；不改 V13，不删除已有数据。本次卡片适配不增加迁移或 API 字段。内置主文件最多 16,000 字符、每包最多 100 份附件、单附件最多 32,000 字符，工具附件分页仍为 4,000 Unicode 码点。OpenAPI 的 builtin 标记、100 项选择数组和只读发布内容范围与生成 TypeScript/jOOQ 保持同步。导出版本继续为 7，保存完整固定正文、附件和原绑定顺序；不授予新的执行权限。
