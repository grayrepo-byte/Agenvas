# ADR 0085：本地字幕识别、固定来源校正与成片映射

状态：接受。本地引擎与模型安装部分由 [ADR 0086](0086-managed-local-asr-model-download.md) 更新：支持默认关闭、管理员显式触发的托管下载及原有手动部署。

用户要求补齐自动字幕闭环。ADR 0049 的声音活动分析继续只负责配音定位，不能推断实际台词；本决定增加独立的真实语音识别入口，同时保持单人、自托管、明确选择固定媒体版本和无隐式外传的边界。

## 决定

采用部署者配置的本地原生 whisper.cpp CLI 和兼容 GGML 模型。应用不下载、安装、转换模型或启动远端服务，未配置时明确返回不可用状态，手动校正和 SRT/WebVTT 交换仍可独立使用。按绝对路径启动固定二进制与参数数组，第一音轨转换成 16 kHz 单声道 PCM，并保留来源媒体的开头静音。请求语言和模型实际语言能力分开，不把 `auto` 请求值冒充检测结果。

固定来源版本的字幕保存为项目内 `SubtitleDraft`。其时间属于来源媒体，人工校正使用 CAS；每项目、每固定版本复用同一草稿。原始 ASR 结果独立保存在 `SUBTITLE_TRANSCRIPTION` Task 终态输出，校正不修改该输出、原媒体或 ArtifactVersion。V60 增加草稿表和任务类型约束，jOOQ 从一次性 PostgreSQL 生成，不改写既有迁移或数据。

识别由用户明确受理，冻结来源版本、Asset、时长、语言和待应用草稿版本，使用项目范围命令键幂等。专用单槽执行器复用既有 Task 的持久认领、租约、epoch、心跳、取消和事件。所有耗时解码/推理在事务外执行；过期本地推理可重新认领，不产生第三方重复提交或费用。旧 epoch 写回同时回滚 Task 与草稿；取消不发布迟到校正。识别期间的人工保存提高草稿版本，完成结果只在版本和最近任务身份都匹配时应用，否则明确 `applied=false` 并保留独立结果，供用户选择采用。

剪辑器在来源字幕区发起识别、查看/取消任务、编辑文字和来源起止时间、导入/导出文件，并可逐来源选择是否用于成片。Query 保存服务端实体，窗口内 Zustand 只保存未提交校正及 CAS 基线。关闭、切换来源和导出先保存校正，非法内容、失败或冲突保留草稿并阻止相应动作；冲突覆盖必须由用户明确选择。刷新后的重新打开读取数据库草稿，不依赖浏览器持久存储。

来源字幕与手动成片字幕保持不同时间语义。前者每次根据固定版本、裁切、速度、片段顺序和 30fps 实际完整帧边界重新投影；配音字幕必须采用服务端实际裁切/位置/速度计划，配乐按取源起点映射。替换来源版本不能套用旧字幕，重复使用同一来源独立映射每个片段。后者继续使用成片绝对时间，缩短时间线后的越界必须显式修正。预览、最终 MP4 请求和成片 SRT/VTT 下载共用同一成片字幕列表，超出预算或计划未就绪时不提交不完整字幕。ASS 烧录和预览保留已有厘秒精度规则，SRT/VTT 保存毫秒。

批量读取每次最多 100 个来源，总计 10,000 条及 8MiB（数据库 JSON 字节含每草稿 1KiB 元数据余量）；数据库在同一查询快照中校验，超额整批返回 413，不向应用物化全部正文。浏览器串行跨批读取并按相同总量累计校验，失败不发布部分时间线，关闭旧来源组合即回收完整查询缓存；校正保存串行执行且失败保稿。后台任务状态读取也串行化，缓存只保留小状态，用户显式采用识别结果时才读取当前任务完整正文。识别受理成功立即关联持久任务身份，后续草稿读取失败仍保留轮询、取消和导出阻塞，不能重复受理。来源 TAB 和 CR/CRLF 在成片投影中统一为普通空格和 LF，预览、MP4 请求及成片字幕文件一致，来源草稿不变。手动成片字幕中的空白行在编辑时标为非法并保留输入，避免 MP4 可受理但交换文件不可导出的分歧。

字幕文件上限 2 MiB、每来源最多 5,000 条、每条最多 500 字符；最终成片还受当前合成预算限制。单次识别来源最长 10 分钟，默认总超时 10 分钟、最高 30 分钟，私有临时空间 64 MiB，CPU 模式默认 2 个线程、最高 4 个。实例固定一个识别槽位，无无界原生任务队列。原生进程不继承凭据环境，普通日志、SSE 和错误响应不携带识别文本、原始输出或本机路径。

## 取舍与验证边界

选择原生本地引擎而非云 ASR，可以保持素材隐私和独立运行；代价是部署者自行准备引擎、核对模型来源/许可证、语言覆盖和资源。缓存的 faster-whisper/CTranslate2 模型不等于可直接使用的 whisper.cpp 模型，不隐式转换。

Compose 的 1,536 MB 限额还承载 Java 与 FFmpeg；单并发不构成足够内存的证明。真实模型、纯音乐/静音幻觉、中文准确度、长音频晚段对白、目标平台与应用并行时的峰值内存须单独实测。受控识别回执、真实 PostgreSQL 和真实 FFmpeg 烧录分别证明协议/状态、持久化/并发和媒体输出，均不能替代真实 ASR 验收。

配置与运行边界见 [本地字幕指南](../agents/local-subtitles.md)，协议见 OpenAPI，实际检查范围见开发清单。
