# ADR 0017：重新生成积累节点版本，图片编辑派生节点

状态：接受（2026-09-30），取代 [ADR 0016](0016-media-nodes-are-single-results.md) 的单结果节点规则，并细化 [ADR 0014](0014-canvas-item-media-branches-and-versioned-image-inputs.md) 的媒体版本归属。

把所有媒体变更都变成新节点会让尝试同一提示词的不同结果占满画布。用户决定按操作区分：图片和视频生成、重新生成在当前 CanvasItem 追加不可变版本并提供历史选用；图片编辑（智能编辑、裁剪、打光、扩图等）、后处理和已有结果的替换上传派生独立节点。批量生成的第一个输出留在当前节点，其余输出保留独立节点布局；生成不会新建编辑派生线。

Artifact 保留共享身份、不可变审计历史及资源默认版本；CanvasItem 拥有自己的结果历史及当前选用结果。编辑结果不混入来源节点的版本列表，复制或从资源库放置只继承一个当前结果。节点切换版本保留媒体草稿及已有精确版本引用；新的连线使用新选用结果，已有引用只有用户显式更新才改变。

2026-09-30 显示细化：图片、视频节点的展示编号按自身历史从 v1 连续计算，派生、复制或资源库放置节点的首个结果也从 v1 开始；按全局审计编号升序确定该节点内部顺序，列表倒序显示最新结果。至少一个保存结果时显示原工具栏版本按钮，尚无结果时隐藏。API 中 ArtifactVersion.versionNo 保留全局审计语义，选用仍提交不可变版本 ID 与节点 CAS，不修改已有版本记录。

2026-10-04 未选用结果入口修复：图片、视频和音频节点只要有至少一个保存结果就显示原工具栏“版本”按钮，包括没有当前选用版本和显示草稿的节点；不新增卡片内入口或其他结果按钮。用户从原版本菜单明确选用后显示媒体，复用节点历史与 CAS 选用接口，不新提交生成、不恢复冻结输入、不修改资源默认版本。生成成功的空预览明确提示“生成完成，尚未选用”，草稿显示态明确为“当前显示草稿”，并指向工具栏“版本”。版本加载失败可重试读取，UNKNOWN 或 BLOCKED 仍保留查看任务入口。自动选用的并发保护保持原规则。

派生结果节点的下一次创作从空白草稿开始：提示词为空、参数为空、未选择能力、时长或视频输入模式，且没有图片输入或图片标签。编辑所用的来源版本、参数和额外素材仅保留在不可变任务及结果来源中，派生线不自动成为参考图输入。普通“复制节点”仍复制当前草稿，批量生成的额外输出仍保留本次生成草稿。此规则适用于新建派生节点，不自动清空既有节点的草稿，避免删除用户后续编辑。

任务完成先追加不可变结果及目标节点历史，仅在受理时的父记录、内容选择 epoch、草稿版本和精确输入仍匹配时自动选用。切换后再切回原结果也算用户的新选择；拖动和改标题不算内容变化。取消、晚到及冲突结果仍可在历史中明确选用，失败不创建内容版本。

2026-10-04 用户决定修订：图片、视频生成期间，编辑栏不能修改下一次创作输入，避免切换视频模式等操作推进草稿修订号并使本次成功结果不能自动选用。前端按节点的 READY、SUBMITTING、RUNNING、WAITING_PROVIDER 任务统一锁定直接生成和已批准的 Agent 生成，受理中及状态读取未确认时也保持只读；覆盖编辑控件、自动保存和自动参数整理，关闭已有菜单。任务结束或 UNKNOWN 后解锁，排队取消和 UNKNOWN 显式重试仍遵循原规则；本地未保存输入保留，锁定期间不因编辑器关闭而补存。音频未纳入本次决定。该交互约束不替代数据库 CAS/选择 epoch，也不放开冲突结果的自动选用；其他入口或并发请求造成的变化仍受现有服务端保护。

新派生节点在受理时按「来源节点当前标题 · 操作名称」命名，例如「海边人物 · 深度图」「海边人物 · 裁剪」「海边人物 · 智能编辑」，替换上传使用「上传」后缀。三视图区分角色、脸部、道具与场景宫格，图层分离区分主体和背景。标题最长 160 个 UTF-16 代码单元，与现有应用层约束一致；超长时截短来源部分，保留操作后缀且不截断 emoji 代理对。标题是创建时快照，完成或重放不重新命名用户已编辑的节点，也不改资源名称、来源名称或既有派生节点标题。

V60 增量迁移保存现有节点与各自结果，并回填仍存在节点的已归档任务输出，不合并历史派生节点、不清空项目。导出清单升级到 schema v3，用 `mediaVersionIds` 保留节点历史归属；v2 清单仍是旧结构，消费者需识别 v3 后读取此字段。OpenAPI 新增节点级历史及选用接口，既有运行路径改为上述绑定规则；前后端须一起升级。
