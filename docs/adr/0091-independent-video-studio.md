# ADR 0091：独立视频工作台及私有生成作用域

状态：接受（2026-11-22）。

## 决策

`/video-studio` 不要求选择项目，不复用画布媒体草稿，也不创建 CanvasItem 或 Run。每位所有者最多持有一个 `VIDEO_STUDIO` 项目，与 `IMAGE_STUDIO` 和普通 `CANVAS` 分开。工作台内部作用域不出现在项目列表，不能通过项目管理、快照、画布或 Run 入口访问；认证所有者仍可通过已有的私有素材读取端点读取已归档的文件。

一次显式生成受理固定一份命令快照与一个视频 Task。同所有者和幂等键的重放核对原请求摘要；Task 与归档版本仍是状态和结果真相，不复制执行状态，也不把供应商额外结果拆成新任务。历史按 `(created_at, id)` 倒序分页，回填提示词和明确回填完整设置均不触发生成。

复用画布已发布且启用的视频生成能力、连接、版本和价格，不复制配置；本地剪辑、抽音频等不是生成模型。工作台支持已发布能力声明的文生视频、首尾帧和全能参考。普通全能参考按类型有序，具名工作流使用同一创作者字段、条件和槽位映射；复用画布的输入校验和 Provider 快照准备，不生成或模拟画布草稿、节点及连线。输入必须是本工作台的私有精确版本，拒绝外部 URL 和跨作用域引用。有效参数在受理时固定；独立工作台不读取画布比例，普通 `AUTO` 取 `16:9`，工作流可沿用已发布的固定尺寸。

现有媒体 Task 负责异步提交、查询、归档和用量，`executionSurface=VIDEO_STUDIO` 区分仅归档的入口。引用视频使用原适配器的私有媒体中继策略；继续遵循 [ADR 0066](0066-preserve-provider-video-audio.md)，保留供应商返回的原视频和音轨。恢复只查原请求或完成原结果归档，不重新生成。

## 迁移及取舍

合并基线后的 V68 不改写既有画布、图片批次、Task 或素材。视频工作台用部分唯一索引仲裁并发首次进入；生成账本用固定用途和复合项目外键同时约束项目的所有者及用途，再以 `(project_id, task_id)` 外键禁止跨作用域关联 Task。沿用已有存储和权限边界，不抽象通用工作区，也不把生图专用批次或清理规则迁到视频工作台。

初版按 [ADR 0012](0012-jooq-persistence.md) 的 V68 增量迁移建立私有作用域；原始设计和验收见 [OpenSpec 归档](../../openspec/changes/archive/2026-11-22-add-video-studio/)。V69 扩展请求 JSONB 检查约束以接受含固定参考素材和有效字段值的 v2 请求，不重写旧文生/首尾帧记录及幂等键。前后端应一起升级。升级和必要的恢复参见[备份与恢复](../operations/backup-restore.md#恢复顺序)。
