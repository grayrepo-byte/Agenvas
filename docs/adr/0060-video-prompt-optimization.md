# ADR 0060：视频节点提示词优化与可选 Skill

状态：接受（2026-10-24，用户要求为视频节点增加提示词优化并可选择 Skill）。

视频提示词编辑栏新增独立的文字模型优化入口，允许不用 Skill，或选择一个个人/内置 Skill 的固定发布版本；结果可预览编辑，明确应用后通过既有媒体草稿保存流程写入。覆盖原 Skill 设计「所有内容节点不提供选择入口」的限制，不形成节点长期 Skill 绑定，不自动运行视频生成，也不改变项目导演的默认选择与多 Skill 渐进加载。

该入口是一次文字转换，而非拥有画布工具的 Agent Run。任务固定所选 Skill 的主说明和全部文字附件，作为完整文字方法输入；不加载图片、不映射输入槽位、不读取其他画布内容或执行 Skill 中的命令。这样可复用现有文字 Worker、无工具调用与响应恢复；代价是所选方法的全部文字进入单次请求，不能借用导演的按需附件读取。界面明确这项文字范围，不声称满足 Skill 的多模态创作流程。

受理使用 `TEXT_GENERATION` / `VIDEO_PROMPT_OPTIMIZATION`、输入 schema 4，固定用户本地提示词、长度上限、功能提示词 `video.optimize-prompt` 正文/版本、文字模型和可选 Skill 的发布内容。查询、关闭或恢复不能重新调用模型；同幂等键重放固定任务，同节点仅一个活动优化，取消 fencing 阻断晚到结果。完整响应留在内部检查点，API 仅返回公开提示词与 Mock 标记。V40 只新增功能提示词种子，无表结构或 jOOQ 变化。

媒体提及转换为稳定的 `[[REF_n]]` 标记，模型输出必须保留全部标记的出现次数；应用时按结果顺序恢复精确版本，保留输入列表。当前草稿或编辑权限已经变化时拒绝回填并保留建议，防止优化结果覆盖后来的用户编辑。实际保存的失败、冲突与重试继续由原草稿流程负责。
