# ADR 0043：可灵图片与视频生成协议

状态：接受。用户确认接入图片、视频生成的全部当前模型与参数。

使用 KLING 连接和单个 API Key，按部署地区选择已核实的 Singapore 或 Beijing 官方根地址。凭据在服务端加密保存并随连接版本固定；不接受任意代理地址。仅适用于旧协议的 AK/SK JWT 不作为新视频连接凭据。

发布稳定适配器 `KLING_IMAGE` / `KLING_VIDEO`，版本化设置固定 model/operation。当前目录含四个图片模型、六个视频模型，共十五种模型/操作组合：普通生成、多图参考、Omni、连续出图、扩图、主体多视图补全和两种动作控制。元素/声音 ID 可作为生成参数使用，其管理接口不属于本次范围；不从过时示例推导历史模型支持。

模型图片生成使用 `/v1/images/...` 和 model_name；扩图使用 `/v1/images/editing/expand`，主体多视图补全使用 `/v1/general/ai-multi-shot`，两者不传模型。新视频通过 URL 模型路径与 contents/settings/options 提交。编译后的 KlingModels 决定字段、默认值、范围与组合限制。管理员通过只读 `/settings/kling/profiles` 目录创建能力，发布能力派生 klingInputs。前端复用通用控件，不复制协议目录，不给云 API 伪造工作流图节点。

草稿使用 parameters.dynamicValues 保存原生标量与命名媒体槽。Prompt 和时长来自画布字段；槽值只能引用本项目已授权的精确媒体版本。图片协议的元素 int64 ID 使用十进制字符串避免浏览器精度丢失，新视频协议的元素 ID 按原生不透明字符串保存，客户端构造原生数组。回调和外部任务 ID 由应用管理。运行前检查首尾帧、参考视频、声音、分辨率、多镜头与时长的交叉限制。

任务固定模型、操作、有效参数、槽、素材、能力/连接版本和价格。图片 n/连续出图由一次请求产生多个结果，复用不可变结果清单和附加节点归档，不复制收费 POST。自动数量和动作控制输出时长预留时保持未知，归档后按实际数量/探测时长估算；估算不是供应商实际账单。查询和下载恢复只使用原 ID；结果身份与序号固定后不受后续查询排序影响。

参考图片发送原始 PNG/JPEG Base64，参考视频按模型验证后使用固定对象签名或中继。准备与网络调用在数据库事务外。下载执行固定域名、DNS、禁止重定向、无凭据、大小/MIME/魔数及实际探测规则；水印选择固定，缺少所选结果显式阻断，过期 URL 只刷新同一任务/输出。创建受理不明保持 UNKNOWN，不自动重新生成；现有取消与晚到结果不自动选用规则继续适用。

旧 KLING_IMAGE_3 / KLING_VIDEO_3 保留已发布能力与历史任务恢复，新发布入口使用完整协议适配器。V19 扩展平台约束，V20 将草稿范围对齐既有 1–60 秒合约；完整目录使用既有版本化 JSON，无需额外 schema 迁移。OpenAPI、生成 TypeScript 与一次性 PostgreSQL 生成的 jOOQ 同步，前后端需一起升级。

官方依据和细节见[接入说明](../kling-api-integration.md)、[图片研究](../research/kling-full-image-protocol.md)、[视频研究](../research/kling-full-video-protocol.md)。假 HTTP 与合成素材不能证明真实供应商已接通，验证范围据实记录于开发清单。
