# ADR 0078：同项目画布子图复制

状态：接受。按用户决定，先完善公共提示词与多个生成节点、角色引用组成的画布流程复用；替代 ADR 0059、0074、0077 中多选复制不继承内部连线的规定。

## 决策

沿用已有复制、粘贴、直接复制和分组复制入口。在当前项目会话内复制选中节点，以及两端均在选区内的 `PROMPT_INPUT`、`MEDIA_INPUT`、`MEDIA_DERIVATION` 和角色逻辑连线。连接到外部节点的关系不复制。完整组建立新的组身份，部分组成员复制为独立节点；每次粘贴重新分配节点、组和连线 ID。仍有单次 100 节点、100 组和 10,000 条内部连线的边界。

复制前先等待相关编辑器确认保存。editor 读取在同一 REPEATABLE READ 快照内提供节点、组和两类拓扑；会话剪贴板固定来源内容/草稿版本与内部连线身份及版本。粘贴在项目事件锁内重新校验完整内部拓扑，新增、删除、重建或版本变化均拒绝旧请求。失败保留原输入和原命令，可按既有编辑回执路径重试，不产生半份副本。

文字建立独立 Artifact 与正文，内部公共提示词连线映射到新文字节点的初始正文版本，并保持来源拼接顺序；以后修改原文字不影响副本。媒体保持原固定选用及精确素材版本、角色/时长/能力/参数/风格/模式、引用角色与顺序/颜色、结构化标签，不以当前来源选用替代旧的固定引用。内部媒体输入来源改为新的连线和来源 ID，手动来源重新分配身份，外部媒体来源降为手动输入；同一版本仍去重，删除复制连线时只移除该连线贡献。已应用的角色快照固定复制并要求复核，保留明确的素材贡献所有权。逻辑节点应用归属仅保留原有归属与本次内部角色来源的交集，纳入冻结回执及撤销保护；断线后显式清理能移除仍属于内部角色的贡献，外部或手动角色仍作为独立固定选择。角色节点保留同项目不可变修订、造型、图片子集与用途；逻辑边映射到新节点，不自动应用角色或触发生成。

全部 CanvasItem 先建立，再安装角色配置、内部拓扑和依赖这些连线的媒体输入，避免角色配置与来源外键顺序错误。每次复制只提交一个 `canvas.edited` 事件及一份私有回执，快照和 SSE 继续刷新服务器投影。

撤销前先验证所有副本的内容、草稿、选用、角色、拓扑 epoch 和后续任务/审批/分镜使用；全部匹配后仅删除该回执创建的内部连线和副本。外部后续连接或连接后再断开的 ABA 仍使撤销冲突。重做使用私有回执冻结的内容和拓扑，不读取已变化的来源；先恢复角色配置再恢复连线及媒体输入，推进节点、正文、草稿、角色和逻辑边版本。普通新增/删除连线仍不成为独立可撤销命令。

## 实现与升级

OpenAPI editor/编辑响应追加两类拓扑，DUPLICATE 请求增加 `connectionCopies`，包含关系类别、来源连线身份与版本、新连线身份。同步生成 TypeScript。沿用现有表和私有 JSON 回执，不需要 Flyway 或 jOOQ 变化；旧回执没有拓扑字段时按空拓扑恢复。前后端一同升级，旧客户端遗漏当前内部拓扑时收到冲突，不静默创建缺线副本。普通连线断开请求必须携带 `expectedVersion`；重做推进连线版本，旧断线请求明确冲突，避免删除恢复后的提示词或派生线。客户端须同步增加该字段。

范围限同项目当前会话的子图复制，不包含系统剪贴板交换、跨项目模板、跨画布导入、完整历史或执行状态复制，不调用模型或外部服务。

验证记录见开发清单。浏览器使用合成 HTTP 夹具，真实持久化、事务与回放由专用 PostgreSQL 验证；不将 Mock 或合成素材视为真实 Provider 验收。
