# ADR 0087：命名 LLM 连接与显式切换

- 状态：接受
- 日期：2026-11-07；整合：2026-11-12
- 依据：用户要求精简 Provider 设置，保留多个可切换服务，编辑时无需反复输入 API Key。

## 决策

管理员维护独立的命名 LLM 连接，每条保存地址、模型、服务端加密凭据与模型容量策略。目录以紧凑行展示连接、当前选择与工具协议状态；新增和编辑使用按需弹窗，模型发现和高级参数默认收起。本机 Ollama 发现位于连接帮助中，打开帮助不探测、不填入或保存。

保存连接与选择当前服务是两个独立操作。新增连接不自动替换当前服务；编辑非当前连接也不改变当前服务。显式切换只影响后续请求，已经冻结的模型请求继续读取原始配置和凭据。诊断可针对任一连接发起，并在独立弹窗中逐次确认可能计费的两轮请求，不隐式切换服务。

新建必须提供有效 API Key。编辑已有连接时，缺省、null、空字符串或纯空白表示保留该连接原有密钥；非空值表示替换，继续校验 8–4096 个无空格可打印 ASCII 字符。浏览器只接收掩码，提交过的新密钥在请求结束后清空。仅修改名称、运行配置和有效凭据完全相同时沿用验证结果；地址、模型、凭据或容量策略实际变化时须重新验证。

## 稳定连接与不可变运行快照

不能把过去每次覆盖形成的历史配置行直接作为服务目录：它们没有稳定连接身份，也不能区分同一服务的修改与另一条服务。V63 新增命名连接 head，指向保留的不可变运行快照；已受理任务继续凭原全局版本读取快照。

保存采用该连接 head 的 CAS，激活同时校验目标 head 与当前活动版本。激活将所选配置克隆为全局新版本并推进目标 head，使切走再切回不会重复使用旧的活动版本，避免旧切换/诊断命令被误认为仍有效。所有新快照按新 UUID 和版本重新加密，不能直接复制绑定旧 AAD 的密文。诊断网络调用在事务之外；成功写回只接受仍为同一连接 head 的版本。全局计数锁、连接 head 和快照采用统一锁序。

模型预览显式携带连接身份与版本。未输入新 Key 的草稿预览从该连接精确快照解密，允许校验后的草稿地址；不能借用当前活动服务或其他连接的凭据。自动容量预览继续绑定连接、版本、地址、供应商与有效凭据摘要，编辑状态、取消和迟到响应不自动保存。

## 合约、迁移与升级

新增 `/settings/llm/connections` 目录、按身份保存、显式激活及连接级诊断接口。原 `/settings/llm` 继续读取/编辑当前活动服务，API Key 同样支持空值保留；其他创作调用方继续读取当前配置状态。OpenAPI、官方生成 TypeScript 和 jOOQ 同步更新。

V63 仅将升级前的活动配置导入为一条命名连接，保留原活动状态、验证结果、凭据字节和所有历史快照；旧的非活动历史不伪装成用户主动保存的连接。空安装保持无连接，管理员明确添加并选择。前后端须同批升级，不支持新前端连接旧后端；本次不修改或部署现有运行数据库，也不操作真实服务密钥。数据库备份和恢复仍遵循既有运维说明。

## 整合说明

此功能此前独立实现但尚未发布。本次迁移采用 V63，保留已经发布的 V55 公共提示词迁移不变；ADR 同步采用 0087，避免覆盖已有 0077。保留后续连接配置的 1M 默认容量、按需展开高级参数与轻量操作样式，不将无容量元数据误报为已检测到模型上限。
