# ADR 0062：导演默认媒体配置与审批前视频修订

状态：接受。用户要求导演采用已有视频生成默认设置，并允许在最后审批阶段改供应商及受支持的分辨率。

导演目录显式标记默认能力并提供默认参数、时长及已发布的输入字段。未指定其他要求且输入兼容时优先采用默认配置；不增加按价格、质量或可用性自动切换供应商的路由器。首轮只传摘要，详细字段按需通过既有工具读取。

允许用户通过带审批 CAS 的命令逐项修订未过期 PENDING 批次的视频能力与参数，同事务更新草稿、固定能力、预检与费用摘要，然后另行批准最新整批版本。选择单独保存与批准，是为了让用户在费用和能力改变后先看见最终摘要；直接编辑普通节点草稿仍会令原审批失效，不将任意草稿变化视为用户已审核的新提案。保存不生成 Task、不延长期限；已批准与终态保持不可修改。

修订保留原提示词、全部精确素材及顺序、目标与镜头依据、Skill、角色和风格，只按协议转换素材角色与具名槽位。不能保留素材或运行不兼容时明确拒绝，失败事务完整回滚。镜头过期、草稿或节点 CAS 改变、取消和权限检查继续生效。原始模型调用及幂等哈希保留；结果续接携带实际修订后的参数，不要求重新调用导演。UNKNOWN 不因此取得重新生成资格。

沿用审批 JSONB 与项目事件，无数据库结构变化或迁移。新增 PUT 合约，前后端与生成 TypeScript 同步部署；没有新依赖。真实供应商的分辨率遵从和账单仍需单列验证。
