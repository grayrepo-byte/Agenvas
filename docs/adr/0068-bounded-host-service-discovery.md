# ADR 0068：管理员主动发现宿主机服务

状态：接受（2026-11-04，用户要求本地服务快捷选项与自动嗅探）。

## 意图与取舍

减少 Docker 下手填 Ollama / ComfyUI 地址的负担，保留手动配置。选择“主动检查一个固定服务，再明确填入”的方案：纯地址预设不能证明可达性；网段、端口与容器枚举会扩大探测面，故不实施。发现不是生成、工具能力验证或网络授权。ADR 0067 的 LLM HTTP 准入继续独立生效。

## 固定范围

管理员经 CSRF 保护的 POST 只提交服务枚举，不接受 URL、端口、网段或路径。Ollama 固定端口 11434、GET `/api/version`；ComfyUI 固定端口 8188、GET `/system_stats`。不携带凭据、Cookie、项目数据或用户提示词，不提交模型/媒体任务。

明确容器运行时仅解析 `host.docker.internal`；全部答案须为 RFC1918 IPv4，验证后只选一个并固定本次连接。不循环探测 DNS 多答案。明确原生运行仅使用字面 `127.0.0.1`。标准 Compose 声明容器运行标记及 `host-gateway` 名称映射；该映射不启动代理、不修改宿主机配置或开放端口。自动识别发现 Docker/Podman 标记时判为容器；明确 Mac/Windows 原生环境可判为原生，无法可靠判断的环境要求部署者选择运行模式或继续手动配置。

只接受固定服务响应形状：Ollama 的非空 `version` 字符串；ComfyUI 的 `system.os`、`system.python_version` 字符串及 `devices` 数组。只返回稳定状态、运行位置、候选地址及现有策略是否允许；原始正文、版本、设备、启动参数、异常文字均不返回、不记录和不进入 debug 采集。

## 资源和安全边界

使用无代理、无重定向、无自动重试、无 debug 采集的专用固定 HTTP 管道。最多读取解压后的 32 KiB 加一字节，超限拒绝。连接超时 1 秒、HTTP 总时限 2 秒，含 DNS 的对外整体等待最多 3 秒。

DNS 与状态请求共用一个有界单线程执行器；只有实际探测退出后才释放容量并发布结果。单槽队列仅衔接上一任务已完成探测、执行器尚未返回的窗口，探测运行中不接受排队。超时后未退出的底层解析继续占据实际执行容量，后续请求返回忙，不能持续创建线程。接受请求间至少间隔一秒。用户取消停止界面等待，已发出的无凭据状态请求仍受服务端时限约束。

所有 DNS 答案先严格检查，不复用允许 fake-IP / ULA 的通用出站谓词。容器候选拒绝公网、回环、link-local、广播、组播、IPv6 和混合答案，包含云元数据。保存和真实使用仍走原配置 API、权限、加密及网络校验。

LLM 候选保留固定宿主别名，使用当前 Origin 和已验证地址计算准入，不再次解析 DNS。ComfyUI 返回实际探测的 IPv4 字面地址，复用现有精确本地 HTTP 规则，不增加域名 HTTP 例外。被策略阻止的结果只说明已发现，不能按“可用连接”填入。

## 界面及平台范围

LLM 设置与 ComfyUI 新建/编辑表单共享发现控件。进入页面不发起探测；点击后显示等待、取消、发现、未发现、解析失败、超时、认证需求、响应不符及权限/部署限制。明确选择才填草稿，不自动保存；取消、切换服务或关闭页面后迟到结果不得覆盖草稿。

Docker Desktop 的名称解析与 Linux Engine 的 host-gateway 路径均需实际网络可达；服务监听和防火墙保持用户配置。Windows/WSL 分层、rootless 网络、自定义端口、IPv6-only 服务、其他容器中的服务不保证可自动发现，继续手动配置。原生 Linux 自动识别不明确时可由部署者显式选择 NATIVE。真实模型、GPU 或媒体生成并非本功能的验证内容。
