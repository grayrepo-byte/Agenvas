# ADR 0054：导演的剧本拆解与完整分镜流程

状态：接受；实际验证范围见开发清单。

用户要求导演支持剧本拆解、分镜设计的一套完整流程。已有默认指令仅要求一份粗粒度「剧情与镜头方案」，八个创作 Skill 必须由用户显式选择，长剧本读取又会因正文超限退化为截断预览。这使默认导演缺少稳定的阶段交接与全文覆盖依据。

## 决定

完整创作方法写入可编辑的 `agent.director` 默认正文，继续在 Run 创建时冻结为独立创作 SystemMessage。程序维护的系统规则只增加文字分页协议，不强制创作风格、镜头数量或创作阶段。用户可以改写导演指令；八个已发行 Skill 及其候选、激活和不可变版本语义不变。这样默认导演无需选择 Skill 即可执行流程，同时保留项目定制和既有权限分工。

完整文字流程依次完成实际剧本读取、场次/节拍拆解、视觉设定与调度、正式分镜、关键帧/视频提示词、覆盖审校及进度记录。所有产物沿用普通 TEXT Artifact 和 CanvasItem，不新增角色、场景、镜头或执行计划表。用户只要求某一阶段时按该范围交付，已有剧本不强制重写；没有 Provider 或参考图时仍可交付文字设计，明确素材缺项。

场号 `SC-`、镜号 `SHOT-` 是创作文档内稳定标识，不是数据库身份。每镜记录来源版本和节拍、叙事职责、景别/机位/轴线、人物调度、动作起止、逐字对白和声音、估计时长及依据、转场与素材依赖。时长以行动、声音和停顿为依据，无实测音频时明确是文本估时。重排保留镜号，拆并镜记录停用号与新号谱系；相关提示词和素材标记待重核。

《分镜制作进度》保存已读来源版本和范围、已完成阶段、工具成功返回的产物版本、遗漏/失败/来源变化及下一范围。长任务按场次分批保存和审校，续接先读取已有记录，修订走完整正文与 CAS。进度记录是 Agent 的公开工作成果，服务端不把它当成权限、自动解析结果或机器保证的质量结论。

## 长文字读取

内置 `read_artifacts` 增加可选 `textOffset`、`textLimit`。任一字段存在时只允许一个 TEXT 精确版本，默认从 0 读取 4000 个 Unicode 码点，上限 4000；返回本页 `content`、`contentTruncated` 及 `textPage.offset/endOffset/total/nextOffset`。最后一页的 `nextOffset=null` 只代表版本末尾，若 offset 非零仍标为截断；完整覆盖要求从 0 连续读取。每页重新验证当前项目画布或显式 Skill 输入权限，不能借分页读取其他项目或已失权版本。

普通调用和媒体读取保持原行为；不增加工具名或权限，也不改变策略版本和 HTTP/OpenAPI。MCP 的同名独立工具不受此内部参数扩展影响。已冻结请求的技术重试和响应重放同时恢复检查点中的消息与工具定义，保持名称、说明、Schema 和顺序；恢复时核对工具名仍属于 Run 冻结允许列表，定义回调拒绝直接执行，业务调用仍经过持久工具执行器。仅恢复消息并重建当前工具会使请求等值校验冲突，因此本次一并修复该恢复缺口。新构造的模型请求才使用增强定义，长文本继续复用现有精确版本授权、账本和恢复链路。

## 升级与媒体边界

新增 V34 数据迁移，以正文精确匹配 V26 原始默认词（含初始化时的首尾空白归一化形式）更新全局默认词和已有导演指令。名称、说明和自定义正文保留；仅匹配行增加配置版本和更新时间。项目行锁先于导演行锁，每个实际更新的导演在同事务递增项目事件序号并写 `agent.instance.changed`，事件只包含身份。Run 冻结输入、会话、任务、审批、内容历史均不改写，进行中的 Run 继续使用原创作指令。后续普通全局提示词编辑仍只影响新项目初始化，不形成持续同步。

迁移不新增 schema、依赖或 jOOQ 生成内容。回退创作指令可通过现有编辑入口；回退迁移记录仍按部署备份规则处理。用户已定制的导演需要自行合入新方法，不自动追加流程干扰其指令。

文字完成后只有用户任务包含媒体生产才继续：能力发现、参考图、关键帧和视频分依赖批次提交，外部生成仍逐批鉴权审批；精确归档版本才可作为后续输入。UNKNOWN、取消、过期不得自动重提。用户要求成片且符合既有工具限制时才接续本地合成；受理回执不等于媒体完成。

验证需覆盖升级保留与事件、长文字 Unicode/越界/权限、默认无 Skill 导演的文字产物与不可变修订链。合成模型验证只证明指令传入、工具链和持久化，真实剧本理解、镜头设计及 Provider 效果另列验收。
