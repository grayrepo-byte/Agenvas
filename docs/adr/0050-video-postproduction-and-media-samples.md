# ADR 0050：有界视频后期、审片与按需媒体采样

用户要求补齐视频处理短板。沿用已有本地配音合成 Task，扩展为列表式裁切拼接、变速、淡黑、原声保留、背景音乐、定时字幕和输出规格选择；直接编辑与导演工具复用同一受理服务。取源、配方与精确版本在受理时冻结，结果为独立不可变视频，不用画布坐标推断播放顺序。继续限制成片60秒，源片与归档放宽至10分钟以覆盖视频延长；深度推理保留单独的资源预算。该决定扩展 ADR 0049，并更新 ADR 0013 当时撤回媒体导出的边界，不恢复旧执行计划或自由多轨时间线。

导演按需读取授权精确版本的时间点画面和短音频。工具事务只登记版本及时间；模型发送前重新授权、在事务外解码，检查点不保存媒体字节或路径。一次最多4帧、15秒音频，下一次样本替换旧附件；画面采样不能声称全片连续性或口型同步，声音活动不等于识别对白。音频通过现有 Spring AI 的 `input_audio` 路径，仅适用于支持音频输入的所配置模型，明确失败不会变成伪造转录。LLM debug 省略音频二进制，保留格式与其他模型字段。

审片在既有预览/版本入口内提供同步对比、速度、用户选定帧率基准的步进及会话时间标记。标记暂不持久化，避免把本地观察冒充已保存的业务记录。字幕采用受控私有ASS文件，字体由服务端配置，镜像包含CJK字体；用户文本不成为任意过滤器或文件路径；ASS控制字符按可见全角字面处理，真实换行保留。自托管FFmpeg需要libass才能烧录字幕，缺少支持时任务失败，不静默交付无字幕成片。

ComfyUI已发布输入契约增加视频及音频槽位，继续要求同项目精确版本、每类连续索引、最多14个素材、固定上传/结果协议。该决定扩展 ADR 0030 的图片输入边界；已有图片工作流及历史任务仍按固定版本运行。协议变化同步 OpenAPI、生成 TypeScript、MCP目录和前后端测试。现有V31合成能力迁移保持不变，本次扩展不增加数据库表或重写已有迁移。
