# ADR 0083：本地 3D 摄影机关键帧与可复用参考

接受（2026-11-10）。用户要求完善 3D 动态运镜。本次扩展 ADR 0051 的静态摄影机，继续使用本地 Three.js 程序化场景，不引入云服务、付费模型、素材上传或新依赖。

选择在既有不可变拍摄版本中归档相机轨迹，而非新建独立导演工程实体：当前完整场景已能通过 `frozenInput.directorScene` 回读；同一严格 JSON 也能离线导出、导入。选择的代价是未拍摄草稿仍只在当前工作台会话中，用户须导出 JSON 或拍摄到画布后再关闭；本次不增加自动保存语义。

新编辑与拍摄使用 schema v3，保留 v2 的三轴缩放，增加 `motion: {durationSeconds, keyframes}`。每个关键帧包含唯一 ID、名称、严格递增的秒数、完整摄影机姿态和到达此机位的过渡。轨迹时长 1–120 秒，最多 24 帧，相机/对象边界沿用原规则，前后端均拒绝额外字段、无效数值、重复 ID/时间和超限数据。服务端继续原样接受 v1/v2，既有版本与命令重放不归一化；编辑器只转换脱离来源的旧场景副本，无数据库迁移。

机位关键帧兼作可复用的多机位，支持记录、跳转、改名、时刻调整、用当前摄影机更新及删除。插值作用于真实三维相机的轨道、look-at 目标、距离和焦距：LINEAR 线性、SMOOTH 使用 smoothstep、CUT 在目标时刻直接切换。方位走最短弧；完整环绕须用中间帧明确方向。首尾之外保持端点；总时长更改按比例缩放全部帧时刻。导演视图绘制分段三维路径，硬切不显示为物理移动。摄影机视图是实际场景取景，不是对二维来源图片做变形。

播放时钟仅更新本地预览，不改写关键帧；暂停、结束、关闭、页面隐藏和 WebGL 失效释放时钟，重播从结束点回到起点。播放期间冻结场景编辑和截图。选中、路径与摄影机辅助物均不进入 PNG，重建轨迹释放旧几何，工作台销毁释放所有渲染资源。拍摄固定当前实际姿态和完整轨迹进入原 PNG 上传/版本/CAS/重试链路；失败保留文件与场景快照。

参考交付为完整场景 JSON、当前帧 PNG 和本地 WebM 运镜参考片，支持离线复用。用户可以把 PNG 导入现有图片节点，再通过已发布模型能力的参考输入显式生成。轨迹 JSON 没有映射到现有视频 Provider 参数；不宣称模型受理或遵守真实轨迹，不增加未经许可的外部媒体调用。浏览器不提供 MP4 编码、骨骼/物体动画或自由手绘样条。


WebM 导出使用浏览器原生 [Canvas captureStream](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/captureStream) 和 [MediaRecorder](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder)，动态检查 VP9、VP8 或 WebM 支持，不安装编码依赖或调用服务端。采用独立、脱离界面的 Three.js 渲染器和冻结场景副本，从起点录制完整轨迹，始终使用拍摄摄影机并排除编辑辅助。原工作台的场景、选中机位、预览位置不被逐帧更新；播放时须先暂停才能导出，不悄悄改变播放状态。

导出上限为 120 秒、最长边 960 像素（四种画幅均取偶数尺寸）、目标 24fps、2Mbps、48MiB；格式与下载扩展名始终明确为无声 WebM，不能改名冒充 MP4。MediaRecorder 是实时录制，实际帧率取决于硬件与页面调度，不承诺离线逐帧精确编码。每 250ms 收集数据并检查字节预算；时长加 15 秒为停止等待预算，超限或编码错误不交付部分文件。导出有进度、取消和明确失败反馈，不支持时直接说明；页面隐藏、用户关闭/取消、视口失效和组件卸载都终止导出，移除监听器、计时器、停止所有流轨并释放独立渲染器。成功才创建下载 URL，触发后回收；重复导出各自建立与清理资源，不上传模型。

WebM 是可下载的动态构图参考，不是 Provider 的摄影机轨迹参数；能否直接用于某个视频功能仍受其媒体格式与参考能力限制。真实 Chrome 导出的字节以本机 FFprobe 核对 WebM/VP9、尺寸与包时间，并以 FFmpeg 解码帧哈希确认运动画面；这属于真实本地媒体编码证据，不是真实 AI 视频效果验收。

用户可将导出的 WebM 通过已有视频上传入口导入素材链。常规上传、资源库及 MCP 素材准备只接收实际 EBML DocType 为 WebM 的单路无声 VP8/VP9，最多 48MiB、每边 960px、7200 帧、容器 121 秒（120 秒轨迹加 1 秒编码尾部容差）。服务端以本地 FFmpeg 转为 H.264/yuv420p MP4，再复用不可变归档与现有剪辑入口；来源文件没有改名冒充 MP4，原 MP4 不重新编码，Provider 归档和恢复仍只接受 MP4。缺少 duration 的 MediaRecorder 文件通过完整解码帧数与转换后时长复核；输入/输出有字节上限、每进程 20 秒时限、受限协议/线程/解码像素，达到安全停止线也必须帧数完整一致，不发布截短结果。无声参考片不具备可识别音轨，不能将导入成功表述为 ASR 已识别。
