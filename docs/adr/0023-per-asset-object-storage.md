# ADR 0023：资源固定存储位置，默认连接只影响新归档

接受（2026-10-01）。用户确认保留默认本地存储，并按部署需要可选阿里云 OSS、腾讯云 COS 或 Amazon S3 / S3 兼容对象存储。默认连接切换只改变新归档的目标；本地旧文件继续读本地，云端旧文件继续读原连接，不自动搬迁。

每份归档在摄取前固定连接身份，已验证字节及元数据先保存独立恢复记录，再上传原文件与缩略图。只有两份对象完成核验后才发布 READY Asset。固定配置的 Endpoint、Region、Bucket、前缀与寻址方式不可被改写；需要更换位置时新增连接，已有连接允许原位置凭证轮换，保证历史资源不会因默认切换或凭证到期失去地址。配置不得删除，避免悬空历史引用。

对象存储是云端资源字节的持久归档位置。应用保持项目鉴权后代理 GET/HEAD/Range，不向浏览器提供桶地址、密钥或长期外链；普通预览不落本地副本。媒体类型、大小、像素和解码检查仍在本地完成，云端归档成功后清理已校验的中转文件。作为生成参考或 FFmpeg 输入的云端资源按需物化到私有缓存，并在闲置到期后清理；本地原文件不参与缓存清理。因此云存储减少长期归档容量，不能消除上传、解码和媒体处理所需的临时空间。

恢复只重试同一已验证内容的归档：在固定对象键核对大小与 SHA-256 元数据，再补齐缺失对象；不覆盖不同内容，不因配置切换改写目标，也不创建新生成请求。未知或失败写入保留中转字节；本地历史任务的已安装文件不会因新云配置被搬到云端。

新增 V64 的配置、默认指针与归档恢复表；既有 Asset / Artifact / CanvasItem 无迁移或数据清空。现有本地对象键继续有效；云对象键仅为服务端内部位置标识。数据库备份与凭证主密钥必须一起保留，历史连接和各个 Bucket 仍需独立备份。OpenAPI 新增设置接口，没有删除旧 API；前后端与迁移需一起发布。

为覆盖上传视频的存储需求，新增实际 MP4 上传接口和画布导入入口，复用既有视频解码、封面、不可变 Asset 与用户上传 Artifact 流程。HTTP 上传中转放在私有工作卷，避免 500 MiB 视频挤满容器的小容量 /tmp；反代仅放宽媒体上传路由，大小仍由对应媒体校验器执行。
