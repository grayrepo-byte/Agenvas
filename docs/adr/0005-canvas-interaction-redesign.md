# ADR 0005：画布交互与直接媒体运行

> 2026-09-27：本 ADR 中 Artifact 级媒体草稿、图片仅文生图、视频单图输入及“移除卡片不影响引用关系”的决定已由 [ADR 0014](0014-canvas-item-media-branches-and-versioned-image-inputs.md) 替代；其余未冲突的画布交互决定继续有效。

状态：接受（2026-09-25）；2026-09-26 修订 Agent 卡片呈现；2026-09-27 修订画布连线与删除交互。产品与领域边界已确认，实施与验收状态见任务清单；技术持久化决定见 [ADR 0006](0006-direct-media-task-boundary.md)。

## 背景与理由

现有工作区把创建、上传、对齐和导出放在左栏，图片/视频生成只能从关联镜头的 Agent 计划进入。用户希望直接在画布上编辑和运行媒体卡片，同时保留 Agent 的受控审批。菜单沿用项目现有的七类业务对象，不把参考图中的音频和 3D 入口误当作已支持类型。

## 画布交互

- 2026-10-04 媒体查看器修订：按用户确认，图片与视频放大统一使用 Yet Another React Lightbox 与 Zoom、Fullscreen、Video 插件，在当前页面沉浸式查看当前展示 Asset 的归档原文件，替代手写图片预览盒子和视频新标签页入口。图片支持缩放、平移和全屏，视频采用原生控件且打开时保持暂停；打开视频查看器时暂停节点内悬停播放，关闭后再次悬停才续播。保留完整比例、加载与显式重试、关闭按钮/Esc/遮罩关闭、键盘焦点约束及恢复，并隔离画布手势和快捷键。查看不创建或修改版本、草稿、任务或选用结果；新增正式前端依赖，不涉及 API 或数据库变更。本修订替代下述图片预览决定中视频入口继续沿用原行为的约定。
- 2026-10-04 视频悬停播放修订：按用户最终决定，取消节点内点击播放与关闭预览按钮；初始只加载海报帧，默认静音；每次进入视频预览连续停留 1 秒后才加载并播放或续播，避免短暂移入点击时立即播放。等待期间移开、打开查看器或卸载节点取消计时，重新进入重新计时。点击已有声音开关后开启声音，也可切回静音；移开暂停，再次进入等待结束后从暂停位置继续并保留当前节点的声音选择，播放结束循环。声音选择属于当前节点的临时播放状态，不修改媒体内容、草稿或任务。悬停不选中节点；播放进度条和声音开关隔离画布选中、拖动及平移手势，拖动进度不打开工具栏或底部编辑区，直接点击封面或视频画面才沿用原节点选中与编辑入口。加载、缓冲、失败及显式重试仍在节点内呈现；切换结果或卸载节点停止旧播放。此前要求首次悬停有声播放并禁止默认静音；干净 Chrome 会话在首次悬停、没有点击的情况下对合成带音轨 MP4 的原生 `play()` 返回 `NotAllowedError`，失败状态随后阻止继续悬停播放，而点击重试可播放同一文件。用户因此改选默认静音悬停播放、点击开启声音，本修订替代先前有声悬停及禁止静音的约定。代价是听到声音需要一次显式点击，保留实际比例、版本与任务边界，无 API、数据库或依赖变更。
- 2026-10-02 视频节点比例修正：按用户反馈，视频结果节点按当前选用 Asset 的实际宽高贴合边界、保持长边，缩放锁定实际比例；封面与播放完整展示。已有视频结果不按下一次生成草稿比例改变展示，草稿占位和尺寸不可用时保留既有布局，读取失败提供重试。尺寸投影不自动写布局，拖动、缩放、对齐仍使用原 CAS 命令保存。验证见 专项证据（开发记录不随源码公开）。
- 2026-09-30 图片预览修订：按用户要求，图片节点的放大按钮在当前页面打开原图模态框，不再新建浏览器标签页。原图完整适配视口，支持关闭按钮、Esc 和点击遮罩关闭，以及加载失败重试；弹窗约束键盘焦点并隔离画布快捷键，关闭后恢复原焦点。此操作只查看当前展示 Asset，不创建或修改版本；视频文件入口继续沿用现有行为。
- 移除左侧创建栏。空白画布双击或悬浮“+”打开同一创建菜单，包含文字、图片、视频、角色、场景、镜头、Agent。卡片放在触发位置对应的画布坐标；菜单避让视口边缘，支持键盘与 Esc 关闭。
- 项目工作区采用深色点状背景；缩放控件在右下角。最初改造范围仅限工作区；2026-09-26 用户追加要求将 Beautiful UI 黑色风格扩展到项目、登录、初始化与设置页，当前页面范围见 [规格 6.1](../MVP-SPEC.md#61-页面路由)。
- 单选 Artifact 时在该节点下方显示对应类型的输入区，使用与上方工具栏相同的锚定方式，跟随节点与视口移动并保持屏幕显示尺寸；文字输入区用于模型生成，文字工具栏用于进入节点内直接编辑；空选隐藏外置输入区，多选显示批量操作。Agent 直接在卡片内提供对话、历史与设置；长期配置指令与本次任务输入分别保存、提交。
- 顶部“资源”打开可搜索抽屉，可找回已移除的草稿与产物并重新放置；上传和导出也从顶部进入。选中对象的版本与引用放右侧。Agent 审批、关键帧、失败与 UNKNOWN 跟随当次 Run 嵌入对话；对应 Agent 卡片不在画布时保留全局处理入口。

## 顶部导航精简修订（2026-10-03）

用户明确要求缩薄顶部导航，并移除多余内容、“导入素材”按钮及其右侧抽屉。本修订替代原决定中从顶部上传的入口：导航改为紧凑单行，项目名保留，移除“创作画布”副标题和正常实时同步文案；连接、恢复、重试及保存状态仍可见。项目返回、资源抽屉和导出清单保留。

删除该入口专用的上传表单、分阶段重试状态和上传后新建节点逻辑。既有卡片上传、编辑器参考素材上传及个人资产库保持原入口；代价是画布顶部不再提供独立的素材上传并新建节点流程。不修改后端上传 API、归档、版本和任务边界，无数据库迁移。

## 连线流光与画布显示设置修订（2026-10-01）

2026-10-03 连线拖拽避让补充：按用户反馈，从节点端点拖拽连线期间隐藏节点工具栏、底部编辑区及多选批量操作条，避免浮层遮挡连线和目标节点。结束手势后按当前选区恢复，成功、无效落点及空白处放弃均执行恢复。选区与编辑器未保存输入保留，恢复不重新定位视口；图片扩展工具的临时面板沿用隐藏工具栏时关闭的现有规则。底部编辑器只隐藏而不卸载，以免丢失未提交 Prompt；无 API、数据库或依赖变更。

用户要求可切换的方向流光与连线显示，画布工具栏因此增加“画布设置”：默认始终显示连线并播放从来源节点到目标节点的流光；关闭始终显示时，仅选中节点的直接上下级连线可见，多选取并集，选中线保持可操作直到取消选择。关闭流光或系统减少动态效果偏好生效时保留静态关系样式。两个开关按当前账户和项目保存在浏览器中，刷新、重新进入及同源标签页同步恢复；这是个人呈现偏好，不修改项目关系、内容版本、引用和运行状态，也不进入项目导出或跨浏览器同步。存储不可用时保留本页选择并报告失败、提供重试。采用现有有向曲线路径的 SVG/CSS 流光，避免逐帧 React 更新，历史版本虚线及关系删除规则保留。此修订替代“尽可能关闭非必要连线动画”的原性能建议，不引入后端 API 或数据库迁移。

同日视觉修订：用户反馈硬边高亮的颜色和亮度过于一致。流光改为沿既有曲线移动的椭圆渐变遮罩，让高亮从透明边缘渐亮到中心，再渐暗回原关系颜色；起终点同步淡入淡出。原生 SVG 动画只驱动遮罩，不逐帧更新 React。遮罩按连线实例隔离，并为水平/垂直直线保留有效边界；系统减少动态效果开启时移除动画实例。

## Agent 对话呈现修订（2026-09-26）

本修订替代原决定中 Agent 使用底部通用编辑区、待办主要位于全局区域的呈现方式。用户希望直接在画布上的 Agent 卡片完成 AI 对话与接管操作，因此将本次指令、公开回复、动作与审批放到同一处；代价是卡片需要管理对话、历史、设置与可滚动消息区，同时必须保留卡片移除后的处理入口。

- Agent 卡片使用黑色聊天界面，顶部切换“对话 / 历史 / 设置”，底部填写并发送本次任务。2026-10-03 按用户要求取消二次确认：发送自动预检并创建 AgentRun，见 [ADR 0010 的发送修订](0010-persistent-agent-conversations.md#发送直接启动修订2026-10-03)。连续记忆与会话边界按后续 [ADR 0010](0010-persistent-agent-conversations.md) 修正：同一持久会话包含多条消息，新建会话才开始新的记忆。
- 只呈现成功模型回合的公开 `assistantText`、已提交工具执行的服务端业务摘要和持久任务状态。模型协议消息、完整工具参数/结果和私有推理不进入聊天；没有公开回复时不编造文本。工具动作保留提交时的业务状态，并明确这是历史记录；待审批提案不表示媒体已生成，当前进度以任务与审批卡片为准。
- 计划审批、关键帧选择、阻断和 UNKNOWN 重试嵌入所属 Run。Beautiful UI 的消息、任务行与审批示例负责外观，不决定业务状态、审批或执行。
- 输入绑定、模型与系统提示词版本预检、计划 hash、逐步骤确认、CAS、同项目单活动 AgentRun 与取消边界保持原规则。Agent 卡片移除不删除或取消其 Run；全局保底入口仍能处理缺少画布卡片的待办。

## 公共下拉框与设置样式修订（2026-09-30）

同日主色修订：用户要求系统主色改为参考按钮的蓝色 `#3D9AFF` 并禁止散落配置。后台、登录、项目与画布统一消费公共主题；主操作、选中、焦点与合法连接反馈采用同一品牌及派生色。输入关系线使用主蓝色，媒体派生线改为浅蓝色，引用灰色、Agent 输出绿色，关系删除规则保持原语义。实际画笔颜料、遮罩和图片引用身份色独立于主题。主色、悬停、前景与透明变体只在 `design-tokens.css` 维护，lint 检查业务 CSS 的品牌色硬编码；具体范围与证据见 [公共样式说明](../frontend-design-system.md#系统主色2026-09-30) 和 蓝色主题验证（开发记录不随源码公开）。

用户确认画布与后台设置共同参考 Beautiful UI，并禁止各处复制下拉框样式。单选控件共用 Select，菜单共用 DropdownMenu；视觉变量由公共设计文件维护，业务文件只保留布局与领域交互。设置页增加已保存配置摘要并共用表单、状态与图标容器。原生 select 保留标签、表单及校验能力，可见选项面板统一渲染并以屏幕坐标挂载，解决平台原生菜单样式差异与画布裁切；代价是需要维护键盘、焦点、禁用和选项刷新处理。该修订只改变前端呈现与菜单交互，既有持久化、CAS、生成授权与成本边界保持原规则。维护入口和验证范围见 [前端公共样式](../frontend-design-system.md) 与 验证证据（开发记录不随源码公开）。

## 调用记录入口修订（2026-09-26）

用户明确要求长期待核对调用不占据画布提示区。本修订将原来的全局 UNKNOWN 横幅及其账本处理入口移到 `/settings/calls` 调用日志页，并去掉画布上的日志入口：调用日志只从侧栏导航进入，进入后可按当前项目筛选。日志支持时间、响应耗时、Trace ID 等审计信息，历史缺失值不补造；仍保留原请求核对与显式风险确认的新尝试。真正待审计划和关键帧操作、Agent 对话中所属 Run 的状态保持可操作，没有待审计划时不绘制空审批横幅。此处只改变呈现与审计入口，不改变 UNKNOWN 的任务状态、配额占用、用量预留和重试语义。

## 调用日志只读修订（2026-09-26）

上一节把 UNKNOWN 处理入口迁入日志页的决定在同一天被推翻。日志里的“待核对”不是持久状态，而是查询时对写回失败调用行的投影：只要关联任务不处于运行中或提交中，历史记录就会一直显示该标签；而 LLM 调用记录没有关联任务 ID，展开后不存在任何可操作入口。因此 `/settings/calls` 改为纯只读审计，调用结果标签改为“未知”，不再承载 UNKNOWN 核对与显式风险的新尝试。恢复动作只在所属 Agent 对话和媒体卡片编辑区进行；代价是卡片移出画布期间没有全局 UNKNOWN 入口，这一点由用户明确接受。任务状态、配额占用、用量预留和重试语义不变。

2026-10-02 筛选入口修订：用户指出独立“刷新”与“筛选”重复，且相同或空条件下点击筛选没有重新读取会误导用户。因此移除“刷新”按钮，“筛选”统一负责校验并应用当前条件、读取最新第一页；即使条件未变化或为空也重新读取。读取期间禁用筛选和分页并显示更新状态，失败保留同条件旧记录及错误重试。日志仍只读，无 API 或数据库变更。

## UNKNOWN 重试简化（2026-09-26）

上一节保留的“原请求核对”在同一天被进一步移除。核对器只有 ComfyUI 一个实现，云端适配器不保存候选 ID、核对按钮对它们从不出现；而 ComfyUI 是本地生成、成本≈电费，核对省下的重复生成费用可以忽略。当时的 ComfyUI 单槽门禁只把“未被替代的 UNKNOWN”计入占用，因此删掉“必须先核对”的硬拒绝后，用户一次重试即可让原任务让出名额，消除了“核对查不到证据就永久卡住”的死锁。该单槽门禁又在 2026-09-28 整体移除。现在 UNKNOWN 只显示“结果未知”和一个重试按钮，不再有提交账本、原请求核对或重复成本勾选。

## 画布连线与删除交互修订（2026-09-27）

2026-10-01 入口视觉与悬停修订：按用户参考图，右侧添加连线入口和手势中浮现的左侧落点统一改为细线圆圈加号，替换方向箭头。2026-10-04 按用户反馈将静止圆圈从 22 放大到 32 个画布像素，右侧出口热区扩大为 60×64 个画布像素，降低点选与拖线难度。右侧入口在鼠标靠近时轻微跟随，激活距离不超过静止中心周围 28 个画布像素，总偏移最多 6 个画布像素；离开、按下开始拖线或取消时复位，触摸、拖动期间及减少动态效果偏好下保持静止。位移只作用于内层圆圈，外层几何盒及连线端点固定，命中范围覆盖圆圈全部位移且不侵入卡片。代价是入口占用稍大的卡片外侧空间；收益是清楚表达添加关系并提供有限的鼠标反馈。只修改前端呈现，无 API、迁移或依赖变化；显隐、手工拖线与合法性沿用以下规则。

用户连续确认了一组画布交互调整，替代本 ADR“画布交互”一节里的原始连线行为：

- **连接点只保留右侧，悬停或选中卡片时显示**（2026-10-04 修订）：鼠标移入未选中卡片即显示右侧添加连线按钮，可直接拖出连线，省去先点击激活节点；悬停本身不选择节点、不打开工具栏或编辑区。鼠标从卡片移向外侧按钮时保持可见；离开卡片及按钮命中区后隐藏，已选中卡片及正在拖出的出口继续显示。此修订替代原先“仅选中时显示”的要求。左侧落点与 Agent 输出组锚点保持原规则：左侧不可见也不接收指针，由距离判定成立，手势靠近时才浮现；Agent 输出锚点不绘制。无 API、数据库或依赖变化。
- **落点按卡片判定**：从右侧出口拖出后，指针落在卡片任意位置松手即可建立关系，不再要求对准左侧连接点；手势中指针所在的卡片显示高亮外圈（可建立为强调色、不可建立为红色），源卡片自身不作落点。贴近连接点的精确落点仍然保留。
- **双击空白画布只打开添加菜单**，不再缩放画布。
- Artifact 卡片标题双击后在原位置编辑；标题属于 CanvasItem 展示实例并使用画布项 `expectedVersion`，不修改 Artifact 身份或内容版本。同一 Artifact 的多张卡片可以有不同标题；保存失败或冲突保留标题草稿。
- **删除键**：选中卡片按 Delete 或退格移除卡片，选中关系线按 Delete 或退格删除对应绑定或引用；Agent 输出组线由输出组决定、必填场景引用只能替换，两者不可选中也不可删除。移除卡片不连带删除绑定与引用——Artifact 与内容版本仍在，关系依然有效。删除先写服务端，投影确认后画布才变化。
- **点空白、拖出选框、平移与缩放画布都取消选中**；应用自己发起的视口移动（例如“查看输出”后的适屏）不清除选中。按住 Cmd（macOS）或 Ctrl 点击卡片是追加选择，不覆盖已有选中；选中的唯一权威是应用状态，React Flow 的选中变更只作为增量输入。
- **关系线不再写文字说明**（“输入”“Agent 输出组”“素材引用 · 角色”）：关系类型只靠颜色与线型区分，绑定指向历史版本时蓝线改为虚线；引用角色与绑定版本从卡片详情与 Agent 配置读取。

代价：画布更安静、手势更宽容，但历史版本与引用角色不再直接写在线上，拖到卡片之外不再建立关系。实现与验收状态见 连接点证据（开发记录不随源码公开）、键盘删除证据（开发记录不随源码公开） 与 节点选中证据（开发记录不随源码公开） 的 2026-09-27 小节。

## 选择与手形工具修订（2026-09-27）

按用户确认，将选择和画布平移分为两个工具：默认选择工具，空白拖动框选，节点拖动仍移动未锁定卡片；短按空格切换并保持手形工具，长按则临时切换，松开或窗口失焦恢复此前工具。按住空格期间开始的指针手势始终是临时切换，即使快速释放也不保持手形。手形工具拖动只平移画布，不移动或缩放节点，也不发起框选和连接。右上角添加按钮旁提供工具菜单，允许持久选择手形工具；V 返回选择工具。文本编辑、输入法组合与组合快捷键不触发工具切换。

这项决定替代此前未区分工具的拖动交互。两种模式避免选择和画布平移争用手势；代价是用户需通过空格或工具菜单进入平移。用户发起平移/缩放仍按既有规则清除选择，程序化视口移动保持选择。

实现同时对齐节点点击容差和拖动阈值，避免微移既不触发点击也不启动拖动的空档。验收范围见节点选中证据，不以模式切换宣称所有偶发选择问题均已解决。

## 节点点击与拖动修订（2026-09-30）

按用户决定，节点点击和拖动使用不同的交互状态。指针移动未超过 3 屏幕像素时，松手后的点击选择节点并显示工具栏及编辑区；超过该阈值进入拖动，只提供被拖动节点的选中外圈，不打开工具栏、编辑区或多选批量栏。此前已经选中的节点开始拖动时也隐藏这些浮层。松手立即取消节点及关系线选择和临时外圈，不等待布局保存，也不把拖动后的 click 当成新的点击选择；后续独立点击正常选择。追加点击与框选保留原规则，多节点拖动结束批量保存所有移动节点，失败保留布局草稿并显示错误。无 API 或数据库变更。

## 框选与多选模式修订（2026-10-04）

用户反馈框选只包含一个节点时立即弹出工具栏和输入区，打断范围选择。选择模式因此不再只按节点数量决定：选中多个节点自动进入多选，范围框选实际选中至少一个节点时也进入多选，单节点范围同样适用。同日按用户反馈收紧触发条件，替代此前框选开始即进入多选的决定：新框选开始先清空旧选区并退出旧模式，空白微移和空范围拖动不进入多选；框选过程中缩回空范围时退出多选，结束时仅保留非空范围的多选。该取舍保留单节点框选的批量操作，同时避免空白手势打开所有卡片的复选框。此模式属于 Zustand 的临时交互状态，不改变业务数据或 React Flow 的受控选区来源。

多选时所有产物与 Agent 卡片左上角显示复选框，选中打勾、未选为空；复选框可增减节点并隔离节点拖动及画布手势。多选隐藏单节点工具栏、缩放手柄、下方输入区和自动定位；有选区展示既有批量操作条，一个节点时禁用左对齐。框选手势之外，通过复选框或 Cmd/Ctrl 追加点击将选区减少到一个或零个节点仍保持多选，避免再次意外弹出输入区；空选区隐藏批量条但保留复选框。普通点击节点明确退出多选并聚焦该节点；空白点击、Esc、关闭批量条、节点拖动结束或用户平移沿用清空选择流程并退出多选。代价是多选会在未选卡片上增加一个选择入口，收益是框选与追加选择的模式和状态可见。无 API、数据库、依赖或任务语义变化。

多选外框不接收指针，以免覆盖选区范围内未选卡片的复选框或普通聚焦点击。它保留边框提示；移动整组从已选卡片的可拖动区域开始，继续复用现有批量布局保存。

关闭只抑制当前错误实例的显示，保留请求状态、幂等重试上下文和草稿，后续新的失败重新显示；不清除持久任务错误，不触发模型或媒体重试。快照/画布读取失败和设置保存失败保留显式重试。Agent/媒体任务失败继续由各自卡片与对话展示，不把节点错误统一提升为全局提示。沿用现有 API，无迁移或依赖变更。

## 多选操作条排版修订（2026-10-03）

按用户反馈，Agent 一键选中输出后的批量工具栏替换旧宽幅编辑面板，使用与节点工具栏一致的紧凑圆角横向表面、主题颜色、32px 公共按钮和 Phosphor 图标。数量与动作、关闭按钮用公共 Separator 分组，关闭按钮参与横向布局，避免绝对定位挤压或覆盖内容。长语言文案允许操作组换行，外层保持视口内居中。

输出产物选区只显示适用动作，恰好包含一个 Agent 的混合选区才展示绑定与清空输入。关闭取消选择、拖动隐藏、批量布局保存和原绑定校验规则保留；不新增生成、内容修改或删除动作，不改变 API 或数据库。

同日左对齐避让修订：用户反馈同一行的多张卡片左对齐后重叠。统一横坐标前按当前纵坐标、横坐标及节点 ID 稳定排序；统一到选区最左侧后，仅把纵向间距不足的卡片向下顺延，保留实际显示高度及一键整理的 120 画布单位间距。原本足够的纵向间距保留，同一行按从左到右的顺序排列为一列。优先使用本地布局草稿和媒体尺寸投影，未选节点不参与；代价是横向选区会增加纵向占用空间。批量 CAS、失败保留草稿和内容边界沿用现有实现，无 API 或数据库变更。

## 空白画布右键菜单与一键整理修订（2026-10-03）

按用户图稿，空白画布右键提供添加、上传和一键整理。添加级联展示图片、视频、文字、音频，复用原节点创建流程和右键画布坐标；双击及“+”的原菜单继续保留 Agent 入口。按用户随后确认的交互，上传直接打开系统本地文件选择器，选完图片、视频或音频即上传并在右键位置创建新节点，以文件名（去扩展名）命名；取消不创建。上传不依赖抽屉，等待与失败显示在画布，显式重试固定原始落点、创建命令和节点身份并复用已确认阶段，避免重复产物。菜单遵循现有主题与公共菜单组件，支持悬停、键盘、关闭及视口边缘避让。

整理按完整关系图的相连分组和有向先后顺序排列，每行最多五个节点，间距取实际卡片尺寸；无连线节点也参与，环形关系按既有空间顺序选定起点。锁定节点不移动，可移动节点放在锁定节点下方，避免覆盖。保留原内容、选择版本、草稿、关系和分组，只通过既有布局 CAS 保存。API 每批最多 100 条命令，超过时顺序分批；后续批次失败时已成功批次保留，未保存布局保留为草稿并提供现有失败/冲突提示。这一取舍沿用现有事务边界，不为大画布新增后端布局接口。

同日定位补充：按用户要求，一键整理在所有布局批次保存成功后将整理顺序中的第一个可移动节点居中显示，保留当前缩放比例和空选区，不打开编辑浮层。第一个节点由整理算法输出顺序确定，中心使用已保存位置和实际展示尺寸，避免依赖 API 列表顺序或尚未同步的 React Flow 节点位置。任何批次失败或无可整理节点时不自动移动视口，保留现有失败反馈与布局草稿；无 API、数据库或依赖变更。
