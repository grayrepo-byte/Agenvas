# ADR 0057：导演直接写入分镜制作台

状态：接受；实际验证范围见开发清单。

用户要求导演把剧本拆解结果直接保存到分镜制作台，并支持按镜头修改，媒体生产继续原审批。ADR 0054 的正式分镜仍保存为 TEXT，ADR 0056 新增的持久镜头只支持用户编辑和显式 JSON 导入；两者之间需要手工搬运。决定为内置导演增加 `read_storyboard`、`write_storyboard_shots`，复用分镜应用服务和不可变修订，以受限的创作字段补丁连接两种工作流。

本决定替代 ADR 0054「正式分镜只保存普通 TEXT」以及 ADR 0056「正式镜头由用户操作或导入建立」的边界。原有剧本阅读、拆解、视觉设定、连续性、提示词、审校和公开进度继续作为辅助 TEXT；已有文字不会隐式转板。导演完整分镜任务先读实际来源和当前板，再按场次持续写入正式镜头，不把文字卡或首批结果当成全任务完成。

`read_storyboard` 默认返回分页目录，offset 从 0 开始，limit 默认 20、最多 40；调用 `shotIds:[单个UUID]` 才返回完整单镜及其制作关联和精确选用。返回的板版本供全板 CAS 使用。目录有界、完整单镜按需读取，避免将整张大板和全部文字注入每个模型回合。板中出现来源或参考 ID 不授予正文/媒体读取权；实际内容读取仍按当前画布或显式 Skill 精确输入授权。

`write_storyboard_shots` 每批 1–6 镜，带 `expectedVersion`。新镜由服务端分配 UUID，必须填写唯一 `code`、`description`、`dialogue`、`durationSeconds`，可附场次、标题、精确 TEXT 来源和媒体参考。已有镜头按 `shotId` 仅修改所给创作字段；未提供字段、其他镜头、顺序、制作关联、精确选用和成片从当前板原样保留。新建或改变引用须满足同项目、内容类型及当前画布/显式 Skill 的精确授权；保持的既有引用不会扩大 Run 权限。模型不能提交制作状态或复核断言，不能删除、重排、修改选用或核销待复核。

采用服务端合并并复用既有全板保存命令，而非让模型重交完整板。这样保留用户的制作状态，也继续使用全板版本冲突保护。修改单镜前先读取目标完整内容及最新板版本；并发冲突重新读取并核对，不用旧快照覆盖。镜头创作变化按 ADR 0056 递增受影响镜头修订，保留旧结果并标记待复核；其他镜头不变，成片依据变化标记成片待复核。Agent 无权确认结果语义适用，用户仍在制作台审看。整批写成功后才根据返回的板版本、真实镜头 id/code/revision/needsReview 与 `compositionNeedsReview` 更新公开进度。

板保存、项目事件和持久工具执行复用原事务及账本。成功重放复用已提交结果，不追加第二次板修订；失败不留下部分镜头。工具不创建媒体草稿或 Task，也不批准媒体。导演需要真实媒体时仍通过 `propose_media_generation` 提出固定批次，由用户按原费用、期限和 CAS 整体批准或拒绝；UNKNOWN、取消、过期不自动重新生成。

长任务的公开上下文压缩只为这两个工具保留有界镜头 ID、镜号、修订、历史板版本及读取游标，并明确提醒写前重读当前板版本；不扩大通用字段白名单，不保留旧创作正文或将历史 CAS 当成当前状态。聊天的「剧本拆解与分镜」入口同步请求正式镜头落板，点击仍只填写可编辑草稿，不创建 Run 或授权媒体。

新 Run 冻结的工具允许列表增补这两个工具，旧 Run 的列表保持原样；恢复不能因当前目录变动获得新能力，已冻结模型请求的技术重放继续还原原消息与有序工具定义。工具策略/schema/系统提示词版本仍为 6/7/14，以 Run 冻结的工具名集合约束增补能力，技术规则仅在该 Run 具备新工具时附加。此次不改变 HTTP/OpenAPI、独立 MCP 目录、数据库 schema、依赖或 jOOQ。

V37 只升级仍精确匹配 V34 默认正文或初始化首尾空白归一化形式的全局 `agent.director` 与已有项目导演。改名、说明、自定义正文保留；项目行锁先于导演行锁，每个实际变更的导演才递增配置版本及同事务项目事件。冻结 Run、会话、Task、审批和分镜历史不改写。后续普通全局默认词编辑仍只影响新项目初始化，不形成持续同步；自定义导演可自行合入新创作流程。

升级验证使用真实 PostgreSQL，覆盖全新安装、36→37、精确匹配、自定义保留、事件失败整体回滚和重放幂等。合成模型/剧本只证明指令、工具、权限与持久化行为；真实剧本理解、按镜修改质量和真实 Provider 效果另列验收。

合并 develop 后，分镜建表迁移顺延为 V36，本项尚未发布的默认指令迁移由原 V36 顺延为 V37；V34 的旧导演流程迁移与正文保持不变。上述验证范围是本项设计要求，合并前专项结果与本轮整合验证在开发清单分别记录。
