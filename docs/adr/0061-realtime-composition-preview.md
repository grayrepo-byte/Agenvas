# ADR 0061：浏览器成片实时预览与只读配音时间表

在 ADR 0050 的有界视频剪辑配方上增加连续成片实时预览和时间线双端裁切。浏览器使用同一30fps时间模型解释裁切、变速、淡黑、配乐、字幕和输出画幅，以原生视频为时钟同步音轨；帧位置属于临时审看状态，编辑草稿仍是导出请求的来源。选择浏览器即时合成，避免每次拖动、音量或字幕编辑都触发服务端编码；预览与最终FFmpeg在字体栅格化、音频变速、限幅和编码上允许实现差异，界面据实说明，不承诺像素或采样逐点一致。

自动配音的位置依赖服务端声音活动分析，浏览器不自行猜测。新增只读预览时间表入口，复用导出授权、声音分析和规划，在事务外执行，并限制并发、时长与临时空间；返回时间和字体，不创建任务、内容、事件或用量。客户端防抖读取；无配音时用首个精确视频的固定最短前缀读取服务端字体，不随裁切或字幕编辑重新分析声音。配音配方变化立即失效旧计划，未就绪或失败时不播放过期配音。最终导出仍独立冻结、重新授权、编码并测量完整音频，试听计划不替代结果验收。

时间线裁切采用源区间与整帧成片预算的映射，触屏、指针及键盘共用约束；取消手势恢复区间。字幕保留成片绝对时间，裁短后的越界须由用户修正。视频主轨顺序拼接、单条配乐及定时字幕的边界保持，不扩展为自由多轨、特效库或新的媒体生成服务。

时间线进一步使用源帧胶片条。常规缩放间隔采样，逐帧缩放与30fps成片网格一一对应；只解码可见帧，单个独立静音解码器串行工作并缓存有限缩略图，不借用或跳转主播放器。空闲释放媒体读取，取消或关闭清理请求和图片URL；该投影不归档新素材，也不改变冻结配方或导出接口。
