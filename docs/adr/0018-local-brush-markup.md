# ADR 0018：画笔标注直接编辑图片，不调用 AI

状态：接受（2026-09-30）。取代 ADR 0015 中将画笔标注作为文字驱动 AI 操作的决定；派生节点遵循 ADR 0017。

用户明确指出画笔标注应是简单图片编辑器：在原图上操作，点击保存后出现编辑派生节点。文字说明交给模型生成标注不能满足这一行为。

画笔标注提供浮动颜色盘与图标工具栏：画笔、橡皮、矩形、箭头、文字、笔刷大小、撤销、重做和保存。浏览器保留独立标注层，橡皮只擦除标注，不修改原图；预览使用有界分辨率，保存重新按原图像素尺寸绘制并合成 PNG。关闭不保存。图层仅在本次编辑中存在，保存后的结果是普通图片，不是可继续编辑的多层工程文件。

保存先通过现有私有图片上传接口归档并执行实际 MIME、大小、像素与解码检查，再以 `upload-version` 的 `purpose=BRUSH_MARKUP`、固定 `sourceVersionId`、`expectedVersion` 和独立 `targetItemId` 提交。服务端不调用能力目录、Provider 或任务服务；同事务创建新 CanvasItem、空白媒体草稿、不可变 USER ArtifactVersion 和可删除 MEDIA_DERIVATION。版本的 `baseVersionId` 及带 schemaVersion 的 `frozenInput` 保留精确来源与操作，来源节点、来源草稿及资源默认版本不变。

编辑开始固定来源；SSE 刷新不替换编辑原图。保存时来源当前选用版本和节点 CAS 必须匹配，否则返回 409，前端保留标注并提示重新基于当前图片开始。上传成功后的重试复用 Asset 和目标 ID，相同目标、内容、用途和来源重放原结果，不同负载不得复用结果。

OpenAPI 从 `RunImageOperationRequest.operation` 移除 `BRUSH_MARKUP`，上传接口新增可选用途与标注来源字段。旧 AI 标注请求返回 400；前后端同时升级。已有归档版本与历史 Task 保留，不重新提交旧任务，不新增数据库迁移。该功能不产生模型调用或费用记录。
