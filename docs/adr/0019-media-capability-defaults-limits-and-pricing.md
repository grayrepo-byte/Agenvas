# ADR 0019：媒体能力的默认参数、输入限制与估算价格

- 状态：接受
- 日期：2026-09-30
- 依据：用户要求补齐能力发布中的模型选项、API 地址、默认生成参数、价格、视频时长和参考图限制。

## 决策

固定适配器继续定义协议、支持的参数集合和硬上限。管理员可以为每个发布能力配置默认生成参数、在固定协议范围内收紧视频时长与参考图数量，并设置估算单价。配置保存于既有 `media_capability_version.spec_json.settings`，修改仍采用 CAS、不可变版本、映射摘要及幂等发布。

图片默认参数包括画幅、分辨率、画质、透明背景与生成数量；只接受当前适配器支持的参数。视频默认参数包括画幅及默认整数秒时长；默认时长必须处于配置后的时长区间。草稿明确保存的字段优先，未填写字段使用所选能力的默认值。已有草稿不被后台配置主动改写或裁剪；超出新限制时用户需要调整，服务端拒绝运行。受理任务固定有效参数、能力版本和价格。

估算价格由十进制字符串金额、CNY/USD 币种及计价单位组成。图片按张计价；视频可按个或按秒计价；最多六位小数。每个批量图片任务分别预留一张费用，界面展示整个批次的估算。价格缺失保留未知，显式零与未知区分。任务快照的 `mediaPricing` 供预留、结算及取消释放账本使用，`costStatus=ESTIMATED`、`costSource=ADMIN_CONFIGURED`，实际费用没有供应商报告时仍为空。它不代表供应商账单、自动扣款或花费封顶。本地处理继续为已知零。

沿用 ADR 0008：OpenAI 与 Google 可编辑协议兼容模型名称及 API 根地址；模型为空时使用内置默认。Google 平台和适配器在界面明确标注 Nano Banana 2。Seedance 仍使用已有固定模型、API 路径与结果下载约束，设置页明确展示只读模型和地址，不声称支持任意视频协议。

## 数据与升级

OpenAPI 增加 `model`（修正已有实现遗漏）、默认参数、限制和 `MediaCapabilityPricing`，同步生成 TypeScript。既有 JSON 行无需迁移，也没有 jOOQ 生成变更。未配置新增字段的历史能力保留编译上限、既有默认参数和未知价格；旧任务没有 `mediaPricing` 时账本继续保持未知。价格不进入任何凭证或 API Key 字段。

## 验证

见 [媒体能力配置证据](../evidence/media-capability-configuration.md)。本轮没有真实云端付费调用；Mock 与假 HTTP 结果不证明真实供应商支持、效果或计费。
