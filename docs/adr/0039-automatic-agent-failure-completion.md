# ADR 0039：自动结束已结算的 Agent 模型失败

模型回合已经 FAILED 时，原实现仍将 Run 留在 BLOCKED 并占用项目，用户必须额外点击结束才能继续创作。按用户决定，无法继续的模型错误、参数修复耗尽及历史数字回合限制在所有 Task 已结束且媒体审批已结算时，将 Run 自动转 FAILED、释放活动槽位并保留输入、错误原因及已有产物；临时模型故障继续执行现有重试规则。

模型调度器以有界身份列表核对历史 BLOCKED 运行，并在每个项目事务内重读状态、当前步骤失败 Task、全部 Task 和审批，确认结算后使用版本与槽位条件更新。若存在 UNKNOWN、BLOCKED、排队或执行中的 Task，或审批未结束，运行继续保持 BLOCKED；这避免自动收尾掩盖外部受理不确定性。核对只结束旧运行，不续接模型、重发媒体、改写原请求检查点和冻结策略，也不能释放新的 Run 槽位。前端沿现有 SSE 与快照恢复发送并保留草稿，明确提示已自动结束。无数据库迁移或新增端点，更新规格 §8.3 和对话流式设计；ADR 0038 的历史策略冻结与不自动重发原则继续适用。
