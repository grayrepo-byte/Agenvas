# ADR 0052：裁剪音频片段以复用音色参考

状态：接受。

用户需要将视频中的声音提取出来，再截取适合的片段用于 H3 音色参考。视频音频分离和音频精确版本引用已经存在；补齐 AUDIO → AUDIO 裁剪即可形成画布上的完整流程。

## 决定

音频卡片提供“裁剪音频”，打开时固定来源版本、节点版本和素材。用户通过真实波形、播放位置、起止时间和片段试听选择范围，提交后以持久 Task 在服务端本地处理。默认选取开头最多 15 秒，用户可修改；通用裁剪不把 H3 的输入限制当作所有音频的限制。

裁剪输入使用整数毫秒，范围为 `[startMs, endMs)`，至少 100ms，且不得超过来源实际时长。来源仍受现有音频上限约束：10 分钟、50MiB。输出可选 WAV 或 MP3，默认 WAV；固定 48kHz 双声道，分别使用 PCM16 和 192kbps。受理前按输出时长预估 50MiB 文件上限，超限需缩短范围或改选 MP3，不静默截断音频。执行时用固定 FFmpeg 参数裁取、重置时间戳，并校验输出完整解码和采样长度。

当用户明确选到来源末尾时，容器时长的毫秒取整或编码填充可能比可播放声音稍长。仅该情况允许通过完整解码来源，再核对成品采样数确认真实尾点；PCM 的差值上限为 1ms，MP3/Opus 为 300ms，成品仍须至少 100ms。结果保留 `requestedEndMs` 和实际 `endMs`，中间区间继续严格校验请求采样长度，不补静音或接受任意短输出。

沿用 [ADR 0017](0017-operation-specific-media-versioning.md)：同类型编辑为同一 Artifact 下的独立派生 CanvasItem 和不可变结果版本。新节点草稿为空，记录可删除派生线与精确来源；不改变原节点选用和资源默认版本。网络响应丢失后原键重放，异参冲突；目标删除、内容选择或草稿变化时仅保留结果历史。

`LOCAL_AUDIO_TRIMMER` 使用现有 Worker、租约、心跳、私有临时目录、大小/时间上限与 Asset 归档；记录 `LOCAL_NO_COST`，不调用 Provider。READY/RUNNING 可立即取消，SUBMITTING 持久化取消请求，由本地处理器停止。取消后的晚到结果仅保存历史，过期恢复和显式新尝试沿用现有本地合成的边界。外部生成的取消规则不变。

REST `POST /api/v1/projects/{projectId}/artifacts/{artifactId}/audio-trims` 使用现有用户 Session、CSRF、项目鉴权与来源节点 CAS。V32 插入本地能力种子，复用本地连接。闭环回归发现已有视频归档允许 10 分钟，但数据库仍保留 60 秒 CHECK；V33 将该约束同步至 ADR 0050 已确定的 10 分钟来源上限，保留现有数据及各模型/成片的独立限制。通过一次性 PostgreSQL 重新生成 jOOQ，不修改旧迁移。

## 使用与边界

1. 视频节点通过“音频分离”得到音频节点。
2. 音频节点裁出同一人物清晰说话的片段，试听并生成音频片段。
3. 在 H3 全能参考视频草稿中通过已有素材选择或连线引用该片段，配合人物图和本镜台词使用。模型适配器继续校验自身的音频格式、时长、数量和总时长限制。

音色参考仍是一份普通的不可变音频版本，不新增声纹或音色模型实体。裁剪保留所选区间的所有声音，不进行人声/音乐分离、降噪、说话人识别或音色训练。多个人声或背景音乐需要选择更合适的来源/区间。本次提供画布与 REST 入口，不把 UI 闭环记为 Agent 自动闭环；后续内置 Agent 的提音、裁剪工具及持久续接由 [ADR 0053](0053-builtin-agent-local-media-workflow.md) 单独扩展，MCP 入口保持原范围。

验收范围见开发清单；合成媒体测试和本地 FFmpeg 成功不代表真实 H3 已接受新片段或音色相似度通过人工听验。
