# ADR 0016：媒体节点固定单一结果，变更一律派生新节点

状态：接受（2026-09-30）。图片和视频 CanvasItem 不再提供多版本选择，也不让生成、上传或后处理覆盖来源节点；每个媒体内容变更先创建具备同类完整能力的结果 CanvasItem，任务只把结果固定到该节点。底层 ArtifactVersion 继续作为不可变审计、任务恢复和精确输入引用记录，但不再是媒体节点上的版本管理界面。

媒体派生关系仅提示“这个结果从哪个节点发起”，不进入草稿或执行依赖，并允许用户删除。删除后两个节点没有特殊关系；用户之后从图片来源重新连向结果节点时，创建普通 `MEDIA_INPUT` 参考关系，而不是恢复派生关系。空媒体节点尚无可追溯内容时也会创建结果节点，但不创建派生线。

这一决定用更多画布节点换取稳定引用和更简单的心智模型：已有引用永远指向不会原位变化的节点结果，分支在画布上直接可见；代价是 Artifact 仍需在后台保留不可变记录，且需要自动放置与节点整理能力。
