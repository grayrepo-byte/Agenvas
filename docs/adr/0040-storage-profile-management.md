# ADR 0040：存储连接编辑与删除

状态：接受。用户要求已保存的 OSS 连接能够编辑、更新和删除，解决错误 Region 等未使用配置无法修正的问题。本决定替代 ADR 0023 中“所有位置字段保存即固定、所有连接禁止删除”的限制；历史素材固定位置、凭证加密与归档恢复规则继续适用。

连接未被引用时，管理员可以修改名称、类型、Endpoint、Region、Bucket、对象前缀与寻址方式，也可以删除。已有归档记录（包括未完成归档）、中继副本或任务视频输入引用时，连接位置固定，拒绝改位置或删除并返回 `409 STORAGE_PROFILE_IN_USE`；名称与凭证仍可更新。任务终态也保留引用，以保护历史输入及显式新尝试。判断不依赖当前默认选择或前端状态。

更新凭证可省略两项以保留原密钥；更换时必须同时提供 ID 与 Secret，以新的凭证版本重新加密并绑定同一连接身份。响应只含掩码。OSS Region 使用 `cn-chengdu` 等区域 ID；新增或更改区域时拒绝 `oss-` 前缀，旧错误区域仍可在未使用时修正，不自动改数据库。

更新和删除使用存储设置的 expectedVersion/CAS、设置行锁及连接行锁。归档固定目标在短事务中取得相同设置行锁；本地视频任务受理读取中继时加入受理事务并保持此锁至输入落库。管理操作不能在引用检查与引用提交之间改写或删除位置。网络、媒体解码及云端操作均在这些事务之外。

删除只移除未引用的配置，不调用云端删除对象。若连接仍被选作默认归档或媒体中继，同事务清空相应指针并递增设置版本，后续归档回到本地、中继关闭；其他选择不变，不自动挑选其他云连接。前端删除确认固定打开时的版本，等待禁用重复提交，失败保留窗口，冲突须显式加载最新配置后重新确认。编辑失败保留非密钥草稿并清空临时密钥。

OpenAPI 新增 `PUT/DELETE /api/v1/settings/storage/profiles/{profileId}`，状态增加只读 `inUse`；同步 Java、生成 TypeScript、四语言界面和契约测试。没有数据库结构变更、迁移或历史对象搬迁，前后端应一同更新。
