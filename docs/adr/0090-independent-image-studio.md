# ADR 0090：独立生图工作台与显式结果归档边界

状态：接受（2026-11-19，用户已确认独立工作台及不传画布节点）。

## 决策

新增主导航 `/image-studio`，直接提供静态图片生成、参考图上传、能力参数、批次历史与私有结果预览/下载。新 API 不接受节点 ID，不复用画布草稿受理，不创建隐藏节点，也不要求选择用户项目。首版目录仅包括已验证的 Mock、GPT Image 2 与 Nano Banana 2 静态图片路径；动态工作流、蒙版与局部重绘不迁移。

现有任务、事件、媒体资产、不可变版本与所有权均以项目为技术边界。为复用这些已存在的边界，项目追加 `purpose=CANVAS|IMAGE_STUDIO`，旧项目默认 CANVAS；通过部分唯一索引保证每位所有者一个内部 Studio 作用域。内部作用域不出现在项目列表，并拒绝普通项目管理、快照、画布与 Run 入口；内部任务和资产继续使用既有所有者校验。用户无需了解或选择该作用域。

独立批次命令表保存幂等键、请求摘要与固定参数；任务成员与所有任务、目标和用量预留同事务提交，完整批次可在刷新后重新读取。Task 仍是每个执行结果的状态真相。参数根据能力校验并固定版本；AUTO 比例在 Studio 中显式转换为 1:1，不继承画布设置。普通数量维持 1/2/4；不再次拆分供应商原生额外结果。

图片参数准备中的通用规则可由画布与 Studio 共用，但节点身份、版本选用与布局留在画布路径。Task 输入显式 `executionSurface=IMAGE_STUDIO`；归档与画布投影分开，Studio 的主结果和额外结果均只生成不可变 ArtifactVersion 与私有 Asset。旧画布生成保留节点归属、版本、选用与多输出落位契约。

上传必须实际解码并遵守已有大小、像素和静态图限制；只冻结所有者作用域内的不可变参考版本与资产，不接受任意 URL。浏览器结果仅暴露私有归档身份。轮询只读已有任务；UNKNOWN 不能自动重新提交。同步图片响应的完成检查点与已保存字节用于恢复归档，恢复不能调用生成或供应商查询；完成已确认但字节无法恢复时明确阻塞，用户只能显式创建新的生成命令。此恢复边界从适配器已返回完成响应开始；若客户端在适配器返回前读取供应商临时结果失败，仍按既有 UNKNOWN 保守处理，不自动查询或重发。

## 取舍

工作台在收到回执前按冻结请求预留输出位置，受理后用批次 ID 和有序任务替换占位。优先给每个请求任务保留主结果编号，再追加供应商返回的额外图片，以便后完成的任务或原生多图结果仍能和用户看到的位置对应。完成计数取自已经归档的结果。

内部项目是现有存储和权限范围，不是隐藏画布。保留它避免在首版同时重构全部 Task、Asset、Artifact、事件和用量外键。未来若其他独立创作工具需要共用作用域，再以真实需求评估通用工作区模型。本次不新增部署服务、队列系统或前端站点。

完整设计与验收范围见 [独立生图工作台设计](../image-studio-design.md)，分步实施见 [实施计划](../image-studio-plan.md)。
