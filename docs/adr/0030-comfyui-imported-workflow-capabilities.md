# ComfyUI 能力由管理员导入 API 工作流并映射发布

2026-10-04，用户确认原来的模型文件表单把 ComfyUI 限制在内置图中，无法发布自己已经准备好的工作流；因此改为管理员导入 ComfyUI API JSON、按实际节点映射画布输入并选择输出后发布，保留既有受控 HTTP 协议与持久任务管线。工作流的节点、连线、固定参数、输入映射和输出规则组成不可变能力版本，普通用户与 Agent 只能向该版本提供声明的输入；这局部取代 ADR 0002、0008 对自托管 ComfyUI 固定图的限制，不改变 AutoDL 与 RunningHub 的协议。

## 后果

- 不再用项目内的节点类型或模型文件字段白名单限制管理员导入的图；节点和模型须已安装在管理员配置的 ComfyUI 实例上。导入只解析和校验，不安装节点、查询远程模型或提交生成。
- 新能力必须携带 `comfyWorkflow`，按节点输入映射可选提示词、种子、尺寸、参考图与视频时长等固定语义；管理员也可明确开放标量扩展参数，其余输入作为固定值。参考图片编号连续且全部必填，不静默省略；映射与扩展参数都必须位于所选输出的依赖路径上。
- 任务固定能力版本、全部有序素材和实际画幅；后续编辑能力或项目画幅不修改已受理任务。结果只从所选节点与字段读取，单任务只归档一个匹配媒体，继续沿用 UNKNOWN、显式重试与归档恢复规则。
- 既有固定图能力和历史任务仍按原版本执行、恢复；管理员编辑旧能力时须导入图后发布新版本，无需数据迁移。普通用户与 Agent 的请求不能携带图、节点类型、文件路径或外部地址。
- 当前支持图片输出 PNG/JPEG/WebP 与视频输出 MP4，不声明音频、透明背景、蒙版或视频/音频输入支持。合成图与假 HTTP 测试不证明真实节点、GPU 或模型兼容性；部署者须在自己的实例上验证所发布的图。

## 统一编辑栏与扩展参数（2026-10-04）

用户要求 ComfyUI 与 RunningHub 的编辑栏保持普通模型的资源缩略图、提示词和底部配置布局，避免未知工作流字段挤占提示词区域。图片映射编号对应具名资源槽位，槽位数量即允许的图片输入数量；管理员选择文本输入作为共享提示词，未声明提示词的能力仍可发布，画布保留置灰提示词区。LoRA、seed 等其他开放标量通过底栏“扩展参数”表格弹窗编辑。

管理员将输入声明为 `comfyWorkflow.parameters`，复用有界标量字段描述，但只允许 PARAMETER 来源和原生标量注入。目标节点和输入名固定，类型、默认值、范围和枚举与原图标量一致；缺少默认值沿用原图值，稳定键与目标均唯一且不与语义映射重叠。普通目录只返回服务端生成的安全 `comfyInputs`，不返回图；草稿只能提供已声明的值，运行固定有效参数和能力版本，并向图副本注入。该变更不允许普通用户修改图、连线或未开放输入。

空语义映射与没有提示词映射的图片工作流有效，视频仍要求时长或帧数映射。现有定义省略 `parameters` 时保留固定值和历史任务恢复；无需数据库迁移，OpenAPI、生成 TypeScript、前后端必须一起升级。本轮合成表单与协议验证不代表真实节点或模型兼容性。
