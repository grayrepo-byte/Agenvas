# ComfyUI 能力由管理员导入 API 工作流并映射发布

2026-10-04，用户确认原来的模型文件表单把 ComfyUI 限制在内置图中，无法发布自己已经准备好的工作流；因此改为管理员导入 ComfyUI API JSON、按实际节点映射画布输入并选择输出后发布，保留既有受控 HTTP 协议与持久任务管线。工作流的节点、连线、固定参数、输入映射和输出规则组成不可变能力版本，普通用户与 Agent 只能向该版本提供声明的输入；这局部取代 ADR 0002、0008 对自托管 ComfyUI 固定图的限制，不改变 AutoDL 与 RunningHub 的协议。

## 后果

- 不再用项目内的节点类型或模型文件字段白名单限制管理员导入的图；节点和模型须已安装在管理员配置的 ComfyUI 实例上。导入只解析和校验，不安装节点、查询远程模型或提交生成。
- 新能力必须携带 `comfyWorkflow`，按节点输入映射可选提示词、种子、尺寸、参考图与视频时长等固定语义；管理员也可明确开放标量扩展参数，其余输入作为固定值。参考图片编号连续且全部必填，不静默省略；映射与扩展参数都必须位于所选输出的依赖路径上。
- 任务固定能力版本、全部有序素材和实际画幅；后续编辑能力或项目画幅不修改已受理任务。结果只从所选节点与字段读取，单任务只归档一个匹配媒体，继续沿用 UNKNOWN、显式重试与归档恢复规则。
- 既有固定图能力和历史任务仍按原版本执行、恢复；管理员编辑旧能力时须导入图后发布新版本，无需数据迁移。普通用户与 Agent 的请求不能携带图、节点类型、文件路径或外部地址。
- 当前支持图片输出 PNG/JPEG/WebP 与视频输出 MP4，不声明音频、透明背景、蒙版或视频/音频输入支持。合成图与假 HTTP 测试不证明真实节点、GPU 或模型兼容性；部署者须在自己的实例上验证所发布的图。

## 统一编辑栏与扩展参数（2026-10-04）

用户要求 ComfyUI 与 RunningHub 的编辑栏保持普通模型的资源缩略图、提示词和底部配置布局，避免未知工作流字段挤占提示词区域。图片映射编号声明具名资源槽位，已分配素材显示具名缩略图，槽位数量即允许的图片输入数量；管理员选择文本输入作为共享提示词，未声明提示词的能力仍可发布，画布保留置灰提示词区。LoRA、seed 等其他开放标量通过底栏“扩展参数”表格弹窗编辑。

管理员将输入声明为 `comfyWorkflow.parameters`，复用有界标量字段描述，但只允许 PARAMETER 来源和原生标量注入。目标节点和输入名固定，类型、默认值、范围和枚举与原图标量一致；缺少默认值沿用原图值，稳定键与目标均唯一且不与语义映射重叠。普通目录只返回服务端生成的安全 `comfyInputs`，不返回图；草稿只能提供已声明的值，运行固定有效参数和能力版本，并向图副本注入。该变更不允许普通用户修改图、连线或未开放输入。

空语义映射与没有提示词映射的图片工作流有效，视频仍要求时长或帧数映射。现有定义省略 `parameters` 时保留固定值和历史任务恢复；无需数据库迁移，OpenAPI、生成 TypeScript、前后端必须一起升级。本轮合成表单与协议验证不代表真实节点或模型兼容性。

2026-10-04 后续用户要求资源栏与全能参考一样，只保留一个共享添加入口，已声明但未使用的槽位不再各自显示上传框。上传、资源库、画布或个人资产选择的图片按参考图编号自动分配第一个活动且同类型的空槽位；没有活动空槽时禁用入口，不新增槽位选择弹窗。共享上传归档完成时重新核对活动空槽，期间被画布连线填入的素材不被覆盖；若同类型槽位已满，保留归档结果并提示用户移除素材后显式重试，不重复上传字节。已分配缩略图保留具名替换与清空，同一精确版本可供多个槽位复用；类型、数量、条件、必填、CAS、运行锁定及上传失败重试边界不变。当前仍只接受声明的图片输入，共享入口不放开视频或音频输入。此次调整沿用现有个人资产 `slotKey` 和其他 API，无合约或数据库迁移变更。

## 发布表单简化（2026-10-04）

用户确认发布表单的横排标签容易换行，长 API JSON 会遮住解析操作；基础宽高也容易被误认为决定实际输出。因此标签改为位于控件上方，JSON 输入限制高度并在框内滚动，结果配置移除基础宽高控件。检查页保留默认参数、映射、结果与价格摘要，取消核对复选框及核对快照门禁；有效配置可通过底部按钮明确发布或保存，编辑不会自动提交，校验、鉴权、版本冲突与失败草稿保留不变。

v1 合约与运行时仍保留 `width`、`height` 作为比例映射的技术基准。首次添加 WIDTH 或 HEIGHT 映射时取目标输入的数值，同来源的后续映射复用已有共同基准；打开既有能力与无关编辑保留已存值。移除某来源最后一个尺寸映射后，其未使用的技术基准恢复为 v1 默认值 1024，固定图保持原值，避免残留无效基准阻断发布。未映射尺寸时，技术默认值不注入工作流；实际输出尺寸由工作流决定并从媒体探测。此次只调整前端发布行为，无后端、API 合约、数据库迁移或依赖变更。

## 画布连线与个人资产赋槽（2026-10-04）

ComfyUI 的图片映射复用普通编辑栏的画布连线，按参考图编号顺序填第一个空槽，不增加选择槽位的交互。工作流草稿为空时的 TEXT 只是尚无素材，不按普通模型的文生视频限制阻止已声明图片槽位；赋槽、精确引用、来源连线及有效模式在同一事务保存，不自动生成。旧位置草稿首次连接改用具名分配时保留已有顺序；同一版本可供多个槽位复用。断开最后来源同步清除槽位，其他来源仍存在时保留。ComfyUI 的视频和音频输入限制维持原契约，不因共用选择组件而放开。

个人资产选择扩展 `ReferenceLibraryRequest.slotKey` 为可选字段，导入出的同项目新版本在原完成事务内写入该槽位。明确替换允许覆盖该槽的旧分配；旧版本仍被其他槽位使用时保留其去重引用与来源，独占旧版本则清除引用、连线和结构化标签。所有步骤受同一草稿 CAS 和导入事务保护，冲突整体回滚；命令键包括槽位，重复提交复用原结果，同键异参返回冲突。普通引用省略该字段保持原请求；画布连接 API 沿用原字段，不新增槽位参数。没有数据库迁移，合约生成 TypeScript 与前后端同步部署；验证使用合成资产及真实 PostgreSQL，不证明真实 Provider 生成效果。

## 2026-10-04 已保存 API JSON 回显

用户要求后续回显与修改不依赖原文件。已有不可变能力版本保存完整 `comfyWorkflow.graph`，本轮补齐导入页：进入该步骤直接显示已保存的 API JSON，未编辑 JSON 时同步当前固定值修改；已输入的 JSON 草稿跨步骤保留。格式化超出导入上限时显示紧凑 JSON，避免已接受的图仅因空白变得不可解析。普通参数映射仍直接编辑；完整图替换继续明确解析并按原流程重新映射，不自动提交。没有后端合约或迁移变化，原图、历史能力和已受理任务保留。
