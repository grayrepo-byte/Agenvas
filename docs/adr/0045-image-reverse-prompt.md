# ADR 0045：图片工具栏提示词反推

状态：接受（2026-10-11，用户要求新增图片工具栏提示词反推）。

## 决策

图片节点工具栏提供「提示词反推」，只针对已有选用图片结果。打开窗口固定当时图片，用户明确点击开始后，后台文字模型读取该精确版本的归档原图，推导一段可用于图片生成的提示词。模型必须支持图片理解；目前通用配置不宣称已经验证所有模型的视觉能力，错误按实际调用反馈。Mock 模式明确展示演示身份。

结果可以编辑和复制，不自动修改图片草稿、内容版本、结果选择、画布节点或关系线。推导描述不承诺还原原始生成提示词。管理员通过统一提示词管理维护内置 FUNCTION `image.reverse-prompt`；每次受理固定正文、版本、语言及文字模型身份，图片内的文字不能授予工具或生成权限。

复用 `TEXT_GENERATION` 持久任务与现有文字 Worker，以输入 schema 3 和 `IMAGE_REVERSE_PROMPT` 用途区分。没有媒体能力绑定或产物输出目标；后台图片后处理功能绑定不控制文字模型。复用租约、用量、取消、项目状态事件及完整响应检查点。检查点只保存精确版本引用与消息文字，图片字节在发送前重新鉴权加载；网络调用不持有数据库事务。成功只向浏览器公开提示词、来源版本及 Mock 标记，不公开模型完整响应或私有推理。

同键同请求重放原任务，异参冲突；项目事务序列化同节点的新受理，其他命令遇到活动任务返回冲突。查询和重新打开窗口仅恢复状态，不自动再次调用模型。响应未确认时继续重放原命令；终态后的「重新反推」明确创建新任务。取消原子阻断后续发布，不能保证服务方停止处理或退款。

## 后果

- 新增项目范围的 `image-prompts` 查询、受理及取消 API，使用现有任务查询和状态事件。
- V24 仅增加内置提示词种子，不改变表结构或 jOOQ；前后端与数据迁移共同升级。
- 历史文字 Task schema 1/2、媒体生成与 Agent 权限保持既有语义。反推任务不占用媒体生成输出目标，不锁定图片草稿。
- 用户编辑的结果属于窗口内草稿；服务端保存原反推结果，刷新后可重新读取。关闭窗口不取消已受理任务。

## 原图输入修订（2026-11-05）

按用户要求，反推不再发送最长边 480px 的缩略图。授权后只读固定版本关联的归档原件，PNG/JPEG/WebP 保持字节、尺寸与 MIME；内联和可选 LLM 中继共用此内容。保留 10 MiB 原始字节上限，超限在访问存储/分配图片缓冲前拒绝；有界完整读取且释放流。缺失原图不回退缩略图，不静默压缩或降分辨率。GIF 明确失败，用户可显式导出要分析的静态图片，避免丢帧。

上限是应用内存边界，不是所有模型的支持范围。当前文字调用统一走 OpenAI 兼容多模态协议，模型目录没有视觉格式/尺寸能力声明，不能从模型名称或 Token 容量猜测。对供应商的显式 400/413/415/422 拒绝返回安全的 `IMAGE_PROMPT_MODEL_REJECTED`，界面说明检查视觉能力、格式/大小与中继可访问性；其他调用错误沿原分类。不记录供应商响应正文，不重试另一张缩图。

核验的官方资料：[OpenAI 视觉](https://developers.openai.com/api/docs/guides/images-vision)支持 PNG/JPEG/WebP 与非动画 GIF；[Gemini 图片理解](https://ai.google.dev/gemini-api/docs/image-understanding)的内联总请求限制为 20MB；[Claude 视觉](https://platform.claude.com/docs/en/build-with-claude/vision)另有每图编码大小与 8000×8000 尺寸限制。兼容网关、模型、部署方式可能进一步收紧；本次没有接入这些原生协议或声明它们全部可用，也不自动换传输来绕过拒绝。

Task schema、固定来源版本、冻结提示词和模型、用量、取消及检查点恢复边界保持。未派发的历史 schema 3 任务同样读取固定版本原图；已经有完整响应的任务直接恢复，不因升级重新调用。不新增合约字段、数据库迁移、依赖或生成代码。验证使用合成图片、本地假 HTTP 与隔离 PostgreSQL；真实模型效果、内部视觉预处理、费用及真实对象桶可达性未实测。

## 默认创作指令修订（2026-11-05）

按用户要求评估并优化一版反推提示词。参照开源项目实际模板与调用代码，继续使用统一管理的创作 system 正文、独立程序约束和单图 user 消息，输出仍为可编辑、可复制的一段通用自然语言。主体、表观媒介和关键视觉特征优先，数量、姿态、布局与空间关系具体化；按图像类型选择适用维度。对模糊细节只描述可见外观，不推测身份、隐藏内容、精确相机参数或制作来源；不添加新元素、通用质量标签、模型专属语法或负面词段。文字设计保留重要可辨文字的原文及布局，不翻译或补全看不清的内容，描述正文仍跟随用户语言。

图片内所有文字保持不可信视觉内容；固定 system 明确拒绝其要求切换语言、输出格式或规则，不开放工具。允许原语言引用不表示执行文字中的指令。这些是提示规则与既有执行边界，不能保证任意模型都能抵御视觉注入或准确识别图中文字。

Flyway V49 只更新正文 SHA-256 精确匹配 V24 的内置 FUNCTION `image.reverse-prompt`，递增版本和更新时间。保留名称、描述、自定义正文（包括近似匹配）及全部旧 Task 冻结输入；已恢复为旧默认完整正文的条目同样会更新。新安装执行至 V49 后使用新默认。没有表结构、API、生成代码或依赖变化；不增加模型模式或改动用户流程。来源与逐项取舍见[评估记录](../research/image-reverse-prompt-2026-11-05.md)，实际检查见开发清单。


## 文字卡片输出修订（2026-11-05）

用户要求「反推按钮改成生成文字卡片」。保留来源版本预览及显式开始确认；新受理使用 schema 5，冻结按请求语言本地化的结果标题，Mock 标题明确标记。成功后创建独立 TEXT 产物、TASK 来源不可变首版和普通文字 CanvasItem，使用既有内容输出布局避碰，不改来源图片、媒体草稿、选用结果或连线。卡片沿用普通文字编辑器、自动保存和版本历史；窗口只展示原始提示词供预览/复制，并提供「查看文字卡片」。定位前刷新服务端画布；卡片被移除后不自动补建，原始提示词仍可复制。卡片在折叠分组内时先按分组 CAS 展开；定位调用持有独立取消信号，关闭/切换来源/卸载后只允许共享查询缓存更新，不再改变视口、选中态或关闭新窗口。

采用后台事务发布，而非浏览器收到成功后再次创建，避免关窗、刷新、丢回执和重复读取丢失或重复产物。项目锁、当前租约/epoch、取消状态和响应检查点在写卡前核验；产物、节点、成功状态及事件同事务提交。命令重放保留原 ID；显式「重新反推」才创建独立新任务和新卡片，不覆盖用户后续编辑。模型/输入/输出校验失败及取消不生成卡片。

卡片发布事务失败时回滚所有新增内容，保留已结算响应并让租约恢复只重试发布，不重新调用模型。持续布局或存储故障会保持任务待恢复，用户仍可取消。来源节点移除或项目归档不丢弃已接受结果；项目删除时保留文字产物和任务输出，但不放置新节点。

旧 schema 3 待执行任务仍按原文协议完成，已完成结果及同键重放不自动补卡。原图字节/MIME、10 MiB 上限、冻结模型及 V49 提示词、权限/CSRF/CAS、用量和私有响应边界保持。公开成功输出为 prompt、sourceVersionId、mock，加新任务的 artifactId、artifactVersionId 和 canvasItemId（已删除项目省略节点 ID）。更新 OpenAPI 并重新生成 TypeScript；无依赖、表结构、Flyway 或 jOOQ 变更。


## 直接派生与来源连线修订（2026-11-07）

按用户明确要求，移除反推确认及结果预览窗口。图片工具栏点击「提示词反推」即授权并受理；受理、排队和运行状态及取消入口放在工具栏，失败、读取异常、冲突、未授权、不确定响应和取消反馈放在来源节点内。成功内容直接使用普通文字节点查看、编辑、复制与版本历史，不保留「查看文字卡片」及专属视口跳转。

沿用 schema 5 后台发布，在同一项目事件事务中创建 TEXT 产物、不可变 TASK 首版、来源右侧避碰的文字 CanvasItem 和 `MEDIA_DERIVATION` 连线，再提交任务成功。节点沿用来源当前分组；已有节点不会被移动。连线固定任务受理的来源图片版本，不读取完成时选用版本，不转换成媒体参考输入。沿用现有关系类型与导出结构，无表结构或数据迁移；OpenAPI 同步行为说明并重新生成 TypeScript。

原命令不确定时，重试固定原键及原请求；隐藏工具栏或切换选用图片不丢弃该命令。读取历史只恢复状态；轮询或项目事件刷新画布和关系投影，绝不从浏览器回执建节点。显式再次反推才创建新任务和新节点。项目锁、租约/epoch、取消屏障及响应检查点继续覆盖产物、节点、连线、成功状态与事件，连线写入失败也必须整体回滚，恢复只重试发布、不再次调用模型。

来源仍存在时，切换图片版本或归档项目不阻断已受理结果的节点及连线发布。来源已移除时使用普通内容避碰布局保留独立文字节点，不重建来源或悬空连线；项目已删除时只保留文字产物和任务结果。历史已完成 schema 5 节点不自动补线或重排；待发布 schema 5 采用新布局与连线。旧 schema 3 保留服务端任务与文本输出，不自动补卡，前端不再保留专属窗口。以上替代前文关于开始确认、窗口查看及不创建连线的旧决定；原图传输、冻结提示词/模型、权限、用量、取消和私有响应边界不变。
