# ADR 0066：保留 Provider 视频生成音轨

状态：接受（2026-11-03）。针对 Issue #42，用户明确要求：所有 Provider 视频生成与归档必须保留返回音轨，应用不以是否上传音频参考强制控制输出音轨。旧自动去音会不可逆地丢失模型生成的对白、环境音或音效，而用户已有显式“音频分离”入口可创建无声派生结果，因此统一保留生成内容。

Seedance 的纯文本、首尾帧与全能参考均不发送 `generate_audio`，包括有音频参考和没有音频参考的请求；由供应商按原生行为处理音频，应用不强制设置该布尔开关。所有 Provider 的单结果、多结果、下载重试、归档恢复和取消晚到视频结果均保留返回音轨；不新增前端或 API 音轨开关。参考音频的格式、时长与视觉素材搭配限制仍只约束输入，不承担输出音轨开关的含义。

需要去音时由用户选择现有“音频分离”，按固定来源版本创建音频和无声视频两个独立结果，保留来源视频。用户明确选择的本地深度提取无音轨结果、视频剪辑或配音合成的音频模式继续遵循各自功能规则，不属于 Provider 生成结果的自动去音。

本决定取代 [ADR 0021](0021-audio-nodes-and-mixed-references.md) 中仅含音频参考才保留 Seedance 音轨的约定，以及[历史固定渠道规格](../superpowers/specs/2026-09-25-fixed-media-provider-adapters-design.md)中的无声输出与归档去音要求；[ADR 0023](0023-per-asset-object-storage.md) 的固定存储及中继决定保持。已归档内容与版本不可变，先前已去除的声音不自动恢复，也不为补音重新提交生成。
