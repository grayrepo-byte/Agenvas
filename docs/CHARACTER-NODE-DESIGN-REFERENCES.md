# 角色节点：商业参考与操作精简

本轮针对“节点按钮突兀、连接镜头含义不清”的反馈调整已有画布，不增加后端能力、接口、迁移或依赖。

## 原操作的准确含义

旧“连接镜头”并非分镜、剪辑或生成操作。菜单列出当前画布的 IMAGE / VIDEO 节点；第一次选择目标会保存角色关联，并打开实际服务端预览。已有关系直接打开预览。预览展示提示词贡献、图片/音频引用与模式变化，模型不支持时明确拒绝；点击“明确应用到草稿”后才更新目标草稿，不启动生成。

关闭预览不会应用草稿，但已建立的关联仍然保留。角色参考图不自动变成视频首帧，角色节点也不是供应商原生主体 ID。

## 设计取舍与实现

只缩小或改色仍保留两个同层级操作框；完全隐藏版本、造型和用途则会损害固定输入的可判断性。本轮选择资产卡结构：

- 角色名、固定版本和一个更多操作入口独立成行；预览区域由 88×118 扩大为 112×152，保持图片比例，不裁掉人物。
- 移除卡片内两个描边按钮。“造型与参考”和“选择图片或视频节点”放入右上角操作菜单；保留既有选中工具条与右侧连线端口。
- 菜单直接说明“选择后建立关联并预览；确认后才写入草稿”，目标带媒体类型图标，已关联目标有勾选与辅助说明。卡片下方使用“生成节点”，不再把任意图片/视频称为“镜头”。
- 操作入口和菜单项最小点击区域均为 44px，不依赖悬停；Enter / 方向键 / Escape 可完成操作。菜单关闭后再打开配置或预览，保证对话框关闭时返回持久的菜单入口。
- 当画布锚点已越出窄视口，菜单仍限制在屏幕内。小于 1024px 保持既有只读规则，不宣称手机支持完整画布编辑。

库/项目手动同步、固定角色快照、UNKNOWN 核对、重复关系复用和明确应用语义均保持原行为。
