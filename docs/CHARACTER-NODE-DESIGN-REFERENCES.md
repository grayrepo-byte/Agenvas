# 角色节点：商业参考与操作精简

本轮针对“节点按钮突兀、连接镜头含义不清”及后续“卡片套卡片”“两个按钮太重”的反馈调整已有画布，不增加后端能力、接口、迁移或依赖。

## 原操作的准确含义

旧“连接镜头”并非分镜、剪辑或生成操作。菜单列出当前画布的 IMAGE / VIDEO 节点；第一次选择目标会保存角色关联，并打开实际服务端预览。已有关系直接打开预览。预览展示提示词贡献、图片/音频引用与模式变化，模型不支持时明确拒绝；点击“明确应用到草稿”后才更新目标草稿，不启动生成。

关闭预览不会应用草稿，但已建立的关联仍然保留。角色参考图不自动变成视频首帧，角色节点也不是供应商原生主体 ID。

## 设计取舍与实现

上一轮虽然移除了双描边按钮，但仍把竖图放在外层卡片内部，左右信息栏和菜单形成了额外层级。用户明确否定这一结构。本轮改为单一图片节点，视觉效果交由用户判断：

- 图片直接铺满 320×300 节点，与现有图片节点共享外轮廓、画布标题、选中边界和工具条；没有内层图片框、内容卡或左右分栏。封面使用 cover 裁切，完整参考仍在既有配置面板中以 contain 显示，不改原始字节、参考版本或生成输入。
- 名称、固定版本、造型、更新状态及图像/音频数量直接叠在图片下缘渐变上；零关联不展示无用计数。完整角色设定移到配置面板的折叠区域，并跟随当前选择的角色修订。
- 右上角仅保留两个直接操作图标：常态不绘制底块，用 18px 白色图标和深色轮廓直接叠在图片上；悬停显示局部圆形反馈，键盘焦点/展开状态增加内缘提示。配置直接打开“造型与参考”，关联打开单用途图片/视频目标选择器。没有通用更多菜单或多层操作菜单；既有工具条与右侧连线端口保留。
- 边缘按钮在悬停、选中、键盘焦点或选择器展开时显示；无悬停/粗指针设备常驻显示。两个按钮和目标条目均为最小 44px 命中区，具备可访问名称；Enter / 方向键 / Escape 与对话框关闭后的焦点恢复保持可用。
- 目标选择器优先放在图片侧边，说明“选择后建立关联并预览；确认后才写入草稿”，已关联目标带勾选并复用原关系。只读状态改为上下展开，避免画布锚点离屏时水平裁切；1024px 以下仍沿用现有画布只读规则。

库/项目手动同步、固定角色快照、UNKNOWN 核对、重复关系复用和明确应用语义均保持原行为。商业参考仅帮助决定视觉与操作层次，不代表接入了对应平台的原生能力。

## 单一图片结构验证（前轮）

真实 IAB 浏览器、独立 PostgreSQL 与 Mock 服务验证：1280×720 的 320×300 节点为完整单一图片表面；配置直接进入、折叠设定与选定版本一致、完整参考可见、未保存退出保护、键盘焦点恢复、目标侧边选择、实际关系预览、关闭后草稿未修改、已有关系不重复创建、端口拖线、图片区域拖动及文字角色占位。1100×800 下两个入口实测 44×44；390×844 下目标项只读且选择器边界为 left82 / right378。最终截图包含静态、选中与目标选择状态，原始文件仅在仓库外私有目录保存。

真实触摸设备、屏幕阅读器、浅色主题的浏览器视觉与付费 Provider 未实测；响应式视口和 CSS 粗指针分支不能代替真机验收。未运行全量测试，未推送或部署。


## 边缘操作轻量化补充

针对两个深色方块仍显厚重的反馈，只调整既有按钮变体及节点局部样式：44×44 透明操作区保留，常态不画背景、边框或整块阴影；图标使用白色填充与深色轮廓。悬停、按下、键盘焦点和目标选择器展开时才出现 32px 圆形反馈，焦点/展开状态有内缘提示。没有新增操作、菜单层级、动效或业务写入。修复通用 ghost 悬停规则会重新画出完整方块的覆盖问题。

本轮对应 4 文件 50 项测试、TypeScript、相关 ESLint、主题检查及 Vite 构建通过；保留既有大 chunk 提示。真实 IAB + 独立 PostgreSQL/Mock 检查了改版前后同一节点、键盘配置/关联/取消与返回焦点、目标实际预览、纯白和纯黑参考上的图标辨识、1100px 下 44×44 命中区，以及 390px 下的只读目标。实际点击透明区边缘仍可打开配置。

独立审查无剩余阻断。纯色截图与源颜色检查不代表所有图片、缩放、视觉条件均已达到无障碍标准；真实触屏、屏幕阅读器和浅色主题未实测，未运行全量测试或付费模型。最终节点与选择器截图保存在仓库外并作为交付提供，视觉效果由用户判断。
