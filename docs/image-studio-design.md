# 独立生图工作台

## 已确认范围

从主导航 `/image-studio` 直接进入，不要求创建或选择画布。首版提供文生图、上传静态参考图、按已发布能力显示模型参数（比例、尺寸/分辨率、质量、数量）、完整批次结果预览及私有下载、持久化历史和参数回填。左侧约三成参数区，右侧结果网格，顶部历史入口；窄屏重排。复用仓库 shadcn、主题与中英文/现有四语言目录。

新入口不接受画布节点 ID，不创建隐藏节点，不使用用户当前画布。蒙版、局部重绘和旧画布编辑草稿不迁移。首版仅开放经现有静态图片链验证的 Mock、OpenAI GPT Image 2、Google Nano Banana 2；动态工作流及其他适配器暂不列入工作台目录。能力级复杂度只有有实际语义时才呈现，不添加占位控件。画布原有 GIF 与工具路径保持原契约。

## 技术边界与取舍

现有 Task、Asset、ArtifactVersion、事件和权限均依赖 project_id。为保持这些可靠边界，追加项目 purpose（默认 CANVAS），每个所有者通过数据库唯一约束原子创建一个 IMAGE_STUDIO 技术作用域。它不出现在项目列表，不被普通项目设置/归档/删除入口操作，也不指向用户活动画布。作用域只用于内部授权、任务和资产存储；工作台界面不要求用户管理它。

工作台有独立批次表与有界分页历史，受理和所有任务、目标、用量预留同事务提交。同一个 Idempotency-Key 与相同请求返回完整原批次，不同请求返回冲突。每个输出任务独立保留成功/失败/UNKNOWN。普通数量为 1/2/4；供应商原生多输出数量不得再次拆分。冻结能力/连接版本、价格、默认比例及合法静态参考资产（或不可变版本）后交给既有 Worker/Adapter；不接收浏览器 URL 或供应商 URL。

图片输入准备从画布依赖中抽取为可复用逻辑。Studio 不调用 MediaDraftEditor/画布草稿受理服务。Task 输入显式 executionSurface=IMAGE_STUDIO；TaskService 将不可变结果归档与 Canvas 投影分开，Studio 所有结果（含供应商额外输出）只归档，不执行 CanvasItem 写入或选中。画布任务保留原节点身份、内容版本、选用与多图布局契约。

浏览器通过经过所有权校验的私有 Asset 内容/缩略图接口读取结果。上传沿用实际解码、尺寸、类型、归档、所有权检查，参考图拒绝动画 GIF。参考身份在受理时冻结。归档重试不再次生成，UNKNOWN 不自动重发；显式再次生成创建新的幂等命令。

## 验收

真实 PostgreSQL + 隔离假供应商验证：无节点从受理到下载、多输出零 CanvasItem、同键重放/冲突及并发、部分失败、历史刷新/参数回填、参考权限和固定版本、能力默认比例冻结、归档失败恢复不重发、UNKNOWN 不自动重发、旧画布正常生成回归。前端组件与真实浏览器验证桌面/窄屏、上传、提交、轮询、历史、预览及下载。真实付费模型不调用、不使用真凭据。

## 交付边界

同步 OpenAPI、生成 TypeScript 与 jOOQ、追加迁移、分批提交并独立审阅。提交 author/committer 与实际推送账户均核对为 grayrepo-byte。交付 feature branch 与到 develop 的 draft PR；不合并、不发布、不部署、不强推。
