# 独立生图工作台

## 已确认范围

从主导航 `/image-studio` 直接进入，不要求创建或选择画布。首版提供文生图、上传静态参考图、按已发布能力显示模型参数（比例、尺寸/分辨率、质量、数量）、完整批次结果预览及私有下载、持久化历史和参数回填。当前采用已批准的深色摄影棚：轻量品牌页头、中央单张主图、同批变体胶片、窄历史栏与三行浮动编辑卡；手机使用历史抽屉。复用仓库 shadcn、主题 token 与现有四语言目录。

新入口不接受画布节点 ID，不创建隐藏节点，不使用用户当前画布。蒙版、局部重绘和旧画布编辑草稿不迁移。首版仅开放经现有静态图片链验证的 Mock、OpenAI GPT Image 2、Google Nano Banana 2；动态工作流及其他适配器暂不列入工作台目录。能力级复杂度只有有实际语义时才呈现，不添加占位控件。画布原有 GIF 与工具路径保持原契约。

## 技术边界与取舍

现有 Task、Asset、ArtifactVersion、事件和权限均依赖 project_id。为保持这些可靠边界，追加项目 purpose（默认 CANVAS），每个所有者通过数据库唯一约束原子创建一个 IMAGE_STUDIO 技术作用域。它不出现在项目列表，不被普通项目设置/归档/删除入口操作，也不指向用户活动画布。作用域只用于内部授权、任务和资产存储；工作台界面不要求用户管理它。

工作台有独立批次表与有界分页历史，受理和所有任务、目标、用量预留同事务提交。同一个 Idempotency-Key 与相同请求返回完整原批次，不同请求返回冲突。每个输出任务独立保留成功/失败/UNKNOWN。普通数量为 1/2/4；供应商原生多输出数量不得再次拆分。冻结能力/连接版本、价格、默认比例及合法静态参考资产（或不可变版本）后交给既有 Worker/Adapter；不接收浏览器 URL 或供应商 URL。

图片输入准备从画布依赖中抽取为可复用逻辑。Studio 不调用 MediaDraftEditor/画布草稿受理服务。Task 输入显式 executionSurface=IMAGE_STUDIO；TaskService 将不可变结果归档与 Canvas 投影分开，Studio 所有结果（含供应商额外输出）只归档，不执行 CanvasItem 写入或选中。画布任务保留原节点身份、内容版本、选用与多图布局契约。

浏览器通过经过所有权校验的私有 Asset 内容/缩略图接口读取结果。上传沿用实际解码、尺寸、类型、归档、所有权检查，参考图拒绝动画 GIF。参考身份在受理时冻结。归档重试不再次生成，UNKNOWN 不自动重发；显式再次生成创建新的幂等命令。

## 验收

真实 PostgreSQL + 隔离假供应商验证：无节点从受理到下载、多输出零 CanvasItem、同键重放/冲突及并发、部分失败、历史刷新/参数回填、参考权限和固定版本、能力默认比例冻结、归档失败恢复不重发、UNKNOWN 不自动重发、旧画布正常生成回归。前端组件与真实浏览器验证桌面/窄屏、上传、提交、轮询、历史、预览及下载。真实付费模型不调用、不使用真凭据。

## 交付边界

首版已经同步 OpenAPI、生成 TypeScript 与 jOOQ、追加迁移并分批提交。当前工作区调整仅改前端与对应测试、文档，保留已有提交及后端边界。提交 author/committer 均为 grayrepo-byte。本轮不推送、不改凭据、不创建 PR、不合并、不发布、不部署；通过私有截图与保留原提交的 thin Git bundle 交付。

## 已批准的深色摄影棚

以用户选定的深色摄影棚视觉及三行输入修订为当前依据，替代此前的后台式多图工作区。保留 Agenvas 品牌与真实模型能力；示例摄影仅用于独立验收夹具，生产页面不预置示例结果。

- Studio 默认不显示管理侧栏，品牌入口返回项目与原产品导航；进入和离开不改其他页面的折叠偏好。近黑中性表面、低对比分隔和约 64px 页头让图片成为主体。
- 主图按真实尺寸比例完整展示，下方胶片用于同批变体选择，并保留放大、下载和显式回填。账户内存草稿按批次记录不可变版本选择；轮询追加、重排输出及更新历史首条都不能抢走用户已选图。失败、部分成功、归档恢复与 UNKNOWN 继续提供真实反馈。
- 点击生成后，主图区立即按本次参数显示等待取景框，胶片按请求数量预留编号。回执到达后显示批次短号、任务状态和已归档张数。各任务的首个结果填入自己的胶片位置，原生额外输出追加在末尾。已归档不等于浏览器已能显示：首张结果等待载入期间，取景框停止扫描并显示「正在加载预览」。
- 仅对用户刚发起且仍在查看的批次，首个可显示的缩略图或原图在同一取景区域以约 240 ms 揭晓，对应胶片编号短亮一次。原图换入、后续出图、刷新、重进及翻阅历史不重播。减少动态效果时直接显示照片。缩略图和原图可相互兜底；两者都不可用时提示预览失败，不影响已归档张数与任务状态。生成失败、取消和待核实继续使用静态状态反馈。
- 浮动编辑卡最大约 1050px，提示词默认三行（24px 行高、至少 72px 内容空间）；附件邻接输入。长文本有界扩展和滚动。模型、比例、分辨率、质量、数量按能力显示；高级设置按需展开，不编造费用。候选确认与回车只编辑文字，显式生成才提交。
- 右侧窄历史按批次展示私有缩略图，当前卡与主图版本一致，日期、状态和提示词在焦点或详情中可访问。刚受理但未进入分页列表的批次暂留于账户内 UI 投影，独立读回状态，直到服务端列表确认，切换历史不会使它消失。
- 编辑栏可编辑时，点击有归档图片的历史卡片会切换预览并直接回填原提示词，不改模型、参数或参考图，也不提交生成。「撤销回填」只恢复最近一次替换前的文字；手动编辑、全量回填或提交会结束这次撤销。无图或编辑锁定时只切换预览；初始化、刷新、轮询及同批换图不改草稿。「回填参数」继续显式恢复整套原设置和固定版本参考图，不提交。窄屏点击后关闭历史抽屉并归还焦点，不自动打开软键盘；主图与胶片保持一组，软键盘弹出时仍可滚动到编辑与生成。新增文案维护四语言。
- 每条批次历史提供独立的删除按钮和二次确认。默认只移除记录，保留文件；可选永久清理本批结果的原图与缩略图。清理尚未完成时只提示已安排，不声称空间已释放。失败保留记录和提示词草稿；仅当前卡片被删时切换预览，不执行历史回填，也不取消受理后的任务。
