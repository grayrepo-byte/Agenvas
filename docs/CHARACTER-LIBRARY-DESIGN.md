# 跨项目角色库与画布角色节点

用户已确认开始实现本方案；历史角色数据兼容不在要求内。本文将已确认的角色库、节点、手动同步和媒体能力边界具体化。实现不操作生产数据库，不推送或部署。

## 目标与范围

角色属于账号，可在不同项目反复使用。库角色保存名称、人设/身份与外观文本、明确的身份基准图片、多造型（衣着、发型等以文本描述）、有用途的多视图图片和可选音频参考/指定音色。创建入口覆盖本地素材、项目画布和已有项目角色。第一版不含参考视频、参数化造型编辑、角色训练、跨团队共享或跨模型一致性保证。

项目继续使用现有项目角色档案及不可变修订。导入库角色创建项目内副本和独立项目媒体版本；保存库更新不能悄悄改写项目角色、画布节点、媒体草稿或 Task。项目明确预览后手动同步：固定库修订、项目角色 CAS 和差异/受影响节点；提交时重新验证。已有绑定继续固定原输入，只标记待复核。编辑项目副本不反向改库。

## 实现选择

只给个人素材增加“角色”分类不能表达多造型、完整修订和同步关系；直接跨项目引用源 ArtifactVersion 会破坏权限与删除边界。本版采用独立账号级角色聚合，加项目固定副本，复用现有角色应用与 Task 冻结管线。普通个人素材条目与完整角色档案继续分开。

库媒体必须有独立归档，不能只保存源项目版本 ID 或依赖可删除的个人素材条目。发布捕获精确项目版本、归档到账号私有空间；导入复制字节并创建目标项目精确版本。网络和文件处理不持有长数据库事务。异步命令固定请求、具备持久回执、恢复与幂等；响应不确定时保留原命令供显式核对，不能创建重复导入。来源删除不影响已归档库；库归档不删除已导入项目内容或历史任务。

## 画布节点与连线

新增真正的 CHARACTER CanvasItem，subjectId 指向同项目角色，节点自己的配置固定项目角色修订、造型、本次参考及外观/声音用途。身份基准与其他视图用途可区分；用户可在节点选择本次图像子集，不能把库的所有视图强塞入模型。节点展示角色名、头像、造型、修订及是否存在较新项目版本，更新须显式操作。

节点沿用画布卡片与浮动工具条，使用可辨认的角色预览、造型名、固定版本、本次图像/音频数量和独立的更新提示。库更新与项目修订更新区分，均不自动替换节点。图片主导的资产卡通过右上角操作菜单提供“造型与参考”和图片/视频目标选择；保留既有选中工具条和连线端口，菜单说明先关联预览、后明确应用。菜单支持键盘与 44px 点击区域，关闭对话框返回菜单入口；已关联目标直接打开现有预览，关联列表默认折叠，图片错误显示占位。配置使用图片网格和简短用途标签，保存错误置顶并聚焦，未保存退出保留继续编辑/放弃选择。节点最小可编辑尺寸为 320×300；小于 1024px 的工作区遵循现有只读规则，打开中的角色对话框也禁用写入，并保留未知命令的只读核对。

角色连线表达角色应用关系，不是可执行 DAG。连接适配的图片/视频节点时先进入现有角色应用预览，再明确应用；提示实际图像/音频数量、模式和限制。保存节点/连线不生成任务。断开或删除节点不能删除历史结果，不得无提示丢弃手工输入；已有角色贡献沿用现有预览清理机制。布局、标题与选择配置使用独立的 CAS。锁定、项目归档、任务占用和权限边界均在服务端执行。

复制节点保留固定角色配置，创建新身份；删除只移除画布展示和逻辑连线，保留项目角色档案、库与已应用的冻结输入。项目删除沿用既有软删除并保留项目历史，库独立存在；后续物理清理须先清理项目侧关系。画布快照、SSE失效与项目导出包含节点及其安全选择配置。

## 模型边界

角色图像使用图片参考能力，视频首/尾帧始终保留其独立语义；不得把角色身份图自动设为首帧冒充角色锁定。不支持一般参考图的视频能力必须明确拒绝角色外观应用，并说明可先生成镜头图再用作首帧。声音参考和指定音色分别适配：音色 ID 不等于任意视频模型支持声音克隆。

供应商原生主体 ID 与普通参考图不同。第一版只能显示并使用已有能力目录和适配器真正支持的能力，不保存未经验证的跨供应商“通用主体 ID”，不假称支持原生角色注册。任务沿用现有受理时冻结输入和角色快照，后续库/节点修改不改变已受理任务。

## 验收与验证

接口和事务验收：同账号跨项目发布/导入、完整多造型/音频映射、源项目删除后可读、跨账号不可读写、同键重放不重复、不同键/CAS冲突、过期同步预览拒绝、库归档后的项目副本仍可用。真实 PostgreSQL 验证版本不可变、并发、FK和事务回滚。

画布验收：创建、重载、选造型/本次图、连接前预览、能力不符拒绝、明确应用、断开/删除、复制与锁定；手工输入保留和历史任务冻结。前端测试覆盖等待、空态、失败草稿保留、冲突、未知提交核对与未授权；类型检查、相关 lint 和生成合约验证。

只跑对应功能测试与专项检查，不自动全量测试。外部模型付费调用未获授权，不作为本次验证；Mock/合成素材验证明确标注。
