# 跨项目角色库与角色节点验收

实现基于 develop `ca69ec3`，保存在独立分支 `codex/character-library`。未合并到 develop，未推送、部署或迁移真实运行环境。功能巡检分支保持独立，只按本次角色放置的真实浏览器失败，复用 `5e60940` / `11f3a82` 中首次视口初始化和等待引用分组的相关实现与回归。

## 已交付

账号级私有完整角色档案：名称、人设、外观、身份基准图、多造型多视图和可选音频/音色。从本地图片/音频、个人素材、画布精确版本或已有项目角色创建，媒体独立归档。导入目标项目复制内容并固定版本，库修改不自动跟随；手动同步先展示完整当前项目内容与库候选，确认后以版本、预览摘要和持久命令安装新修订。项目已有草稿、受理任务和历史结果不被同步覆盖。

画布使用真正的 CHARACTER 主体，与 Artifact 类型分开。节点固定项目角色修订、造型、本次图片子集和声音用途；支持放置/目录拖入、配置、复制、锁定、删除、导出和独立逻辑连线。连接后预览，明确应用才保存媒体输入，不生成任务。手动角色和素材贡献保留，角色图不冒充视频首帧；已有首尾帧需要用户明确切换一般参考模式。

角色配置、逻辑连接与应用的未知提交保留原身份核对；锁定或归档后使用只读回执。显式关闭可保留本会话待核对请求，工作区提供重新打开入口。节点删除不删除库/项目角色、已应用草稿或历史结果。

新增 V50/V51、账号库及节点合约、生成 TypeScript/jOOQ、项目导出 schema 12，更新领域词汇、规格及 ADR 0074。没有新增或升级依赖。

## 验证结果

- 对应后端单测 42 项通过：角色服务/媒体适配、真实文件锁 fencing、准备媒体清理、导演安全摘要、Run 固定选择、恢复写守卫和画布复制。
- 唯一 PostgreSQL 专项 49 项通过：13 类统一串行运行 48 项；最后新增只读回执后完整节点 8 项再验，其中新增 1 项。覆盖库/节点、迁移、既有素材库恢复清理、Skill 归档、角色应用、复制、导出、MCP、恢复模式和 Mock Task 冻结。
- 前端最终限定 16 文件、346 项测试通过，覆盖库/项目角色、节点、未知提交核对、脏草稿、旧修订、真实 React Flow 工作区投影/恢复入口、视口、素材选择、分镜与缓存。
- 完整 TypeScript、ESLint、3841 个四语消息、主题检查通过；Vite 生产构建通过，保留既有大 chunk 提示。
- 在专用 PostgreSQL 17.11 空库执行 V1–V51，并验证 V50→V51 升级、约束与注释。官方 Maven profile 向独立目录重生 jOOQ，与源码比较零漂移；OpenAPI TypeScript 由官方生成器生成。
- 真实 Chrome 使用独立临时 profile、Mock 服务和纯合成素材，验证图片上传/独立归档、项目导入、界面建库角色及放置节点。1440×1000 下新节点完整可见，390×844 资产页无横向溢出，角色卡片容纳图片。
- 两名独立审查者完成后端与前端审查及限定复核。首帧别名绕过、提交确认丢失清理、连线 ABA、同步差异、旧修订选择、无造型默认用途、脏关闭和锁定/归档后的未知提交恢复均有修复与回归。

测试数据库和媒体目录均为专用临时资源。没有真实 Provider 或付费生成，Mock/合成素材不能证明外部模型效果。遵循仓库约束，未运行全量测试。早期并行 Maven 导致共享构建目录类加载干扰；上述最终结果使用独占构建目录串行重验，不计受干扰运行。

## 限制

- 不包含参考视频、参数化造型编辑、训练、跨团队共享或供应商原生主体注册；不承诺跨模型身份/音色一致性。
- 项目投影仍受原有 4000 字说明、每造型 14 图等边界限制；超限明确拒绝，不截断或静默丢素材。
- 未实测真实浏览器 HTML5 目录拖拽或付费 Provider；已验证点击放置、关系手势逻辑和实际 HTTP/数据库行为。
- 未保存表单及交互级待核对请求只在当前应用会话保留，不跨浏览器刷新。目标节点随后被删除时，历史回执仍有服务端授权读取接口，但当前工作区不提供该已删除目标的核对入口，也不会重建目标。
- 已受理命令的归档/回收可恢复。受理前进程崩溃或数据库持续不可用时，未被命令引用的临时 pin 可能保留；未实现账号私有归档全目录孤立文件 GC，避免不确定提交时误删输入。
