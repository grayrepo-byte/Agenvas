# 安全扫描例外台账

2026-10-05 按用户决定取消 CI 源码依赖与容器镜像漏洞扫描及 HIGH/CRITICAL 发布门禁，保留源码密钥扫描、镜像 SBOM 和许可证清单。当前没有生效的漏洞扫描例外，也不新增 gosu 排除；CI 成功不能作为漏洞检查通过的证据。

若以后恢复漏洞扫描，例外必须只覆盖经核实的误报，记录负责人、原因和到期日；到期前复审，不能自动延长。

已退役例外：SEC-001 曾只排除自建 agenvas-postgres 镜像中被 su-exec 符号链接替换的底层 `usr/local/bin/gosu`。2026-10-04 按用户决定改用官方固定版本 PostgreSQL，不再替换该程序；原例外和 CI 排除同步撤销。旧扫描结果仅为历史证据，不证明当前官方镜像没有漏洞。
