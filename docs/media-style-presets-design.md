# ADR 0030：图片与视频共用后台注入的风格预设

状态：接受（2026-10-02）。

图片和视频节点共用管理员维护的全局风格库，节点草稿单独保存可为空的风格选择。创作者通过带效果配图的模态框选择或清除风格，输入框保留用户原文；后台在渲染结构化媒体提及后拼接风格提示词，再按能力校验实际提交的完整提示词。没有提示词输入的工作流不支持风格。

任务受理时固定风格身份、版本、名称和提示词，已有排队任务、恢复与 UNKNOWN 的显式新尝试使用原快照。风格编辑与配图上传使用版本比较，停用风格保留既有草稿的选择并禁止新的运行，直到用户明确清除或更换。这样可以维护预设，同时避免后台配置变化静默改写创作输入。

内置八种通用风格及本地合成效果配图；管理员可手动添加、编辑、上传配图与停用。配图属于全局设置，不作为项目 Asset，也不会自动进入生成参考输入。手动上传经过实际解码与重新编码，不接受外部图片 URL。媒体草稿复制保留选择，新建编辑或后处理派生节点沿用空白草稿规则。项目导出保留选择和结果的冻结来源；全局风格配置与手动配图属于数据库备份范围。

权威合约新增登录后可读的 `/api/v1/media-styles` 与预览读取端点，以及管理员 `/api/v1/settings/media-styles` 创建、读取、版本化修改和配图上传端点。V75 新增风格表及草稿选择外键；升级的项目导出 schemaVersion=5 保存可空 `styleId` 和配置快照，既有草稿为空、既有任务不重新注入。风格名称、分类、提示词分别限制为 80、40、4000 字符；配图限制为 5 MiB / 20 MP，实际解码后缩放最长边 640 像素、重新编码为至多 1 MiB PNG。内置效果图的合成提示词见 [配图记录](../backend/src/main/resources/media-styles/PREVIEW-PROMPTS.md)。

新受理媒体输入升级到 schemaVersion=4，保留原始结构化提示词、渲染后的用户文本、完整提交文本和可空风格快照。旧任务保留字段回退，结果提示词不会因分离风格而丢失已渲染的素材标签。升级前未批准的 Agent 提案可能因输入摘要变化失效，需重新提案并批准；已受理任务与 UNKNOWN 显式重试不重新读取最新风格。
