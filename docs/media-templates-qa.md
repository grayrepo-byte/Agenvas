# 图片与视频模板界面验收

验收日期：2026-10-02。用户提供的图片/视频编辑栏、模板选择和创建模态框作为交互参考；实现沿用系统现有主题、shadcn/Radix 组件与字体。图片模板和视频模板分开，文字、音频节点没有模板入口。

## 浏览器范围

在隔离 Mock 页面使用实际生产模板选择、创建和系统管理组件，API 与素材均为合成数据，不连接真实项目或 Provider。桌面视口为 1280 × 720，窄屏视口为 390 × 844；临时视口覆盖已恢复。截图保存在仓库外私有目录，未将用户附件或实际项目截图纳入源码。

- 图片弹窗只展示 IMAGE 模板，视频弹窗只展示 VIDEO 模板。
- 全部/我的模板切换及名称搜索即时筛选；系统模板与个人模板标签可区分。
- 带图模板预览显示参考图片和替换当前引用/连线的影响；应用后填入提示词与一张参考图，合成生成调用保持零。
- 视频带图模板未选择受支持的输入模式时禁用应用；选择首尾帧后可应用。
- 纯提示词模板保留已经存在的参考图片。
- 个人视频模板表单固定视频类型，保存后新增模板出现在我的列表；系统设置管理组件可创建系统图片模板，保存后出现在系统目录。
- 窄屏弹窗宽度 374px，clientWidth 和 scrollWidth 均为 372px，无弹窗横向溢出；预览区域可滚动到应用按钮。
- 最终完整刷新后的浏览器验收中，控制台未发现 error 或 warn。

## 视觉检查

模板弹窗使用深色表面、轻边框、清晰的类型标题、顶部筛选/搜索/创建入口和图片卡片。无图模板以提示词摘要作为内容，预览与创建表单使用现有公共表单和状态组件；生成素材不作为预置内容随代码分发。创建表单有明确名称、模板类型、提示词、有序参考图片和保存栏。窄屏卡片双列换行，长提示词自然换行，弹窗头部保持可见。

未发现仍需修复的 P0/P1/P2 视觉问题。此记录验证模板组件与合成交互，不代表真实部署或 Provider 端到端验收；编辑器接入、保存冲突和后端权限由对应定向组件/真实 PostgreSQL 测试补充。
