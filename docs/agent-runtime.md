# 导演长任务运行配置

一条导演指令对应一个持久 AgentRun，没有累计模型轮次、工具次数或整体时长上限。关闭页面、等待媒体审批或模型暂时不可用时，数据库检查点和后台调度继续管理任务；服务关闭期间不执行，恢复后按持久期限和租约接管。

上下文达到配置阈值时，系统按 Codex 本地压缩的主流程生成任务交接，普通已完成模型/工具历史由摘要覆盖；初始指令、当前任务、已激活 Skill 主说明和当前媒体引用独立保留。摘要没有单独的 Token 长度配置，也不保留固定数量的近期工具回合。交接记录目标、约束、进度、待办、下一步、阻塞与精确引用。完整摘要按实际后继请求容量及压缩进展验证；来源太大时持久分块整理，原始记录不覆盖。压缩计入模型用量，不在聊天中冒充导演答复，也不能批准生成或执行工具。

管理员从侧栏进入 **导演设置**（`/settings/director`）。所有项目共享设置；只有管理员可读取和保存。保存后新请求立即读取数据库，无需重启。保存失败保留草稿，并发修改返回冲突；“载入最新设置”会替换当前草稿。

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| 上下文窗口 | 32,768 Token | 应用规划上限，还受所选模型容量约束 |
| 自动压缩阈值 | 50% | 按完整窗口计算，默认 16,384 个估算 Token |
| 响应预留 | 4,096 Token | 为完整模型响应预留空间，还受模型输出上限约束；压缩沿用同一额度 |
| 恢复期限 | 1,440 分钟（24 小时） | 从首次临时模型失败开始计算 |
| 最大模型重试次数 | 288 次 | 初次调用以外最多重试次数 |
| 最大退避间隔 | 300 秒 | 从 2 秒指数增长的退避上限 |
| 最大局部修复次数 | 4 次 | 一条可修复工具错误或摘要错误链的最多修复次数 |

升级需同步部署前后端并执行 Flyway 迁移。V64 删除 `summary_tokens` 和 `recent_tool_rounds`，保留其他已保存设置并推进配置版本，旧页面草稿须重新载入。GET/PUT 导演设置接口同步移除这两个字段。旧模型请求和压缩计划原样保留；新摘要修复可恢复原计划保存的完整响应预留。导演运行参数不从环境变量导入。

估算复用 Spring AI tokenizer，统计文字、工具 Schema、参数和回执，另加 25% 余量与媒体预留；它不是 Provider 的实际计费或窗口测量。窗口范围为 8,192–2,000,000 Token，响应预留至少 1,024 且少于窗口一半，触发比例为 1–100%。固定输入超过软触发线、没有历史可压缩且仍能放入输入预算时照常调用。固定指令本身无法容纳时显示配置错误，不静默删除任务约束。

恢复窗口可设为 1 分钟至 7 天，重试次数 1–10,000，退避上限 2 秒至 1 小时，局部修复 1–10 次。首次失败固定恢复期限、次数及修复链上限，重启或修改设置不会重置。摘要格式错误、响应截断、无法容纳后继请求或没有压缩进展时，在该上限内重新整理；不执行截断内容。普通模型回合与文字生成的截断响应仍终止，避免半截工具调用产生副作用。

工具参数/领域校验拒绝、资源失效或业务版本冲突时，整个失败批次回滚，原调用 ID 与拒绝结果交回模型修复；此前成功回合保留，不重复执行。版本冲突后先重读当前状态，再调整引用和 expectedVersion。权限拒绝、用户锁定、执行/幂等冲突和媒体 UNKNOWN 沿原规则处理；既有 FAILED Run 不自动重跑。

单次模型请求保留 600 秒总体、180 秒读取和 10 秒连接超时。鉴权、余额不足和永久配置错误不会盲目重试。媒体批次仍需明确批准，审批及执行各有独立期限，UNKNOWN 不自动重新生成。未保存完整模型响应时发生崩溃可能产生额外模型费用，不能承诺外部请求恰好一次。

来源、适配边界与决策见 [开源压缩方案核验](research/agent-compaction-summary-budgets.md) 和 [ADR 0063](adr/0063-durable-context-compaction-and-long-agent-tasks.md)。真实模型验收与假模型、真实 PostgreSQL、虚拟时间测试分别记录在开发清单中，不能以虚拟时间测试代替十几个小时的真实运行。
