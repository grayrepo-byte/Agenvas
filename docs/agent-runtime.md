# 导演长任务运行配置

导演的一条指令对应一个持久 AgentRun，没有累计模型轮次、工具次数或整体时长上限。关闭页面、等待媒体审批或模型暂时不可用时，任务由数据库检查点与后台调度继续管理。启动时须启用模型调度器；关闭服务期间不会执行，恢复后按持久期限和租约接管。

长任务的估算上下文达到完整模型窗口的 50%（默认 500,000 Token）时，系统用本 Run 固定的模型生成结构化交接摘要，再继续原任务。摘要保留目标、创作约束、进度、待办、下一步、阻塞与精确引用；初始指令和已激活 Skill 主说明单独保留。压缩调用会计入模型用量。源历史过大时分块处理，原始检查点不被覆盖；摘要不在聊天中冒充导演答复，也不能批准生成或执行工具。

管理员从侧栏进入 **导演设置**（`/settings/director`）。所有项目共享这一组运行参数；只有管理员可读取和保存。修改后点击“保存导演设置”，后续新请求立即读取数据库，无需重启。保存失败保留草稿，并发修改返回冲突；“载入最新设置”会明确替换当前草稿。

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| 上下文窗口 | 1,000,000 Token | 模型窗口预算（1M），按所选模型实际容量设置 |
| 自动压缩阈值 | 50% | 以完整窗口计算；默认 500,000 个估算 Token |
| 响应预留 | 8,192 Token | 从窗口预算中预留给响应的空间；不是 Provider 输出参数 |
| 摘要预算 | 2,048 Token | 交接摘要的估算 Token 上限 |
| 保留近期工具回合 | 4 回合 | 压缩时最多保留的完整近期工具回合；预算不足时减少 |
| 恢复期限 | 1,440 分钟（24 小时） | 一次临时模型故障从首次失败开始的恢复期限 |
| 最大模型重试次数 | 288 次 | 初次调用以外最多重试次数 |
| 最大退避间隔 | 300 秒 | 从 2 秒指数增长的退避上限 |
| 最大局部修复次数 | 4 次 | 一条工具参数或摘要错误链的最多修复次数 |

升级须执行 V41 迁移，并同步部署后端与前端。迁移用上述默认值初始化设置，不导入旧环境变量；原来使用自定义环境预算的安装需在界面重新保存。`AGENVAS_AGENT_*` 环境入口与对应 Spring 配置绑定均已移除；独立 JVM 和 Compose 都以数据库为准。其余模型连接、调度及媒体配置保持原有入口。

预算使用 Spring AI 自带 tokenizer，统计文本、工具 Schema、参数与回执，另加 25% 余量和媒体预留。不同模型 tokenizer、图片与音频的实际 Token 用量仍由 Provider 决定。窗口至少 8,192、最多 2,000,000 Token；响应预留至少 1,024 且少于窗口一半，摘要至少 256 且不超过输入预算四分之一。触发百分比可配置为 1–100%，有效触发线同时受响应预留后的硬输入预算约束。50% 是压缩软触发线：固定输入超过触发线、没有历史可压缩且仍在硬输入预算内时照常调用。消息数资源保护统一提高到 4,096 条，避免旧 80 条上限使 1M 窗口过早压缩。固定指令或主说明本身无法容纳时显示明确配置错误，不静默删除创作约束。可减少激活内容或指令，也可在实际模型支持的前提下提高预算。

恢复窗口可设为 1 分钟至 7 天，重试次数 1–10,000，退避上限 2 秒至 1 小时，局部修复 1–10 次。恢复的截止时间和次数上限在首次失败时固定；调整导演设置或重启不会重置已有恢复。普通新请求按当前导演设置规划，已冻结请求原样重放。模型无完整响应时发生崩溃，恢复可能产生额外模型费用，不能承诺外部模型调用恰好一次。

单次模型请求仍有 600 秒总体超时、180 秒读取超时和 10 秒连接超时；它们限制一次请求，不限制整个 Run。鉴权、余额不足和永久配置错误不会盲目重试。媒体批次仍须明确批准；审批及执行各有独立 24 小时期限，UNKNOWN 不自动重新生成。一个模型响应最多 40 个工具调用、一个媒体提案最多 6 项，也不限制整个 Run 的累计工作量。

实现决策见 [ADR 0063](adr/0063-durable-context-compaction-and-long-agent-tasks.md)。自动化验证使用真实 PostgreSQL、假模型和可控时钟；它不能替代真实模型摘要质量或十几个小时的墙钟运行验收。
