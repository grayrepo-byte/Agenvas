# Proposal

## Why

只想用文字或静态帧生成视频的用户，现在要先进入画布并配置视频节点。独立视频工作台沿用生图工作台的「编辑、生成、看结果、翻历史」流程，让这类任务不依赖项目或节点。

## What Changes

- 主导航新增 `/video-studio`。桌面使用居中的播放器、右侧历史栏及底部编辑区，窄屏将历史收进抽屉；不改变生图工作台或现有画布的入口。
- 提供文生视频和首尾帧两种模式。首帧必填；只有模型声明支持时才开放可选尾帧。模式、时长、画幅和分辨率使用已发布能力的真实约束。计划先接入既有 Mock 与 Seedance 2.0 两条路径，不引入新供应商协议。
- 显式生成后可查看任务和归档状态；在同一页面播放、放大、下载已归档视频，保留供应商返回的音轨。历史在刷新后可继续浏览；点开已有视频可继续编辑原提示词，也可显式回填完整设置和固定帧引用，两种回填均不启动生成。
- 生成任务和资产使用所有者私有的视频工作台作用域，不创建隐藏画布节点。核对未确认受理和恢复归档均不自动重新生成。
- 本次不做全能参考、剪辑与导出、跨工作台或画布导入、一键批量生成及历史文件清理。保留现有画布流程，包括其原有模型和输入能力。

## Capabilities

### New Capabilities

- `video-studio`: 独立视频生成的输入、受理、私有播放下载、历史和回填。

### Modified Capabilities

无；`image-studio` 的既有行为不变。

## Impact

影响前端导航、视频工作台页面和四语言目录，以及 Spring Boot 视频工作台 API、服务、持久化、现有媒体任务归档与权限边界。同步 OpenAPI、生成的 TypeScript 和增量 Flyway/jOOQ；不修改已有 API 合约，不新增服务、Provider 协议或媒体处理工具。
